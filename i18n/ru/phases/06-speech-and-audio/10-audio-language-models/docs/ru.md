# Аудио-языковые модели — Qwen2.5-Omni, Audio Flamingo, GPT-4o Audio

> Аудио-языковые модели 2026 года рассуждают о речи + звуках окружения + музыке. Qwen2.5-Omni-7B сравнивается с GPT-4o Audio на MMAU-Pro. Audio Flamingo Next превосходит Gemini 2.5 Pro на LongAudioBench. Разрыв между открытыми и закрытыми моделями практически устранён — за исключением задач с несколькими аудиодорожками, где все модели работают почти на уровне случайного угадывания.

**Type:** Learn
**Languages:** Python
**Prerequisites:** Phase 6 · 04 (ASR), Phase 12 · 03 (Vision-Language Models), Phase 7 · 10 (Audio Transformers)
**Time:** ~45 минут

## Проблема

У вас есть 5 секунд аудио: лай собаки, кто-то кричит "стоп!", затем тишина. Полезные вопросы охватывают несколько осей:

- **Транскрипция.** "Что было сказано?" — территория ASR.
- **Семантическое рассуждение.** "Человеку угрожает опасность?" — требует совместного понимания лая + крика + тишины.
- **Музыкальное рассуждение.** "Какие инструменты играют мелодию?"
- **Поиск по длинному аудио.** "В какой момент этой 90-минутной лекции преподаватель объяснял градиентный спуск?"

Единая модель, отвечающая на всё это по одному запросу, — это **аудио-языковая модель** (LALM / ALM). Отдельно от чистого ASR: LALM выдают ответы на естественном языке в свободной форме, а не просто транскрипты.

### Шаблон из трёх компонентов

Каждая LALM 2026 года имеет одинаковый скелет:

1. **Аудиоэнкодер.** Whisper encoder · BEATs · CLAP · WavLM · или собственный энкодер для конкретной модели.
2. **Проектор.** Линейный слой или MLP, связывающий признаки аудиоэнкодера с пространством эмбеддингов токенов LLM.
3. **LLM.** Декодер на основе Llama / Qwen / Gemma. Принимает чередующиеся текстовые + аудиотокены; генерирует текст.

Обучение:

- **Этап 1.** Заморозить энкодер + LLM; обучать только проектор на данных ASR / описания аудио (captioning).
- **Этап 2.** Полная / LoRA-дообучение на инструктивных аудиозадачах (QA, рассуждение, понимание музыки).
- **Этап 3 (опционально).** Добавление речевого входа/выхода (voice-in / voice-out) через речевой декодер. Так делают Qwen2.5-Omni и AF3-Chat.

### Где LALM полезны в 2026 году

- **Аудит соответствия записей колл-центра.** "Упомянул ли агент требуемое раскрытие информации?"
- **Доступность.** Описание звуковых событий для глухих пользователей (не просто транскрипция).
- **Модерация контента.** Выявление агрессивной лексики + угрожающего тона + фонового контекста.
- **Разбивка подкастов / совещаний на главы.** Семантическое резюме, а не просто смена говорящих.
- **Анализ музыкального каталога.** "Найти все треки со сменой тональности в B-секции."

### Где они (пока) НЕ полезны

- Тонкая музыкальная теория (ниже уровня аккордов).
- Рассуждение с привязкой к говорящему в длинных разговорах (качество падает после 10 минут).
- Сравнение нескольких аудиодорожек (22-26% — едва выше случайного угадывания).
- Потоковое рассуждение в реальном времени (большинство моделей работают в офлайн-пакетном режиме).

## Реализация

### Шаг 1: запрос к Qwen2.5-Omni

```python
from transformers import AutoModelForCausalLM, AutoProcessor

processor = AutoProcessor.from_pretrained("Qwen/Qwen2.5-Omni-7B")
model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-Omni-7B", torch_dtype="auto")

audio, sr = load_wav("clip.wav", sr=16000)
messages = [{
    "role": "user",
    "content": [
        {"type": "audio", "audio": audio},
        {"type": "text", "text": "What sounds do you hear, and what's happening?"},
    ],
}]
inputs = processor.apply_chat_template(messages, tokenize=True, return_tensors="pt")
output = model.generate(**inputs, max_new_tokens=200)
print(processor.decode(output[0], skip_special_tokens=True))
```

### Шаг 2: паттерн проектора

```python
import torch.nn as nn

class AudioProjector(nn.Module):
    def __init__(self, audio_dim=1280, llm_dim=4096):
        super().__init__()
        self.down = nn.Linear(audio_dim, llm_dim)
        self.act = nn.GELU()
        self.up = nn.Linear(llm_dim, llm_dim)

    def forward(self, audio_features):
        return self.up(self.act(self.down(audio_features)))
```

Вот и всё. Проектор обычно состоит из 1-3 линейных слоёв. Его обучение на парах ASR (аудио → транскрипт) — это вспомогательная задача Этапа 1.

### Шаг 3: бенчмаркинг MMAU / LongAudioBench

```python
from datasets import load_dataset
mmau = load_dataset("gamma-lab-umd/MMAU-Pro", split="test")
mcq = mmau.filter(lambda item: len(item["choices"] or []) > 1)

correct = 0
for item in mcq:
    answer = call_model(item["audio_path"], item["question"], item["choices"])
    if answer == item["answer"]:
        correct += 1
print(f"Accuracy: {correct / len(mcq):.3f}")
```

`audio_path` указывает на репозиторий датасета `data.zip` (около 47 ГБ), поэтому перед оценкой его нужно скачать и распаковать. Этот цикл с точным совпадением — проверка на здравый смысл, а не официальный скоринг бенчмарка, поэтому полученное число несопоставимо с опубликованными результатами MMAU-Pro. Официальный оценщик сопоставляет ответы с несколькими вариантами по сходству эмбеддингов (NV-Embed-v2), оценивает ответы в свободной форме с помощью LLM-судьи и проверяет ответы на соответствие инструкциям по regex-правилам: запишите предсказания в столбец `model_output` и запустите `evaluate_mmau_pro_comprehensive.py` из [репозитория MMAU-Pro](https://github.com/sonalkum/MMAUPro). Сообщайте результаты по каждой `category` (речь, звук, музыка, multi и остальное) отдельно. Агрегированные числа скрывают, где именно модель даёт сбой.

## Подводные камни

- **Чрезмерное доверие в задачах с несколькими дорожками.** Если вашей задаче нужно "какой клип содержит X", результат на уровне случайного угадывания — это реальность.
- **Деградация на длинном аудио.** После 10 минут атрибуция говорящего у большинства моделей ломается. Сначала проведите диаризацию (Урок 6), затем суммаризацию.
- **Галлюцинации на тишине.** Та же проблема, что у Whisper, унаследованная LALM, использующими Whisper-энкодер. Используйте VAD-фильтрацию.
- **Избирательное цитирование бенчмарков.** Блоги вендоров выделяют лучшие категории. Прогоните подмножество multi-audio из MMAU-Pro самостоятельно.
