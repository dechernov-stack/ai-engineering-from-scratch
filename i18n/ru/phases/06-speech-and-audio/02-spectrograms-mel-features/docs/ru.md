# Спектрограммы, мел-шкала и аудио-признаки

> Нейросети плохо воспринимают сырые waveform'ы. Они воспринимают спектрограммы. Мел-спектрограммы они воспринимают ещё лучше. Любая ASR-, TTS- и аудио-классификационная модель 2026 года живёт или умирает из-за этого единственного решения на этапе предобработки.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 6 · 01 (Audio Fundamentals)
**Time:** ~45 минут

## Проблема

Возьмём 10-секундный клип с частотой дискретизации 16 кГц. Это 160 000 чисел с плавающей точкой, все в `[-1, 1]`, почти идеально не коррелирующих с меткой "собака лает" или "слово кошка". Сырой waveform содержит информацию, но в форме, которую модели трудно извлечь. Две идентичные фонемы, произнесённые с интервалом 100 мс, дают совершенно разные сырые сэмплы.

Спектрограмма решает эту проблему. Она схлопывает временную детализацию там, где человеческое восприятие её игнорирует (микросекундный джиттер), и сохраняет структуру там, где восприятие на неё обращает внимание (какие частоты энергетически активны в окнах времени порядка ~10–25 мс).

Мел-спектрограммы идут ещё дальше. Люди воспринимают высоту тона логарифмически: 100 Гц против 200 Гц звучит "на том же расстоянии", что и 1000 Гц против 2000 Гц. Мел-шкала искажает ось частот в соответствии с этим. Мел-спектрограмма — единственный самый важный признак в речевом ML с 2010 по 2026 год.

## Концепция

![Waveform to STFT to mel spectrogram to MFCC ladder](../assets/mel-features.svg)

**STFT (кратковременное преобразование Фурье).** Нарезаем waveform на перекрывающиеся фреймы (типично: окно 25 мс, шаг 10 мс = 400 сэмплов / 160 сэмплов при 16 кГц). Умножаем каждый фрейм на оконную функцию (Hann по умолчанию; Hamming даёт чуть другой компромисс). Применяем FFT к каждому фрейму. Складываем амплитудные спектры в матрицу формы `(n_frames, n_freq_bins)`. Это и есть спектрограмма.

**Логарифм амплитуды.** Сырые амплитуды охватывают 5-6 порядков величины. Берём `log(|X| + 1e-6)` или `20 * log10(|X|)`, чтобы сжать динамический диапазон. Каждый продакшн-пайплайн использует логарифм амплитуды, а не сырую амплитуду.

**Мел-шкала.** Частота `f` в герцах отображается в мел `m` через `m = 2595 * log10(1 + f / 700)`. Отображение примерно линейно ниже 1 кГц и примерно логарифмично выше. 80 мел-бинов, покрывающих 0–8 кГц, — стандартный вход для ASR.

**Мел-банк фильтров.** Набор треугольных фильтров, равномерно расположенных по мел-шкале. Каждый фильтр — это взвешенная сумма соседних бинов FFT. Умножение амплитуды STFT на матрицу банка фильтров даёт мел-спектрограмму за одно матричное умножение.

**Лог-мел спектрограмма.** `log(mel_spec + 1e-10)`. Вход Whisper. Вход Parakeet. Вход SeamlessM4T. Универсальный аудио-фронтенд 2026 года.

**MFCC.** Берём лог-мел спектрограмму, применяем DCT (тип II), оставляем первые 13 коэффициентов. Декоррелирует признаки и дополнительно сжимает их. Доминирующий признак примерно до 2015 года, когда CNN/Transformer'ы на сырых лог-мелах их догнали. Всё ещё используется в распознавании диктора (x-vectors, ECAPA).

**Компромисс разрешения.** Больший размер FFT = лучшее частотное разрешение, но худшее временное. 25 мс / 10 мс — стандарт по умолчанию в аудио-ML; 50 мс / 12.5 мс для музыки; 5 мс / 2 мс для детекции транзиентов (удары барабана, взрывные согласные).

## Построение

### Шаг 1: нарезка waveform на фреймы

```python
def frame(signal, frame_len, hop):
    n = 1 + (len(signal) - frame_len) // hop
    return [signal[i * hop : i * hop + frame_len] for i in range(n)]
```

10-секундный клип с частотой 16 кГц при `frame_len=400, hop=160` даёт 998 фреймов.

### Шаг 2: окно Hann

```python
import math

def hann(N):
    return [0.5 * (1 - math.cos(2 * math.pi * n / (N - 1))) for n in range(N)]
```

Умножаем поэлементно перед FFT. Устраняет спектральную утечку, вызванную обрезанием на ненулевых концах.

### Шаг 3: амплитуда STFT

```python
def stft_magnitude(signal, frame_len=400, hop=160):
    win = hann(frame_len)
    frames = frame(signal, frame_len, hop)
    return [magnitudes(dft([w * s for w, s in zip(win, f)])) for f in frames]
```

В продакшне используется `torch.stft` или `librosa.stft` (на базе FFT, векторизованные). Цикл здесь приведён в учебных целях; он работает на коротких клипах за `code/main.py`.

### Шаг 4: мел-банк фильтров

```python
def hz_to_mel(f):
    return 2595.0 * math.log10(1.0 + f / 700.0)

def mel_to_hz(m):
    return 700.0 * (10 ** (m / 2595.0) - 1)

def mel_filterbank(n_mels, n_fft, sr, fmin=0, fmax=None):
    fmax = fmax or sr / 2
    mels = [hz_to_mel(fmin) + (hz_to_mel(fmax) - hz_to_mel(fmin)) * i / (n_mels + 1)
            for i in range(n_mels + 2)]
    hzs = [mel_to_hz(m) for m in mels]
    bins = [int(h * n_fft / sr) for h in hzs]
    fb = [[0.0] * (n_fft // 2 + 1) for _ in range(n_mels)]
    for m in range(n_mels):
        for k in range(bins[m], bins[m + 1]):
            fb[m][k] = (k - bins[m]) / max(1, bins[m + 1] - bins[m])
        for k in range(bins[m + 1], bins[m + 2]):
            fb[m][k] = (bins[m + 2] - k) / max(1, bins[m + 2] - bins[m + 1])
    return fb
```

80 мелов, покрывающих 0–8 кГц, с `n_fft=400` дают матрицу `(80, 201)`. Умножаем амплитуду STFT `(n_frames, 201)` на транспонированную матрицу, получая мел-спектрограмму `(n_frames, 80)`.

### Шаг 5: лог-мел

```python
def log_mel(mel_spec, eps=1e-10):
    return [[math.log(max(v, eps)) for v in frame] for frame in mel_spec]
```

Распространённые альтернативы: `librosa.power_to_db` (нормализованные относительно эталона дБ), `10 * log10(power + eps)`. Whisper использует более сложную процедуру клиппинга + нормализации (см. `log_mel_spectrogram` у Whisper).

### Шаг 6: MFCC

```python
def dct_ii(x, n_coeffs):
    N = len(x)
    return [
        sum(x[n] * math.cos(math.pi * k * (2 * n + 1) / (2 * N)) for n in range(N))
        for k in range(n_coeffs)
    ]
```

Применяем DCT к каждому лог-мел фрейму, оставляем первые 13 коэффициентов. Это и есть матрица MFCC. Первый коэффициент обычно отбрасывают (он кодирует общую энергию).

## Применение

Стек 2026 года:

| Задача | Признаки |
|------|----------|
| ASR (Whisper, Parakeet, SeamlessM4T) | 80 лог-мелов, шаг 10 мс, окно 25 мс |
| Акустическая модель TTS (VITS, F5-TTS, Kokoro) | 80 мелов, шаг 5–12 мс для тонкого временного контроля |
| Аудио-классификация (AST, PANNs, BEATs) | 128 лог-мелов, шаг 10 мс |
| Эмбеддинг диктора (ECAPA-TDNN, WavLM) | 80 лог-мелов или raw-waveform SSL |
| Музыка (MusicGen, Stable Audio 2) | дискретные токены EnCodec (не мелы) |
| Keyword spotting | 40 MFCC для крошечных устройств |

Эмпирическое правило: **если вы не работаете с музыкой, начинайте с 80 лог-мелов.** Бремя доказательства лежит на любом отклонении от этого.

## Подводные камни, которые всё ещё встречаются в продакшне в 2026 году

- **Несовпадение числа мелов.** Обучение на 80 мелах, инференс на 128 мелах. Тихий сбой. Логируйте форму признаков с обеих сторон.
- **Несовпадение частоты дискретизации выше по пайплайну.** Мелы, вычисленные при 22.05 кГц, выглядят иначе, чем при 16 кГц. Исправляйте SR *до* извлечения признаков.
- **дБ против логарифма.** Whisper ожидает лог-мел, а не дБ-мел. Некоторые пайплайны HF определяют это автоматически; ваш собственный код — нет.
- **Дрейф нормализации.** Нормализация по отдельному высказыванию при обучении, глобальная нормализация при инференсе. Продакшн-баг, удваивающий WER.
- **Утечка из-за паддинга.** Заполнение нулями конца клипа создаёт плоский спектр в завершающих фреймах. Дополняйте симметрично или репликацией.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Фрейм | Срез | 25-мс кусок waveform, подаваемый на одно FFT. |
| Шаг (hop) | Страйд | Количество сэмплов между последовательными фреймами; 10 мс — стандарт для ASR. |
| Окно | Штука типа Hann/Hamming | Поэлементный множитель, сглаживающий края фрейма до нуля. |
| STFT | Генератор спектрограммы | Фреймированное + оконное FFT; даёт матрицу время × частота. |
| Мел | Искажённая частота | Шкала логарифмического восприятия; `m = 2595·log10(1 + f/700)`. |
| Банк фильтров | Матрица | Треугольные фильтры, проецирующие STFT на мел-бины. |
| Лог-мел | Вход Whisper | `log(mel_spec + eps)`; стандартизовано в 2026 году. |
| MFCC | Старая школа признаков | DCT от лог-мела; 13 коэффициентов, декоррелированы. |
