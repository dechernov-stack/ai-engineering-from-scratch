**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 6 · 04, 05, 06, 07, 11; Phase 11 · 09 (Function Calling); Phase 14 · 01 (Agent Loop)
**Time:** ~120 минут

## Проблема

Соберите сквозного ассистента, который:

1. Захватывает ввод с микрофона (16 кГц, моно).
2. Определяет начало/конец речи пользователя.
3. Транскрибирует речь потоково.
4. Передаёт транскрипт LLM, способной вызывать инструменты (таймер, погода, календарь).
5. Стримит текст LLM в TTS.
6. Воспроизводит аудио пользователю.
7. Останавливается, если пользователь прерывает ответ.

Целевая задержка: первый байт аудио от TTS в пределах 800 мс после того, как пользователь закончил говорить, на ноутбучном CPU. Целевое качество: ни одного пропущенного слова, никаких галлюцинированных субтитров на тишине, никаких утечек клонирования голоса, никаких успешных prompt injection.

## Концепция

![Voice assistant pipeline: mic → VAD → STT → LLM+tools → TTS → speaker](../assets/voice-assistant.svg)

### Семь компонентов

1. **Захват аудио.** Микрофон → 16 кГц моно → чанки по 20 мс. Обычно `sounddevice` в Python или нативный AudioUnit/ALSA/WASAPI в продакшене.
2. **VAD (Урок 11).** Silero VAD с порогом 0.5, минимальная длина речи 250 мс, хвост тишины 500 мс. Сигнализирует "начало" и "конец".
3. **Потоковый STT (Уроки 4-5).** Whisper-streaming, Parakeet-TDT или Deepgram Nova-3 (API). Частичные и финальные транскрипты.
4. **LLM с вызовом инструментов.** GPT-4o / Claude 3.5 / Gemini 2.5 Flash. JSON-схема для инструментов. Потоковая генерация токенов.
5. **Потоковый TTS (Урок 7).** Kokoro-82M (самый быстрый открытый) или Cartesia Sonic (коммерческий). Запуск TTS после 20 токенов LLM.
6. **Воспроизведение.** Вывод на динамик; opus-кодирование для сетей с низкой пропускной способностью.
7. **Обработчик прерываний.** Если VAD срабатывает во время воспроизведения TTS — остановить воспроизведение, отменить генерацию LLM, перезапустить STT.

### Три сбоя, с которыми вы столкнётесь

1. **Обрезанное первое слово.** VAD стартует на такт позже, чем нужно. "Эй" пользователя теряется. Установите порог старта на 0.3, а не 0.5.
2. **Путаница при прерывании в середине ответа.** LLM продолжает генерацию после того, как пользователь прервал; ассистент говорит поверх пользователя. Свяжите VAD → отмену генерации LLM.
3. **Галлюцинации на тишине.** Whisper выдаёт "Thanks for watching" на тихих прогревочных кадрах. Всегда используйте VAD-гейтинг.

## Соберите это

### Шаг 1: захват с микрофона с чанкингом (псевдокод)

```python
import sounddevice as sd

def mic_stream(chunk_ms=20, sr=16000):
    q = queue.Queue()
    def cb(indata, frames, time, status):
        q.put(indata.copy().flatten())
    with sd.InputStream(channels=1, samplerate=sr, blocksize=int(sr * chunk_ms/1000), callback=cb):
        while True:
            yield q.get()
```

### Шаг 2: захват реплики с VAD-гейтингом

```python
def capture_turn(stream, vad, pre_roll_ms=300, silence_ms=500):
    buf, pre, triggered = [], collections.deque(maxlen=pre_roll_ms // 20), False
    silent = 0
    for chunk in stream:
        pre.append(chunk)
        if vad(chunk):
            if not triggered:
                buf = list(pre)
                triggered = True
            buf.append(chunk)
            silent = 0
        elif triggered:
            silent += 20
            buf.append(chunk)
            if silent >= silence_ms:
                return b"".join(buf)
```

### Шаг 3: потоковый STT → LLM → TTS

```python
async def turn(audio_bytes):
    transcript = await stt.transcribe(audio_bytes)
    async for token in llm.stream(transcript):
        async for audio in tts.stream(token):
            await speaker.play(audio)
```

### Шаг 4: вызов инструментов внутри цикла LLM

```python
tools = [
    {"name": "get_weather", "parameters": {"location": "string"}},
    {"name": "set_timer", "parameters": {"seconds": "int"}},
]

async for chunk in llm.stream(user_text, tools=tools):
    if chunk.type == "tool_call":
        result = dispatch(chunk.name, chunk.args)
        continue_streaming(result)
    if chunk.type == "text":
        await tts.stream(chunk.text)
```

### Шаг 5: обработка прерываний

```python
tts_task = asyncio.create_task(tts_loop())
while True:
    chunk = await mic.get()
    if vad(chunk):
        tts_task.cancel()
        await speaker.stop()

```

## Используйте это

См. `code/main.py` — запускаемую симуляцию, которая связывает все семь компонентов с заглушками моделей, чтобы вы могли увидеть форму пайплайна даже без оборудования. Для реальной реализации замените заглушки на:

- `silero-vad` (`pip install silero-vad`)
- `deepgram-sdk` или `openai-whisper`
- `openai` (`gpt-4o`) или `anthropic`
- `kokoro` или `cartesia`
- `sounddevice` для ввода/вывода

## Подводные камни

- **Бесконечное логирование персональных данных.** Полная запись реплики — это PII в большинстве юрисдикций. Храните 30 дней, шифруйте при хранении.
- **Отсутствие barge-in.** Пользователи будут прерывать. Ваш ассистент обязан замолчать.
- **Блокирующий TTS.** Синхронный TTS блокирует event loop. Используйте async или отдельный поток.
- **Отсутствие обработки ошибок вызова инструментов.** Инструменты дают сбои. LLM должна получить ошибку обратно + одну повторную попытку, затем плавно деградировать.
- **Чрезмерно ретивые фильтры галлюцинаций.** Перефильтруете — ассистент будет повторять "Я не могу помочь с этим". Недофильтруете — он будет говорить что угодно. Калибруйте на отложенной выборке.
- **Отсутствие опции wake-word.** Постоянное прослушивание — угроза приватности. Добавьте гейт по ключевому слову (Porcupine или openWakeWord).

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле значит |
|------|-----------------|-----------------------|
| Turn (реплика) | Обмен репликами пользователь + ассистент | Одна ограниченная VAD речь пользователя + один ответ LLM-TTS. |
| Barge-in | Прерывание | Пользователь говорит, пока говорит ассистент; ассистент замолкает. |
| Wake word (ключевое слово) | "Эй, ассистент" | Короткий детектор ключевого слова; Porcupine, Snowboy, openWakeWord. |
| End-pointing (определение конца реплики) | Завершение реплики | Решение VAD + минимальной тишины о том, что пользователь закончил. |
| Pre-roll (предбуфер) | Буфер перед речью | Хранение 200-400 мс аудио до срабатывания VAD, чтобы избежать обрезки первого слова. |
| Tool call (вызов инструмента) | Вызов функции | LLM выдаёт JSON; рантайм диспетчеризует; результат возвращается обратно в цикл. |
