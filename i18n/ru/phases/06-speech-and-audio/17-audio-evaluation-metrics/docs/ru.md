Этот урок называет метрики 2026 года для каждой аудиозадачи: ASR (WER, CER, RTFx), TTS (MOS, UTMOS, SECS, WER по обратному проходу через ASR), аудио-языковые модели (MMAU, LongAudioBench), музыка (FAD, CLAP) и говорящий/дикторская верификация (EER). ## Проблема

У каждой аудиозадачи есть несколько метрик, каждая измеряет свою ось. Использование неправильной метрики — это способ поставить модель, которая отлично выглядит на вашей панели мониторинга и ужасно работает в продакшене. Канонический список 2026 года:

| Задача | Основная | Вторичная |
|------|---------|-----------|
| ASR | WER | CER · RTFx · задержка первого токена |
| TTS | MOS / UTMOS | SECS · WER по обратному проходу через ASR · CER · TTFA |
| Клонирование голоса | SECS (ECAPA cosine) | MOS · CER |
| Верификация диктора | EER | minDCF · FAR / FRR в рабочей точке |
| Диаризация | DER | JER · спутывание дикторов |
| Классификация аудио | top-1 · mAP | macro F1 · recall по классам |
| Генерация музыки | FAD | CLAP · MOS от панели слушателей |
| Аудио-языковая модель | MMAU-Pro | LongAudioBench · AudioCaps FENSE |
| Потоковый S2S | задержка P50/P95 | WER · MOS |

### Метрики ASR

**WER (Word Error Rate, частота ошибок на словах).** `(S + D + I) / N`. Приводите к нижнему регистру, убирайте пунктуацию, нормализуйте числа перед подсчётом. Используйте `jiwer` или `whisper_normalizer` от OpenAI. &lt; 5% = речь уровня человека на чтении вслух.

**CER (Character Error Rate, частота ошибок на символах).** Та же формула, но на уровне символов. Используется для тональных языков (мандаринский, кантонский), где сегментация на слова неоднозначна.

**RTFx (обратный коэффициент реального времени).** Секунды аудио, обработанные за секунду реального времени. Чем выше, тем лучше. Parakeet-TDT достигает 3380×. Whisper-large-v3 — около 30×.

**Задержка первого токена.** Время от аудиовхода до первого токена транскрипта. Критично для потоковой обработки. Deepgram Nova-3: ~150 мс.

### Метрики TTS

**MOS (Mean Opinion Score, средняя оценка мнений).** Оценка людьми от 1 до 5. Золотой стандарт, но медленный. Собирайте 20+ слушателей на образец, 100+ образцов на модель.

**UTMOS (2022-2026).** Обученный предиктор MOS. Коррелирует примерно на 0.9 с человеческими оценками MOS на стандартных бенчмарках. F5-TTS: UTMOS 3.95; эталон: 4.08.

**SECS (Speaker Encoder Cosine Similarity, косинусное сходство эмбеддингов диктора).** Для клонирования голоса. Косинус между ECAPA-эмбеддингами эталона и клонированного вывода. &gt; 0.75 = узнаваемый клон.

**WER по обратному проходу через ASR.** Прогоните вывод TTS через Whisper, вычислите WER относительно исходного текста. Выявляет регрессии разборчивости. SOTA 2026: &lt; 2% CER.

**TTFA (time-to-first-audio, время до первого звука).** Задержка в реальном времени. Kokoro-82M: ~100 мс; F5-TTS: ~1 с.

### Специфика клонирования голоса

Тройка **SECS + MOS + CER**. Клонирование с высоким SECS, но низким MOS означает правильный тембр, но неестественное звучание; обратная ситуация — естественный голос, но неверный диктор.

### Верификация диктора

**EER (Equal Error Rate, равная частота ошибок).** Порог, при котором частота ложных принятий равна частоте ложных отклонений. ECAPA на VoxCeleb1-O: 0.87%.

**minDCF (min Detection Cost, минимальная стоимость обнаружения).** Взвешенная стоимость в выбранной рабочей точке (часто FAR=0.01). Более релевантна для продакшена, чем EER.

### Диаризация

**DER (Diarization Error Rate, частота ошибок диаризации).** `(FA + Miss + Confusion) / total_speaker_time`. Пропущенная речь + ложно обнаруженная речь + спутывание дикторов, каждая как доля. Встречи AMI: реалистичный DER ~10-20%. pyannote 3.1 + коммерческий Precision-2: &lt;10% DER на хорошо записанном аудио.

**JER (Jaccard Error Rate, частота ошибок Жаккара).** Альтернатива DER, устойчива к смещению на коротких сегментах.

### Классификация аудио

Мультиметочная классификация: **mAP (mean Average Precision)** по всем классам. AudioSet: 0.548 mAP для BEATs-iter3.

Взаимоисключающая мультиклассовая классификация: **top-1, top-5 accuracy**. Speech Commands v2: 99.0% top-1 (Audio-MAE).

Несбалансированные данные: **macro F1** + **recall по классам**. Сообщайте по классам — агрегированная точность скрывает, какие классы проваливаются.

### Генерация музыки

**FAD (Fréchet Audio Distance, расстояние Фреше для аудио).** Расстояние между распределениями VGGish-эмбеддингов реального и сгенерированного аудио. MusicGen-small на MusicCaps: 4.5. MusicLM: 4.0. Чем ниже, тем лучше.

**CLAP Score.** Оценка согласованности текста и аудио с использованием эмбеддингов CLAP. &gt; 0.3 = разумное соответствие.

**MOS от панели слушателей.** По-прежнему последнее слово для музыки потребительского уровня. Suno v5 ELO 1293 на TTS Arena (по парным предпочтениям людей).

### Аудио-языковые бенчмарки

**MMAU (Massive Multi-Audio Understanding).** 10 тыс. пар аудио-вопрос-ответ.

**MMAU-Pro.** 1800 сложных элементов, четыре категории: речь / звук / музыка / мульти-аудио. Случайное угадывание 25% при выборе из 4 вариантов. Gemini 2.5 Pro в целом ~60%; мульти-аудио ~22% по всем моделям.

**LongAudioBench.** Многоминутные клипы с семантическими запросами. Audio Flamingo Next превосходит Gemini 2.5 Pro.

**AudioCaps / Clotho.** Бенчмарки для подписи аудио. Метрики SPICE, CIDEr, FENSE.

### Потоковая речь-в-речь

**Задержка P50 / P95 / P99.** Время от конца речи пользователя до первого звукового ответа. Moshi: 200 мс; GPT-4o Realtime: 300 мс.

**WER / MOS** на выходе.

**Отзывчивость на прерывание (barge-in).** Время от прерывания пользователем до отключения звука ассистента. Целевое значение &lt; 150 мс.

## Постройте это

### Шаг 1: WER с нормализацией

```python
from jiwer import wer, Compose, ToLowerCase, RemovePunctuation, Strip

transform = Compose([ToLowerCase(), RemovePunctuation(), Strip()])
score = wer(
    truth="Please turn on the lights.",
    hypothesis="please turn on the light",
    truth_transform=transform,
    hypothesis_transform=transform,
)
# ~0.17
```

### Шаг 2: Обратный проход WER для TTS

```python
def ttr_wer(tts_model, asr_model, texts):
    errors = []
    for txt in texts:
        audio = tts_model.synthesize(txt)
        recog = asr_model.transcribe(audio)
        errors.append(wer(truth=txt, hypothesis=recog))
    return sum(errors) / len(errors)
```

### Шаг 3: SECS для клонирования голоса

```python
from speechbrain.inference.speaker import EncoderClassifier
sv = EncoderClassifier.from_hparams("speechbrain/spkrec-ecapa-voxceleb")

emb_ref = sv.encode_batch(load_wav("reference.wav"))
emb_clone = sv.encode_batch(load_wav("cloned.wav"))
secs = torch.nn.functional.cosine_similarity(emb_ref, emb_clone, dim=-1).item()
```

### Шаг 4: FAD для генерации музыки

```python
from frechet_audio_distance import FrechetAudioDistance
fad = FrechetAudioDistance()
score = fad.get_fad_score("generated_folder/", "reference_folder/")
```

### Шаг 5: EER для верификации диктора (тот же код, что и в уроке 6)

```python
def eer(same_scores, diff_scores):
    thresholds = sorted(set(same_scores + diff_scores))
    best = (1.0, 0.0)
    for t in thresholds:
        far = sum(1 for s in diff_scores if s >= t) / len(diff_scores)
        frr = sum(1 for s in same_scores if s < t) / len(same_scores)
        if abs(far - frr) < best[0]:
            best = (abs(far - frr), (far + frr) / 2)
    return best[1]
```

## Используйте это

Сопровождайте каждый деплой фиксированной системой оценки, которая запускается при каждом обновлении модели. Три главных правила:

1. **Нормализуйте перед оценкой.** Нижний регистр, удаление пунктуации, раскрытие чисел. Указывайте правило нормализации.
2. **Сообщайте распределения, а не средние значения.** P50/P95/P99 для задержки. Recall по классам для классификации. По категориям для MMAU.
3. **Запускайте один канонический публичный бенчмарк.** Даже если ваши продакшен-данные отличаются, отчётность по Open ASR / TTS Arena / MMAU позволяет рецензентам сравнивать равное с равным.

## Подводные камни

- **Экстраполяция UTMOS.** Обучена на чистой речи в стиле VCTK; плохо оценивает зашумлённое / клонированное / эмоциональное аудио.
- **Смещение панели MOS.** 20 работников Amazon Mechanical Turk ≠ 20 целевых пользователей. Платите за доменную панель, если ставки высоки.
- **FAD зависит от эталонного набора.** Сравнивайте с одним и тем же эталонным распределением для всех моделей.
- **Агрегированный WER.** 5% WER в целом может скрывать 30% WER на речи с акцентом. Сообщайте по демографическим срезам.
- **Насыщение публичных бенчмарков.** Большинство передовых моделей близки к потолку на стандартных бенчмарках. Создайте внутренний отложенный набор данных, отражающий ваш реальный трафик.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| WER | Оценка ASR | `(S+D+I)/N` на уровне слов после нормализации. |
| CER | Символьный WER | Для тональных языков или систем на уровне символов. |
| MOS | Человеческое мнение | Оценка от 1 до 5; 20+ слушателей × 100 образцов. |
| UTMOS | ML-предиктор MOS | Обученная модель; коррелирует примерно на 0.9 с человеческим MOS. |
| SECS | Сходство клонированного голоса | Косинус ECAPA между эталоном и клоном. |
| EER | Оценка верификации диктора | Порог, при котором FAR = FRR. |
| DER | Оценка диаризации | (FA + Miss + Confusion) / всего. |
| FAD | Качество генерации музыки | Расстояние Фреше на эмбеддингах VGGish. |
| RTFx | Пропускная способность | Секунды аудио на секунду реального времени. |
