# Генерация музыки — MusicGen, Stable Audio, Suno и землетрясение в области лицензирования

> Генерация музыки в 2026 году: Suno v5 и Udio v4 доминируют в коммерческом сегменте; MusicGen, Stable Audio Open и ACE-Step лидируют среди open-source решений. Техническая проблема в целом решена. Юридическая проблема (урегулирование Warner Music на $500 млн, урегулирование UMG) изменила ландшафт отрасли в 2025-2026 годах.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 6 · 02 (Spectrograms), Phase 4 · 10 (Diffusion Models)
**Time:** ~75 минут

## Проблема

Текст → музыкальный клип длиной от 30 секунд до 4 минут, с текстом песни, вокалом и структурой. Три подзадачи:

1. **Генерация инструментала.** Текст вроде «lo-fi hip-hop drums with warm keys» → аудио. MusicGen, Stable Audio, AudioLDM.
2. **Генерация песни (с вокалом и текстом).** «Country song about rainy Texas nights» → полноценная песня. Suno, Udio, YuE, ACE-Step.
3. **Условная / управляемая генерация.** Продолжить существующий клип, перегенерировать бридж, сменить жанр, разделить на стемы или заинпейнтить фрагмент. Инпейнтинг + разделение на стемы в Udio — это та функция 2026 года, с которой нужно сравниваться.

## Концепция

![Music generation: token-LM vs diffusion, the 2026 model map](../assets/music-generation.svg)

### Языковая модель токенов поверх нейро-кодек токенов

**MusicGen** от Meta (2023, MIT) и множество производных: обуславливание на текстовых / мелодических эмбеддингах, авторегрессивное предсказание токенов EnCodec (32 кГц, 4 кодбука), декодирование через EnCodec. 300M - 3,3B параметров. Сильная базовая линия; испытывает трудности после 30 секунд.

**ACE-Step** (open-source, версия 4B XL выпущена в апреле 2026) расширяет этот подход для генерации полных песен с условием на текст. Ближайший открытый аналог Suno от сообщества.

### Диффузия над мел-спектрограммами или латентами

**Stable Audio (2023)** и **Stable Audio Open (2024)**: латентная диффузия на сжатом аудио. Отлично справляется с лупами, саунд-дизайном, эмбиент-текстурами. Не очень хороша для структурированных полных песен.

**AudioLDM / AudioLDM2**: text-to-audio через латентную диффузию в стиле T2I, обобщённую на музыку, звуковые эффекты, речь.

### Гибридный подход (продакшн) — Suno, Udio, Lyria

Закрытые веса. Вероятно, авторегрессионная кодек-LM + вокодер на основе диффузии со специализированными головами для голоса / барабанов / мелодии. Suno v5 (2026) — лидер по качеству с ELO 1293. Udio v4 добавляет инпейнтинг + разделение на стемы (бас, барабаны, вокал как отдельные загрузки).

### Оценка

- **FAD (Fréchet Audio Distance).** Расстояние на уровне эмбеддингов между распределением сгенерированного и реального аудио с использованием признаков VGGish или PANNs. Чем меньше, тем лучше. MusicGen small: 4.5 FAD на MusicCaps; SOTA ~3.0.
- **Музыкальность (субъективная оценка).** Человеческие предпочтения. Лидирует Suno v5 с ELO 1293.
- **Соответствие текста и аудио.** Оценка CLAP между промптом и результатом.
- **Артефакты музыкальности.** Несинхронные переходы, дрейф вокальных фраз, потеря структуры после 30 с.

## Юридический ландшафт (2025-2026)

- **Урегулирование между Warner Music и Suno.** $500 млн. WMG теперь осуществляет надзор над ИИ-похожестью, музыкальными правами и пользовательскими треками на Suno. Аналогичное урегулирование UMG по Udio.
- **EU AI Act** + **California SB 942**: ИИ-сгенерированная музыка должна раскрываться.
- **Riffusion / MusicGen** под лицензией MIT не несут юридического бремени, но и не предоставляют коммерческий вокал.

Безопасные для продакшна паттерны:

1. Генерировать только инструментал (MusicGen, Stable Audio Open, выходные данные MIT/CC0).
2. Использовать коммерческие API (Suno, Udio, ElevenLabs Music) с лицензией на каждую генерацию.
3. Обучать на собственном или лицензированном каталоге (большинство предприятий в итоге приходят к этому).
4. Маркировать генерации водяными знаками + метаданными.

## Реализация

### Шаг 1: генерация с помощью MusicGen

```python
from audiocraft.models import MusicGen
import torchaudio

model = MusicGen.get_pretrained("facebook/musicgen-small")
model.set_generation_params(duration=10)
wav = model.generate(["upbeat synthwave with driving drums, 128 BPM"])
torchaudio.save("out.wav", wav[0].cpu(), 32000)
```

Три размера: `small` (300M, быстрая), `medium` (1.5B), `large` (3.3B). Small достаточна, чтобы проверить, «работает ли идея».

### Шаг 2: обуславливание по мелодии

```python
melody, sr = torchaudio.load("humming.wav")
wav = model.generate_with_chroma(
    ["jazz piano cover"],
    melody.squeeze(),
    sr,
)
```

MusicGen-melody принимает хромаграмму и сохраняет мелодию, меняя тембр. Полезно для запроса «дай мне эту мелодию в виде струнного квартета».

### Шаг 3: оценка FAD

```python
from frechet_audio_distance import FrechetAudioDistance
fad = FrechetAudioDistance()

fad.get_fad_score("generated_folder/", "reference_folder/")
```

Вычисляет расстояние между эмбеддингами VGGish. Полезно для регрессионных тестов на уровне жанра; не замена живым слушателям.

### Шаг 4: добавление в рабочий процесс LLM-музыки

Объедините с идеями из уроков 7-8:

```python
prompt = "Write a 30-second jazz loop. Describe the drums, bass, and piano voicing."
description = llm.complete(prompt)
music = musicgen.generate([description], duration=30)
```

## Подводные камни, которые всё ещё актуальны в 2026 году

- **Промпты для обхода авторских прав.** «Песня в стиле Taylor Swift» — коммерческие Suno/Udio теперь фильтруют такое, открытые модели — нет. Добавьте свой собственный список фильтров.
- **Повторение / дрейф после 30 с.** AR-модели зацикливаются. Кроссфейдите несколько генераций или используйте ACE-Step для структурной связности.
- **Дрейф темпа.** Модели «уплывают» от BPM. Используйте теги BPM в промпте и пост-фильтруйте с помощью `beat_track` из librosa.
- **Разборчивость вокала.** Suno отлично справляется; открытые модели часто «смазывают» слова. Если текст важен, используйте коммерческое API или дообучение.
- **Моно-вывод.** Открытые модели генерируют моно или фейковое стерео. Улучшайте с помощью правильной реконструкции стерео (ezst, стерео-диффузия Cartesia).

## Упражнения

1. **Лёгкое.** Запустите `code/main.py`. Это создаёт «генеративную» последовательность аккордов + барабанный паттерн в виде ASCII-символов — карикатуру на генерацию музыки. При желании можно воспроизвести через любой MIDI-рендерер.
2. **Среднее.** Установите `audiocraft`, сгенерируйте 10-секундные клипы по 4 жанровым промптам с помощью MusicGen-small, измерьте FAD относительно эталонного жанрового набора.
3. **Сложное.** Используя ACE-Step (или MusicGen-melody), сгенерируйте три вариации одной и той же мелодии с разными промптами тембра. Вычислите сходство CLAP с промптом, чтобы проверить соответствие.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| FAD | Audio FID | Расстояние Фреше между распределениями эмбеддингов реального и сгенерированного аудио. |
| Хромаграмма | Мелодия как высоты тона | 12-мерный покадровый вектор; вход для обуславливания по мелодии. |
| Стемы | Инструментальные дорожки | Разделённые бас / барабаны / вокал / мелодия в виде WAV. |
| Инпейнтинг | Перегенерация секции | Маскирование временного окна; модель перегенерирует только его. |
| CLAP | Text-audio CLIP | Контрастивный текстово-аудио эмбеддинг; оценка соответствия текста и аудио. |
| EnCodec | Музыкальный кодек | Нейронный кодек от Meta, используемый в MusicGen; 32 кГц, 4 кодбука. |
