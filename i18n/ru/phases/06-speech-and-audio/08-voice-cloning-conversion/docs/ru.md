# Клонирование голоса и преобразование голоса

> Клонирование голоса читает ваш текст голосом другого человека. Преобразование голоса переписывает ваш голос в чужой, сохраняя сказанное. Обе задачи опираются на одну и ту же декомпозицию: отделить идентичность говорящего от содержания.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 6 · 06 (Speaker Recognition), Phase 6 · 07 (TTS)
**Time:** ~75 минут

## Проблема

В 2026 году 5-секундного аудиоклипа достаточно, чтобы на потребительском GPU получить высококачественный клон голоса любого человека. ElevenLabs, F5-TTS, OpenVoice v2, VoiceBox — все они поставляют zero-shot или few-shot клонирование. Эта технология одновременно благо (доступная TTS, дубляж, вспомогательные голоса) и оружие (мошеннические звонки, политические дипфейки, кража интеллектуальной собственности).

Две тесно связанные задачи:

- **Клонирование голоса (сторона TTS):** текст + 5-секундный референсный голос → аудио этим голосом.
- **Преобразование голоса (сторона речи):** исходное аудио (человек A произносит X) + референсный голос человека B → аудио, где B произносит X.

Обе задачи раскладывают звуковую волну на (содержание, говорящий, просодия) и пересобирают содержание из одного источника с говорящим из другого.

Ключевое ограничение, с которым вы теперь работаете в 2026 году: **водяные знаки и шлюзы согласия юридически обязательны в ЕС (AI Act, вступает в силу в августе 2026) и в Калифорнии (AB 2905, действует с 2025)**. Ваш пайплайн обязан встраивать неслышимый водяной знак и отклонять клонирование без согласия.

## Концепция

![Voice cloning vs conversion: factorize, swap speaker, recombine](../assets/voice-cloning.svg)

**Zero-shot клонирование.** Передайте 5-секундный клип модели, обученной на тысячах говорящих. Кодировщик говорящего отображает клип в эмбеддинг говорящего; декодер TTS обуславливается на этот эмбеддинг плюс текст.

Используется в: F5-TTS (2024), YourTTS (2022), XTTS v2 (2024), OpenVoice v2 (2024).

**Few-shot дообучение.** Запишите 5–30 минут целевого голоса. LoRA-дообучите базовую модель за час. Качество скачкообразно переходит от «приемлемого» к «неотличимому». Coqui и ElevenLabs поддерживают этот паттерн; сообщество применяет его с F5-TTS.

**Преобразование голоса (VC).** Два семейства:

- **Распознавание-синтез.** Запустите ASR-подобную модель для извлечения представления содержания (например, мягкие фонемные постериоры, PPG), затем ресинтезируйте с эмбеддингом целевого говорящего. Устойчиво к языку и акценту. Используется в KNN-VC (2023), Diff-HierVC (2023).
- **Разделение (disentanglement).** Обучите автоэнкодер, который разделяет содержание, говорящего и просодию в латентном пространстве на узком месте (bottleneck). Замените эмбеддинг говорящего на этапе инференса. Качество ниже, но быстрее. Используется в AutoVC (2019), вариантах VITS-VC.

**Клонирование на основе нейронных кодеков (2024+).** VALL-E, VALL-E 2, NaturalSpeech 3, VoiceBox — рассматривают аудио как дискретные токены из SoundStream / EnCodec, обучают крупную авторегрессионную модель или модель с flow-matching поверх токенов кодека. Качество сопоставимо с ElevenLabs на коротких промптах.

### Этическая часть — не довесок

**Водяные знаки.** PerTh (Perth) и SilentCipher (2024) встраивают ~16-32-битный идентификатор незаметно в аудио. Переживает перекодирование, стриминг и типичные правки. Готов к продакшену, с открытым исходным кодом.

**Шлюзы согласия.** Каждый клонированный выход обязан сопровождаться проверяемой записью о согласии. «Я, Рохит, 22.04.2026 разрешаю использование этого голоса для цели X». Хранить в защищённом от подделки журнале.

**Детекция.** AASIST, RawNet2 и Wav2Vec2-AASIST поставляются как детекторы. Испытание ASVspoof 2025 опубликовало EER 0,8–2,3% для современных детекторов против выходов ElevenLabs, VALL-E 2 и Bark.

### Цифры (2026)

| Модель | Zero-shot? | SECS (сходство с целью) | WER (разборчивость) | Параметры |
|-------|-----------|--------------------|--------------|--------|
| F5-TTS | Да | 0.72 | 2.1% | 335M |
| XTTS v2 | Да | 0.65 | 3.5% | 470M |
| OpenVoice v2 | Да | 0.70 | 2.8% | 220M |

## Постройте это

### Шаг 1: декомпозиция методом «распознавание-синтез» (демонстрация только кодом в main.py)

```python
def clone_pipeline(ref_audio, text, target_embedder, tts_model):
    speaker_emb = target_embedder.encode(ref_audio)
    mel = tts_model(text, speaker=speaker_emb)
    return vocoder(mel)
```

Концептуально просто; основная масса реализации сосредоточена в `tts_model` и кодировщике говорящего.

### Шаг 2: zero-shot клонирование с F5-TTS

```python
from f5_tts.api import F5TTS
tts = F5TTS()
wav = tts.infer(
    ref_file="rohit_5s.wav",
    ref_text="The quick brown fox jumps over the lazy dog.",
    gen_text="Please add milk and bread to my list.",
)
```

Референсная транскрипция должна в точности совпадать с аудио; несовпадение ломает выравнивание.

### Шаг 3: преобразование голоса с KNN-VC

```python
import torch
from knnvc import KNNVC  # 2023 model, https://github.com/bshall/knn-vc
vc = KNNVC.load("wavlm-base-plus")
out_wav = vc.convert(source="my_voice.wav", target_pool=["alice_1.wav", "alice_2.wav"])
```

KNN-VC запускает WavLM для извлечения покадровых эмбеддингов для источника и целевого пула, затем заменяет каждый исходный кадр ближайшим соседом в пуле. Непараметрический метод, работает с минутой целевой речи.

### Шаг 4: встраивание водяного знака

```python
from silentcipher import SilentCipher
sc = SilentCipher(model="2024-06-01")
payload = b"consent_id:abc123;ts:1745353200"
watermarked = sc.embed(wav, sr=24000, message=payload)
detected = sc.detect(watermarked, sr=24000)   # returns payload bytes
```

~32 бита полезной нагрузки, обнаруживается после перекодирования в MP3 и лёгкого шума.

### Шаг 5: шлюз согласия

```python
def cloned_inference(text, ref_audio, consent_record):
    assert verify_signature(consent_record), "Signed consent required"
    assert consent_record["speaker_id"] == hash_speaker(ref_audio)
    wav = tts.infer(ref_file=ref_audio, gen_text=text)
    wav = watermark(wav, payload=consent_record["id"])
    return wav
```

## Применение

Стек 2026 года:

| Ситуация | Выбор |
|-----------|------|
| 5-секундное zero-shot клонирование, open-source | F5-TTS или OpenVoice v2 |
| Коммерческое производственное клонирование | ElevenLabs Instant Voice Clone v2.5 |
| Преобразование голоса (переписывание) | KNN-VC или Diff-HierVC |
| Дообучение на много говорящих | StyleTTS 2 + адаптер говорящего |
| Межъязыковое клонирование | XTTS v2 или VALL-E X |
| Детекция дипфейков | Wav2Vec2-AASIST |

## Подводные камни

- **Несовпадающая референсная транскрипция.** F5-TTS и аналогичные требуют точного совпадения референсного текста с референсным аудио, вплоть до пунктуации.
- **Реверберирующий референс.** Эхо убивает клон. Записывайте в сухом помещении, близко к микрофону.
- **Эмоциональное несоответствие.** Если референс «весёлый», клонирует всё с весёлой интонацией. Подбирайте эмоцию референса под целевое применение.
- **Утечка языка.** Клонирование англоговорящего, а затем просьба модели говорить по-французски часто всё равно несёт акцент; используйте межъязыковые модели (XTTS, VALL-E X).
- **Отсутствие водяного знака.** Юридически непригодно к поставке в ЕС с августа 2026 года.

## Упражнения

1. **Лёгкое.** Запустите `code/main.py`. Демонстрирует замену эмбеддинга говорящего путём вычисления косинуса между двумя «говорящими» до и после замены.
2. **Среднее.** Используйте OpenVoice v2, чтобы клонировать свой собственный голос. Измерьте SECS между референсом и клоном. Измерьте CER с помощью Whisper.
3. **Сложное.** Примените водяной знак SilentCipher к 20 клонам, прогоните их через кодирование+декодирование MP3 128 кбит/с, обнаружьте полезную нагрузку. Сообщите точность по битам.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле значит |
|------|-----------------|-----------------------|
| Zero-shot клон | 5 секунд достаточно | Предобученная модель + эмбеддинг говорящего; без дообучения. |
| PPG | Фонетическая постериограмма | Покадровые ASR-постериоры, используемые как языконезависимое представление содержания. |
| KNN-VC | Преобразование методом ближайших соседей | Замена каждого исходного кадра ближайшим кадром из целевого пула. |
| Нейронный кодек TTS | В стиле VALL-E | Авторегрессионная модель поверх токенов EnCodec/SoundStream. |
| Водяной знак | Неслышимая подпись | Биты, встроенные в аудио, переживающие перекодирование. |
| SECS | Точность клонирования | Косинус между эмбеддингами говорящего цели и клона. |
| AASIST | Детектор дипфейков | Модель защиты от спуфинга; обнаруживает синтезированную речь. |
