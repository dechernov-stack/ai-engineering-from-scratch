# Инпейнтинг, аутпейнтинг и редактирование изображений

> Text-to-image создаёт новое. Инпейнтинг чинит старое. В продакшене 70% оплачиваемой работы с изображениями — это редактирование: заменить фон, убрать логотип, расширить холст, перегенерировать руку. Инпейнтинг — это та задача, на которой диффузия действительно зарабатывает себе место.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 8 · 07 (Latent Diffusion), Phase 8 · 08 (ControlNet & LoRA)
**Time:** ~75 минут

## Проблема

Клиент присылает идеальное фото продукта с отвлекающей вывеской на заднем плане. Вы хотите стереть вывеску и оставить всё остальное пиксель-в-пиксель идентичным. Запускать text-to-image с нуля нельзя — результат будет другого цвета, с другим освещением, с другим ракурсом продукта. Вы хотите перегенерировать *только* замаскированную область, и чтобы при этом регенерация учитывала окружающий контекст.

Это и есть инпейнтинг. Варианты:

- **Инпейнтинг.** Регенерация внутри маски, пиксели снаружи сохраняются.
- **Аутпейнтинг.** Регенерация вне маски (или за пределами холста), внутренняя часть сохраняется.
- **Редактирование изображений.** Регенерация всего изображения с сохранением семантической или структурной верности оригиналу (SDEdit, InstructPix2Pix).

Каждый диффузионный пайплайн в 2026 году поставляется с режимом инпейнтинга. Flux.1-Fill, Stable Diffusion Inpaint, SDXL-Inpaint, DALL-E 3 Edit. Все они работают по одному и тому же принципу.

## Концепция

![Inpainting: mask-aware denoising with context-preserving reinjection](../assets/inpainting.svg)

### Наивный подход (и почему он неверен)

Запустить стандартный text-to-image с маской. На каждом шаге сэмплирования заменять немаскированную область шумного латента на прямо-диффундированное чистое изображение. Это работает... плохо. Артефакты на границах просачиваются насквозь, потому что у модели нет информации о том, что находится в замаскированной области.

### Правильная модель инпейнтинга

Обучить модифицированный U-Net, принимающий 9 входных каналов вместо 4:

```
input = concat([ noisy_latent (4ch), encoded_image (4ch), mask (1ch) ], dim=channel)
```

Дополнительные каналы — это копия VAE-закодированного исходного изображения плюс одноканальная маска. На этапе обучения случайным образом маскируются области изображения, и модель обучается удалять шум только в замаскированной области, при этом немаскированная область подаётся как чистый сигнал обусловливания. На этапе инференса модель "видит", что окружает замаскированную область, и производит связные дополнения.

SD-Inpaint, SDXL-Inpaint, Flux-Fill — все используют этот 9-канальный (или аналогичный) вход. Diffusers `StableDiffusionInpaintPipeline`, `FluxFillPipeline`.

### SDEdit (Meng et al., 2022) — бесплатное редактирование

Добавить шум к исходному изображению до некоторого промежуточного `t`, затем запустить обратную цепочку от `t` до 0 с новым промптом. Без переобучения. Выбор начального `t` меняет баланс между верностью исходнику и творческой свободой:

- `t/T = 0.3` → почти идентично исходнику, небольшие стилистические изменения
- `t/T = 0.6` → умеренные правки, грубая структура сохраняется
- `t/T = 0.9` → генерация почти из чистого шума, минимальное сохранение исходника

### InstructPix2Pix (Brooks et al., 2023)

Файнтюнинг диффузионной модели на тройках `(input_image, instruction, output_image)`. На этапе инференса обусловливание происходит и на входном изображении, и на текстовой инструкции ("сделай закат", "добавь дракона"). Два масштаба CFG: масштаб изображения и масштаб текста.

### RePaint (Lugmayr et al., 2022)

Берём стандартную безусловную диффузионную модель. На каждом обратном шаге выполняем ресэмплинг — периодически прыгаем назад к более шумному состоянию и регенерируем заново. Это избавляет от артефактов на границах. Используется, когда у вас нет обученной модели инпейнтинга.

```figure
inpaint-mask-reinject
```

## Построение

`code/main.py` реализует игрушечную 1-D схему инпейнтинга на 5-мерных данных. Мы обучаем DDPM на 5-D данных смеси, где каждый сэмпл — это 5 чисел с плавающей точкой из одного из двух кластеров. На этапе инференса мы "маскируем" 2 из 5 измерений, инжектируем прямо-диффундированную версию немаскированных трёх измерений на каждом шаге и регенерируем только замаскированные измерения.

### Шаг 1: 5-D данные DDPM

```python
def sample_data(rng):
    cluster = rng.choice([0, 1])
    center = [-1.0] * 5 if cluster == 0 else [1.0] * 5
    return [c + rng.gauss(0, 0.2) for c in center], cluster
```

### Шаг 2: обучение денойзера по всем 5 измерениям

Стандартный DDPM. Сеть выдаёт предсказание 5-D шума для 5-D шумного входа.

### Шаг 3: на этапе инференса — обратный проход с учётом маски

```python
def inpaint_step(x_t, mask, clean_image, alpha_bars, t, rng):
    # replace unmasked dims with a freshly noised version of the clean source
    a_bar = alpha_bars[t]
    for i in range(len(x_t)):
        if not mask[i]:
            x_t[i] = math.sqrt(a_bar) * clean_image[i] + math.sqrt(1 - a_bar) * rng.gauss(0, 1)
    # ...then run the normal reverse step on x_t
```

Это наивный подход, и он работает на игрушечных 1-D данных. В реальном инпейнтинге изображений используется 9-канальный вход, потому что связность текстуры важнее.

### Шаг 4: аутпейнтинг

Аутпейнтинг — это инпейнтинг с инвертированной маской: маскируется новый (ранее не существовавший) холст, остальное заполняется оригиналом. Целевая функция обучения идентична.

## Подводные камни

- **Швы.** Наивный подход оставляет видимые границы, потому что информация о градиенте не передаётся через маску. Решение: расширить маску на 8-16 пикселей или использовать нормальную модель инпейнтинга.
- **Утечка маски.** Если немаскированная область обусловливающего изображения низкого качества или шумная, это загрязняет генерацию внутри маски. Слегка удалите шум или размойте.
- **CFG взаимодействует с размером маски.** Высокий CFG на маленькой маске = перенасыщенный участок. Уменьшайте CFG для мелких правок.
- **Обрыв верности SDEdit.** Переход от `t/T = 0.5` к `t/T = 0.6` может привести к потере идентичности субъекта. Прогоняйте перебор и сохраняйте чекпоинты.
- **Несоответствие промпта.** Промпт должен описывать *всё* изображение, а не только новое содержимое. "Кот, сидящий на стуле", а не просто "кот".

## Применение

| Задача | Пайплайн |
|------|----------|
| Удаление объекта, маленькая маска | SD-Inpaint или Flux-Fill, стандартный промпт |
| Замена неба | SD-Inpaint + "голубое небо на закате" |
| Расширение холста | режим outpaint SDXL (feather 8px) или Flux-Fill с маской для outpaint |
| Регенерация руки / лица | SD-Inpaint с промптом, переописывающим субъект + ControlNet-Openpose |
| Изменение стиля одной области | SDEdit на `t/T=0.5` на замаскированной области |
| "Сделай закат" | InstructPix2Pix или Flux-Kontext |
| Замена фона | маска SAM → SD-Inpaint |
| Ультра-высокая точность | Flux-Fill или GPT-Image (хостируемый) для самых сложных случаев |

SAM (Meta's Segment Anything, 2023) + диффузионный инпейнтинг — это пайплайн удаления фона образца 2026 года. SAM 2 (2024) работает с видео.

## Упражнения

1. **Лёгкое.** В `code/main.py` варьируйте долю замаскированных измерений от 0.2 до 0.8. При каком значении доли качество инпейнтинга (остаток по замаскированным измерениям) сравнивается с безусловной генерацией?
2. **Среднее.** Реализуйте RePaint: на каждом 10-м обратном шаге прыгайте назад на 5 шагов (добавляя шум) и заново удаляйте шум. Измерьте, снижает ли это остаточную ошибку на границе маски.
3. **Сложное.** Используйте Hugging Face diffusers для сравнения: SD 1.5 Inpaint + ControlNet-Openpose против Flux.1-Fill на 20 задачах регенерации лиц. Оцените отдельно соответствие позе и сохранение идентичности.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Инпейнтинг | "Заполнить дыру" | Регенерация внутри маски; пиксели снаружи сохраняются. |
| Аутпейнтинг | "Расширить холст" | Регенерация за пределами холста; внутренняя часть сохраняется. |
| 9-канальный U-Net | "Нормальная модель инпейнтинга" | U-Net с `noisy \| encoded-source \| mask` на входе. |
| SDEdit | "Img2img с уровнем шума" | Шум до времени `t`, удаление шума с новым промптом. |
| InstructPix2Pix | "Правки только по тексту" | Файнтюнинг диффузии на тройках (изображение, инструкция, результат). |
| RePaint | "Без переобучения" | Периодическое повторное зашумление во время обратного процесса для уменьшения швов. |
| SAM | "Segment Anything" | Генератор масок по кликам или боксам; работает в паре с инпейнтингом. |
| Flux-Kontext | "Редактирование с контекстом" | Вариант Flux, принимающий референсное изображение + инструкцию для правок. |

## Заметка о продакшене: пайплайны редактирования чувствительны к задержке

Пользователи, редактирующие изображение, ожидают round trip менее 5 секунд. 30-шаговый SDXL-Inpaint при разрешении 1024² занимает 3-4 с на L4, плюс генерация маски SAM (~200 мс) и кодирование/декодирование VAE (~500 мс суммарно). В продакшен-терминах это ограничение по TTFT, а не по пропускной способности — батч 1, низкая конкурентность, минимизация каждого этапа:

- **SAM-H — самый медленный.** SAM-H при 1024² занимает ~200 мс; SAM-ViT-B — ~40 мс с небольшой потерей качества. SAM 2 (видео) добавляет временные накладные расходы; не используйте его для правок одиночных изображений.
- **По возможности пропускайте кодирование.** `pipe.image_processor.preprocess(img)` кодирует в латенты. Если у вас есть латенты от предыдущей генерации (типично для итеративных UI редактирования), передавайте их напрямую через `latents=...`, чтобы пропустить одно VAE-кодирование.
- **Расширение маски важно и для пропускной способности.** Маленькая маска означает, что большая часть прямого прохода U-Net тратится впустую (немаскированные пиксели всё равно обрезаются). `diffusers` `StableDiffusionInpaintPipeline` запускает полный U-Net независимо от размера маски; только собственно 9-канальные варианты инпейнтинга используют вычисления с учётом маски.
- **Flux-Kontext — ответ 2025 года.** Один прямой проход по `(source_image, instruction)` — без отдельной маски, без перебора уровня шума SDEdit. На H100 правка выполняется за ~1.5 с. Архитектурный урок: схлопните стадии в одну.
