# ControlNet, LoRA и условная генерация

> Текст сам по себе — грубый сигнал управления. ControlNet позволяет клонировать предобученную диффузионную модель и управлять ею картой глубины, скелетом позы, наброском или контурным изображением. LoRA позволяет дообучать модель с 2 млрд параметров, обучая всего 10 миллионов параметров. Вместе они превратили Stable Diffusion из игрушки в пайплайн генерации изображений 2026 года, который используется в каждом агентстве.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 8 · 07 (Latent Diffusion), Phase 10 (LLMs from Scratch — для основ LoRA)
**Time:** ~75 минут

## Проблема

Промпт вида «женщина в красном платье выгуливает собаку на оживлённой улице» не даёт модели никакой информации о том, *где* находится собака, *в какой позе* женщина или *какова перспектива* улицы. Текст фиксирует примерно 10% того, что нужно для задания изображения. Остальное — визуальная информация, которую нельзя эффективно описать словами.

Обучать новую условную модель с нуля для каждого сигнала (поза, глубина, canny, сегментация) непозволительно дорого. Хочется оставить бэкбон SDXL с 2,6 млрд параметров замороженным, подключить небольшую боковую сеть, которая считывает условие, и заставить её подталкивать промежуточные признаки бэкбона. Это и есть ControlNet.

Также хочется научить модель новым концепциям (вашему лицу, вашему продукту, вашему стилю) без переобучения всей модели. Нужна дельта в 100 раз меньше. Это LoRA — адаптеры низкого ранга, подключаемые к существующим весам attention.

ControlNet + LoRA + текст = набор инструментов практика 2026 года. Большинство production-пайплайнов для изображений накладывают друг на друга 2-5 LoRA, 1-3 ControlNet и IP-Adapter поверх базовой модели SDXL / SD3 / Flux.

## Концепция

![ControlNet clones the encoder; LoRA adds low-rank deltas](../assets/controlnet-lora.svg)

### ControlNet (Zhang et al., 2023)

Возьмите предобученную SD. *Клонируйте* энкодер-половину U-Net. Заморозьте оригинал. Обучите клон принимать дополнительный вход — условие (контуры, глубина, поза). Подключите клон обратно к декодер-половине оригинала через skip-соединения с *нулевой свёрткой* (1×1 свёртки, инициализированные нулём — начинают как no-op, учатся выдавать дельту).

```
SD U-Net decoder:   ... ← orig_enc_features + zero_conv(controlnet_enc(condition))
```

Инициализация нулевой свёрткой означает, что ControlNet начинает работу как тождественное преобразование — вреда нет даже до обучения. Обучение проводится на 1 млн троек (промпт, условие, изображение) со стандартной функцией потерь диффузии.

ControlNet для каждой модальности поставляется как небольшая боковая модель (~360M для SDXL, ~70M для SD 1.5). Их можно комбинировать на этапе вывода:

```
features += weight_a * control_a(depth) + weight_b * control_b(pose)
```

### LoRA (Hu et al., 2021)

Для любого линейного слоя `W ∈ R^{d×d}` в модели заморозьте `W` и добавьте дельту низкого ранга:

```
W' = W + ΔW,  ΔW = B @ A,  A ∈ R^{r×d},  B ∈ R^{d×r}
```

где `r << d`. Ранг 4-16 стандартен для attention, ранг 64-128 — для серьёзных дообучений. Количество новых параметров: `2 · d · r` вместо `d²`. Для attention SDXL с `d=640`, `r=16`: 20 тыс. параметров на адаптер вместо 410 тыс. — сокращение в 20 раз. По всей модели: LoRA обычно весит 20-200 МБ против 5 ГБ у базовой модели.

На этапе вывода LoRA можно масштабировать: `W' = W + α · B @ A`. `α = 0.5-1.5` — нормальное значение. Несколько LoRA складываются аддитивно (с обычной оговоркой, что они взаимодействуют нелинейно).

### IP-Adapter (Ye et al., 2023)

Крошечный адаптер, который принимает в качестве условия *изображение* (наряду с текстом). Использует CLIP image encoder для получения токенов изображения, внедряет их в cross-attention наряду с текстовыми токенами. ~20 МБ на базовую модель. Позволяет делать «сгенерировать изображение в стиле этого референса» без LoRA.

## Матрица совместимости

| Инструмент | Что контролирует | Размер | Когда использовать |
|------|------------------|--------|-----------|
| ControlNet | Пространственную структуру (поза, глубина, контуры) | 70-360МБ | Точная компоновка, композиция |
| LoRA | Стиль, субъект, концепцию | 20-200МБ | Персонализация, стиль |
| IP-Adapter | Стиль или субъект по референсному изображению | 20МБ | Когда внешний вид словами не описать |
| Textual Inversion | Одну концепцию как новый токен | 10КБ | Устаревший подход, в основном заменён LoRA |
| DreamBooth | Полное дообучение на субъекте | 2-5ГБ | Сильная идентичность, высокие вычислительные затраты |
| T2I-Adapter | Более лёгкая альтернатива ControlNet | 70МБ | Edge-устройства, ограниченный бюджет на вывод |

ControlNet ≈ пространственное. LoRA ≈ семантическое. Используйте оба.

## Реализация

`code/main.py` симулирует оба механизма в 1-D:

1. **LoRA.** Предобученный линейный слой `W`. Заморозьте его. Обучите низкоранговые `B @ A` так, чтобы `W + BA` соответствовал целевому линейному слою. Покажите, что `r = 1` достаточно, чтобы идеально выучить коррекцию ранга 1.

2. **ControlNet-lite.** «Замороженный базовый» предиктор и «боковая сеть», которая считывает дополнительный сигнал. Выход боковой сети контролируется обучаемым скаляром-гейтом, инициализированным нулём (наша версия zero-conv). Обучите и понаблюдайте, как гейт постепенно увеличивается.

### Шаг 1: математика LoRA

```python
def lora(W, A, B, x, alpha=1.0):
    # W is frozen; A, B are the trainable low-rank factors.
    return [W[i][j] * x[j] for i, j in ...] + alpha * (B @ (A @ x))
```

### Шаг 2: боковая сеть с нулевой инициализацией

```python
side_out = control_net(x, condition)
gated = gate * side_out  # gate initialized to 0
h = base(x) + gated
```

На шаге 0 выход идентичен базовому. Ранние этапы обучения медленно обновляют `gate` — без катастрофического дрейфа.

## Подводные камни

- **Чрезмерное масштабирование LoRA.** `α = 2` или `α = 3` — распространённый приём «сделать сильнее», который приводит к переcтилизованным / сломанным результатам. Держите `α ≤ 1.5`.
- **Конфликт весов ControlNet.** Использование Pose ControlNet с весом 1.0 и Depth ControlNet с весом 1.0 обычно даёт перебор. Сумма весов ≈ 1.0 — безопасное значение по умолчанию.
- **LoRA на неподходящей базе.** LoRA для SDXL молча не работают на SD 1.5, потому что размерности attention не совпадают. Diffusers предупредит об этом начиная с версии 0.30+.
- **Дрейф Textual Inversion.** Токены, обученные на одном чекпоинте, сильно дрейфуют на другом. LoRA более переносим.
- **Слияние весов LoRA и хранение.** Можно «впечь» LoRA в веса базовой модели для более быстрого вывода (без рантайм-сложения), но при этом теряется возможность масштабировать `α` во время работы. Храните обе версии.

## Ключевые термины

| Термин | Что обычно говорят | Что это на самом деле означает |
|------|-----------------|-----------------------|
| ControlNet | «Пространственное управление» | Клонированный энкодер + skip-соединения с нулевой свёрткой; считывает условное изображение. |
| Нулевая свёртка | «Начинает как тождественное преобразование» | 1×1 свёртка, инициализированная нулём; ControlNet стартует как no-op. |
| LoRA | «Адаптер низкого ранга» | `W + B @ A`, `r << d`; в 100 раз меньше параметров, чем полное дообучение. |
| ранг r | «Рычаг управления» | Степень сжатия LoRA; обычно 4-16, 64+ для серьёзной персонализации. |
| α | «Сила LoRA» | Масштабирование дельты LoRA во время работы. |
| IP-Adapter | «Референсное изображение» | Небольшой адаптер условия по изображению через токены CLIP-image. |
| DreamBooth | «Полное дообучение на субъекте» | Обучение всей модели на ~30 изображениях субъекта. |
| Textual Inversion | «Новый токен» | Обучение только нового эмбеддинга слова; устаревший подход, в основном заменён. |

## Production-заметка: замена LoRA, линии ControlNet, multi-tenant serving

Реальный SaaS text-to-image сервис обслуживает сотни LoRA и десяток ControlNet поверх одного и того же базового чекпоинта. Задача обслуживания сильно напоминает multi-tenancy для LLM (production-литература описывает случай LLM в разделах про continuous batching и LoRAX / S-LoRA):

- **Горячая замена LoRA, а не слияние.** Слияние `W' = W + α·B·A` с базой даёт ~3-5% ускорение вывода на шаг, но замораживает `α` и базу. Держите LoRA «горячими» в VRAM как дельты ранга r; diffusers предоставляет `pipe.load_lora_weights()` + `pipe.set_adapters([...], adapter_weights=[...])` для активации на уровне запроса. Стоимость замены — веса `2 · d · r · num_layers` — масштаб МБ, доли секунды.
- **ControlNet как вторая линия attention.** Клонированный энкодер работает параллельно с базой. Два ControlNet с весом 1.0 каждый = два дополнительных прямых прохода на шаг, а не один объединённый проход. Запас по размеру батча падает квадратично. Закладывайте ~1.5× стоимости шага на каждый активный ControlNet.
- **Квантованные LoRA тоже работают.** Если база квантована (см. Lesson 07, Flux на 8ГБ), дельта LoRA также чисто квантуется до 8-бит или 4-бит. Загрузка в стиле QLoRA позволяет накладывать 5-10 LoRA поверх 4-битной базы Flux, не превышая лимит памяти.

Специфика Flux: ноутбук Niels' Flux-on-8GB квантует базу до 4-бит; наложение стилевой LoRA (`pipe.load_lora_weights("user/style-lora")`) на эту квантованную базу при `weight_name="pytorch_lora_weights.safetensors"` по-прежнему работает. Это рецепт, который большинство SaaS-агентств используют в 2026 году.
