## Проблема

Безусловный GAN генерирует произвольные лица. Полезно для демо, бесполезно в продакшене. Вам нужно: *преобразовать набросок в фото*, *преобразовать карту в аэрофотоснимок*, *преобразовать дневную сцену в ночную*, *раскрасить чёрно-белое изображение*. Во всех этих случаях вам дано входное изображение `x`, и вы должны получить на выходе `y` с некоторым семантическим соответствием. Существует множество правдоподобных `y` для каждого `x`. Среднеквадратичная ошибка размазывает их в кашу. Состязательная функция потерь — нет, потому что «выглядит реалистично» — это резкий критерий.

Условный GAN (Mirza & Osindero, 2014) добавляет условие `c` как вход как для `G`, так и для `D`. Pix2Pix (Isola et al., 2017) специализировал этот подход: условие — это полное входное изображение, генератор — это U-Net, дискриминатор — это *патч-based* классификатор (PatchGAN), а функция потерь — состязательная + L1. Этот рецепт превосходит text-to-image модели, обученные с нуля, на узких задачах преобразования изображения в изображение даже в 2026 году, потому что он обучается на *парных данных* — у вас есть ровно тот сигнал, который нужен.

## Концепция

![Pix2Pix: U-Net generator, PatchGAN discriminator](../assets/pix2pix.svg)

**Условный G.** `G(x, z) → y`. В Pix2Pix `z` — это dropout внутри G (без входного шума — Isola обнаружил, что явный шум игнорировался).

**Условный D.** `D(x, y) → [0, 1]`. Входом является *пара* (условие, выход). Это ключевое отличие: D должен судить, согласован ли `y` с `x`, а не просто выглядит ли `y` реалистично.

**Генератор U-Net.** Энкодер-декодер со skip-соединениями через бутылочное горлышко. Критично важно для задач, где вход и выход имеют общую низкоуровневую структуру (края, силуэт). Без skip-соединений высокочастотные детали исчезают.

**Дискриминатор PatchGAN.** Вместо вывода единой оценки реальный/поддельный, D выводит сетку `N×N`, где каждая ячейка оценивает рецептивное поле размером ~70×70 пикселей. Результаты усредняются. Это предположение марковского случайного поля: реалистичность локальна. Обучается значительно быстрее, меньше параметров, более резкий результат.

**Функция потерь.**

```
loss_G = -log D(x, G(x)) + λ · ||y - G(x)||_1
loss_D = -log D(x, y) - log (1 - D(x, G(x)))
```

L1-слагаемое стабилизирует обучение и подталкивает G к известной целевой точке. L1 даёт более резкие края, чем L2 (медианы, а не средние). `λ = 100` был значением по умолчанию в Pix2Pix.

## CycleGAN — когда у вас нет парных данных

Pix2Pix требует парных данных `(x, y)`. CycleGAN (Zhu et al., 2017) убирает это требование ценой дополнительной функции потерь: *цикловой согласованности* (cycle consistency). Два генератора `G: X → Y` и `F: Y → X`. Их обучают так, что `F(G(x)) ≈ x` и `G(F(y)) ≈ y`. Это позволяет преобразовывать лошадей в зебр, лето в зиму — без парных примеров.

В 2026 году непарное преобразование изображения в изображение в основном выполняется через диффузию (ControlNet, IP-Adapter), а не через CycleGAN, но идея цикловой согласованности сохраняется почти в каждой статье о непарной доменной адаптации.

## Реализация

`code/main.py` реализует крошечный условный GAN на одномерных данных. Условие `c` — это метка класса (0 или 1). Задача: получить выборку из условного распределения для заданного класса.

### Шаг 1: добавление условия как ко входу G, так и ко входу D

```python
def G(z, c, params):
    return mlp(concat([z, one_hot(c)]), params)

def D(x, c, params):
    return mlp(concat([x, one_hot(c)]), params)
```

One-hot-кодирование — простейший способ. Более крупные модели используют обучаемые эмбеддинги, FiLM-модуляцию или кросс-внимание.

### Шаг 2: условное обучение

```python
for step in range(steps):
    x, c = sample_real_conditional()
    noise = sample_noise()
    update_D(x_real=x, x_fake=G(noise, c), c=c)
    update_G(noise, c)
```

Генератор должен соответствовать реальному распределению *для данного условия*, а не маргинальному.

### Шаг 3: проверка выхода по классам

```python
for c in [0, 1]:
    samples = [G(noise, c) for noise in batch]
    mean_c = mean(samples)
    assert_near(mean_c, real_mean_for_class_c)
```

## Подводные камни

- **Условие игнорируется.** G учится маргинализировать, D никогда не наказывает, потому что сигнал условия слишком слаб. Решение: обуславливайте D более агрессивно (на раннем слое, а не только на позднем), используйте проекционный дискриминатор (Miyato & Koyama 2018).
- **Слишком малый вес L1.** G дрейфует к произвольным правдоподобным, но не достоверным выходам. Начинайте с λ≈100 для задач в стиле Pix2Pix.
- **Слишком большой вес L1.** G выдаёт размытые результаты, потому что L1 всё ещё является L_p-нормой. Снижайте его постепенно после стабилизации обучения.
- **Утечка ground-truth в D.** Конкатенируйте `(x, y)` на входе D, а не только `y`. Без этого D не может проверить согласованность.
- **Коллапс мод по классам.** Каждый класс может коллапсировать независимо. Проводите проверки разнообразия для каждого класса отдельно.

## Применение

Состояние задач преобразования изображения в изображение в 2026 году:

| Задача | Лучший подход |
|------|---------------|
| Набросок → фото, тот же домен, парные данные | Pix2Pix / Pix2PixHD (по-прежнему быстро, по-прежнему резко) |
| Набросок → фото, непарные данные | ControlNet с моделью кондиционирования Scribble |
| Семантическая сегментация → фото | SPADE / GauGAN2 или SD + ControlNet-Seg |
| Перенос стиля | Диффузия с IP-Adapter или LoRA; GAN-методы устарели |
| Глубина → фото | ControlNet-Depth поверх Stable Diffusion |
| Суперразрешение | Real-ESRGAN (GAN), ESRGAN-Plus или SD-Upscale (диффузия) |
| Раскрашивание | ColTran, диффузионные раскрашиватели или Pix2Pix-color |
| День → ночь, смена сезонов, погода | CycleGAN или решения на основе ControlNet |

Pix2Pix остаётся правильным инструментом, когда (a) у вас есть тысячи парных примеров, (b) задача узкая и повторяемая, и (c) вам нужен быстрый инференс. В универсальных открытых доменных задачах побеждает диффузия.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Условный GAN | «GAN с метками» | G(z, c), D(x, c). Обе сети видят условие. |
| Pix2Pix | «GAN для изображение-в-изображение» | Парный cGAN с U-Net в качестве G и PatchGAN в качестве D + потеря L1. |
| U-Net | «Энкодер-декодер со skip-соединениями» | Симметричная свёрточная сеть; skip-соединения сохраняют высокие частоты. |
| PatchGAN | «Классификатор локальной реалистичности» | D выдаёт оценку по патчам вместо глобальной оценки. |
| CycleGAN | «Непарное преобразование изображений» | Два G + потеря цикловой согласованности; без парных данных. |
| SPADE | «GauGAN» | Нормализует промежуточные активации с помощью семантической карты; преобразование сегментации в изображение. |
| FiLM | «Поэлементная линейная модуляция признаков» | Поэлементное аффинное преобразование от условия; дешёвое кондиционирование. |

## Заметка о продакшене: Pix2Pix как baseline, ограниченный задержкой

Когда у вас есть парные данные и узкая задача (набросок → рендер, семантическая карта → фото, день → ночь), одношаговый инференс Pix2Pix превосходит диффузию по задержке на порядок. Сравнение в продакшене обычно выглядит так:

| Путь | Шаги | Типичная задержка при 512² на одном L4 |
|------|-------|----------------------------------------|
| Pix2Pix (прямой проход U-Net) | 1 | ~30 мс |
| SD-Inpaint или SD-Img2Img | 20 | ~1.2 с |
| SDXL-Turbo Img2Img | 1-4 | ~0.15-0.35 с |
| ControlNet + SDXL base | 20-30 | ~3-5 с |

Pix2Pix выигрывает по пропускной способности при статических батчах (каждый запрос требует одинакового количества FLOPs). Диффузия выигрывает по качеству и обобщению. Современный подход часто состоит в том, чтобы поставлять дистиллированную модель в стиле Pix2Pix для узкой задачи и диффузионный fallback для хвостовых (нетипичных) входных данных.
