# GAN — генератор против дискриминатора

> Трюк Гудфеллоу в 2014 году заключался в том, чтобы полностью обойти плотность распределения. Две сети. Одна создаёт подделки. Другая их ловит. Они борются, пока подделки не станут неотличимы от реальных данных. Это не должно работать. Часто и не работает. Но когда работает, результаты по-прежнему остаются самыми чёткими в литературе для узких доменов.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 3 · 02 (Backprop), Phase 3 · 08 (Optimizers), Phase 8 · 02 (VAE)
**Time:** ~75 минут

## Проблема

VAE выдают размытые образцы, потому что их MSE-функция потерь декодера оптимальна по Байесу для *среднего* изображения — а среднее от множества правдоподобных цифр представляет собой размытую цифру. Нужна функция потерь, которая вознаграждает *правдоподобность*, а не попиксельную близость к какой-то одной цели. Для правдоподобности нет замкнутой формулы. Её приходится выучивать.

Идея Гудфеллоу: обучить классификатор `D(x)` отличать реальные изображения от подделок. Обучить генератор `G(z)` обманывать `D`. Сигнал потерь для `G` — это то, что `D` в данный момент считает похожим на настоящее. Этот сигнал меняется по мере улучшения `G`, преследуя движущуюся цель. Если обе сети сходятся, `G` выучила распределение данных, ни разу не записав `log p(x)` в явном виде.

Это состязательное обучение. Математика представляет собой игру минимакс:

```
min_G max_D  E_real[log D(x)] + E_fake[log(1 - D(G(z)))]
```

В 2026 году GAN уже не являются SOTA-генератором (эту корону забрали диффузионные модели и flow matching). Но StyleGAN 2/3 остаются самыми чёткими моделями лиц из когда-либо выпущенных, дискриминаторы GAN используются как *перцептивные функции потерь* при обучении диффузионных моделей, а состязательное обучение лежит в основе быстрых 1-шаговых дистилляций (SDXL-Turbo, SD3-Turbo, LCM), которые позволяют поставлять диффузию в реальном времени.

## Концепция

![GAN training: generator and discriminator in minimax](../assets/gan.svg)

**Генератор `G(z)`.** Отображает вектор шума `z ~ N(0, I)` в сэмпл `x̂`. Сеть в форме декодера (полносвязная или с транспонированными свёртками).

**Дискриминатор `D(x)`.** Отображает сэмпл в скалярную вероятность (или оценку). Реальное → 1, поддельное → 0.

**Функция потерь.** Два чередующихся обновления:

- **Обучение `D`:** `loss_D = -[ log D(x) + log(1 - D(G(z))) ]`. Бинарная кросс-энтропия на реальных=1, поддельных=0.
- **Обучение `G`:** `loss_G = -log D(G(z))`. Это *ненасыщающаяся* форма, использованная Гудфеллоу (исходная `log(1 - D(G(z)))` насыщается и убивает градиенты, когда `D` уверен в своём решении).

**Цикл обучения.** Один шаг для `D`, один шаг для `G`. Повторять.

**Почему это работает.** Если `G` в точности соответствует `p_data`, то `D` не может действовать лучше случайного угадывания и выдаёт 0.5 везде; `G` больше не получает градиента. Равновесие.

**Почему это ломается.** Коллапс мод (`G` находит одну моду, которую `D` не может классифицировать, и чеканит её бесконечно), затухающий градиент (`D` обучается слишком быстро, и `log D` насыщается), нестабильность обучения (скорости обучения, размеры батчей, что угодно).

## Реализация

`code/main.py` обучает крошечный GAN на одномерных данных: смеси двух гауссиан. Генератор и дискриминатор — однослойные MLP со скрытым слоем. Мы реализуем прямой проход, обратный проход и цикл минимакс вручную. Цель — увидеть, как возникают два ключевых режима отказа (коллапс мод + затухающий градиент).

### Шаг 1: ненасыщающаяся функция потерь

Исходная функция потерь Гудфеллоу `log(1 - D(G(z)))` стремится к 0, когда D классифицирует подделку G как подделку с высокой уверенностью. В этот момент градиент для G практически равен нулю — G не может улучшаться. Ненасыщающаяся форма `-log D(G(z))` имеет противоположную асимптоту: она резко возрастает, когда D уверен, давая G сильный сигнал.

```python
def g_loss(d_fake):
    # maximize log D(G(z))  <=>  minimize -log D(G(z))
    return -sum(math.log(max(p, 1e-8)) for p in d_fake) / len(d_fake)
```

### Шаг 2: один шаг дискриминатора на каждый шаг генератора

```python
for step in range(steps):
    # train D
    real_batch = sample_real(batch_size)
    fake_batch = [G(z) for z in sample_noise(batch_size)]
    update_D(real_batch, fake_batch)

    # train G
    fake_batch = [G(z) for z in sample_noise(batch_size)]  # fresh fakes
    update_G(fake_batch)
```

Свежие подделки для G, иначе градиенты устаревают.

### Шаг 3: отслеживание коллапса мод

```python
if step % 200 == 0:
    samples = [G(z) for z in sample_noise(500)]
    mode_a = sum(1 for s in samples if s < 0)
    mode_b = 500 - mode_a
    if min(mode_a, mode_b) < 50:
        print("  [!] mode collapse: one mode is starved")
```

Канонический симптом: одна из двух реальных мод перестаёт генерироваться. Дискриминатор перестаёт её корректировать, потому что никогда не видит её как подделку.

## Подводные камни

- **Дискриминатор слишком силён.** Снизьте скорость обучения D в 2-5 раз или добавьте шум на уровне инстанса/слоя. Если D достигает точности >95%, G мёртв.
- **Генератор запоминает одну моду.** Добавьте шум ко входам D, используйте слой minibatch-дискриминации или переключитесь на WGAN-GP.
- **Утечка статистики через батч-норм.** Реальный батч и поддельный батч, проходящие через один и тот же слой BN, смешивают свою статистику. Используйте вместо этого инстанс-норм или спектральную норм.
- **Игра с Inception Score.** FID и IS зашумлены при малом числе сэмплов. Используйте ≥10k сэмплов при оценке.
- **Однократная генерация — это ложь для условных задач.** Вам всё равно нужны масштабы CFG, трюки усечения и повторная генерация для получения пригодных результатов.

## Применение

Стек GAN 2026 года:

| Ситуация | Выбор |
|-----------|------|
| Фотореалистичные человеческие лица, фиксированная поза | StyleGAN3 (самый чёткий, самый компактный) |
| Аниме / стилизованные лица | StyleGAN-XL или Stable Diffusion LoRA |
| Перевод изображения в изображение | Pix2Pix / CycleGAN (Phase 8 · 04) или ControlNet (Phase 8 · 08) |
| Быстрая 1-шаговая генерация текста в изображение | Состязательная дистилляция диффузии (SDXL-Turbo, SD3-Turbo) |
| Перцептивная функция потерь внутри тренера диффузии | Небольшой дискриминатор GAN на кропах изображения |
| Что угодно мультимодальное, открытого формата | Не используйте GAN — используйте диффузию или flow matching |

GAN чёткие, но узкие. Как только ваш домен расширяется — фотографии, произвольные текстовые промпты, видео — переходите на диффузию. Состязательный трюк продолжает жить как компонент (перцептивные функции потерь, дистилляция), а не как самостоятельный генератор.

## Ключевые термины

| Термин | Как говорят | Что это на самом деле значит |
|------|-----------------|-----------------------|
| Генератор | «G» | Сеть от шума к сэмплу, `G: z → x̂`. |
| Дискриминатор | «D» | Классификатор `D: x → [0, 1]`, реальное против поддельного. |
| Минимакс | «Игра» | `min_G max_D` совместной целевой функции. |
| Ненасыщающаяся функция потерь | «Исправление» | Используйте `-log D(G(z))` для G вместо `log(1 - D(G(z)))`. |
| Коллапс мод | «G запомнил одну вещь» | Генератор производит мало различимых выходов, несмотря на разнообразие данных. |
| WGAN | «Вассерштейн» | Замена BCE на расстояние Земного Движения (Earth-Mover) + градиентный штраф; более гладкий градиент. |
| Спектральная норм | «Трюк Липшица» | Ограничение норм весов D для ограничения его наклона; стабилизирует обучение. |
| StyleGAN | «Тот, что работает» | Отображающая сеть + AdaIN; лучший в своём классе для лиц, актуален до сих пор в 2026 году. |

## Заметка о продакшне: одношаговый инференс — долговременное преимущество GAN

GAN больше не выигрывают по качеству сэмплов для генерации открытого домена, но они по-прежнему выигрывают по стоимости инференса. В терминологии литературы по производственному инференсу GAN обладает:

- **Нет стадий prefill и decode.** Единственный прямой проход `G(z)`. TTFT ≈ общая задержка.
- **Нет давления на KV-кэш.** Единственное состояние — это веса. Размер батча ограничен памятью активаций, а не кэшем.
- **Тривиальный непрерывный батчинг.** Поскольку каждый запрос требует одинакового фиксированного числа FLOPs, статический батч при целевой загрузке сервера обычно оптимален. Планировщик "на лету" не нужен.

Именно поэтому дистилляция GAN (SDXL-Turbo, SD3-Turbo, ADD, LCM) является доминирующей техникой для быстрой генерации текста в изображение в 2026 году: она сжимает диффузионный конвейер из 20-50 шагов в 1-4 прямых прохода в стиле GAN, сохраняя при этом распределение базовой диффузионной модели. Состязательная функция потерь продолжает существовать как настраиваемый параметр во время обучения для превращения медленных генераторов в быстрые.
