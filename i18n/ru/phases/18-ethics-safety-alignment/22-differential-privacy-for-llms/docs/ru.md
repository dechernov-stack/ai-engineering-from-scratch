# Дифференциальная приватность для LLM

> DP-SGD остаётся стандартом — обновления градиентов с добавлением шума дают формальные гарантии (epsilon, delta). Издержки по вычислениям, памяти и полезности существенны; параметрически эффективная DP-дообучение (LoRA + DP-SGD) — типичная конфигурация 2025 года (ACM 2025). Два массива свидетельств находятся в противоречии: атаки на принадлежность на основе канареек (Duan et al., 2024) сообщают об ограниченном успехе против языковых моделей; извлечение обучающих данных (Carlini et al., 2021; Nasr et al., 2025) восстанавливает значительный объём дословного запоминания. Разрешение (arXiv:2503.06808, март 2025 года): разрыв заключается в том, что именно измеряется — вставленные канарейки против "наиболее извлекаемых" данных. Новые конструкции канареек позволяют проводить MIA на основе функции потерь без теневых моделей и дают первый нетривиальный DP-аудит LLM, обученной на реальных данных, с реалистичными DP-гарантиями. Альтернативы: PMixED (arXiv:2403.15638) — приватное предсказание на этапе инференса через смесь экспертов на распределениях следующего токена; генерация DP-синтетических данных (Google Research, 2024). Новая атака: разворот дифференциальной приватности через обратную связь LLM — утечка через оценки уверенности.

## The Problem

LLM запоминают. Carlini et al. 2021 показали, что промышленные языковые модели воспроизводят дословный обучающий текст по запросу. DP — формальная защита: обучение, при котором результат доказуемо нечувствителен к любому отдельному обучающему примеру. Свидетельства 2024-2025 годов показывают, что DP-SGD необходим, но развёрнутые значения ε могут не соответствовать модели угроз.

## The Concept

### (ε, δ)-дифференциальная приватность

Рандомизированный алгоритм M является (ε, δ)-DP, если для любых двух наборов данных, различающихся одним примером, и любого события S:
P(M(D) in S) <= e^ε * P(M(D') in S) + δ.

Интерпретация: распределение выходных данных достаточно близко (параметризовано ε), чтобы вклад любого отдельного индивида нельзя было достоверно определить, за исключением вероятности δ.

### DP-SGD

Abadi et al. 2016. Стандартный рецепт:
1. Выбрать мини-пакет.
2. Вычислить поэкземплярные градиенты.
3. Обрезать каждый поэкземплярный градиент до порога C.
4. Суммировать обрезанные градиенты и добавить гауссовский шум со стандартным отклонением σ * C.
5. Использовать зашумлённую сумму для обновления параметров.

Приватностная стоимость отслеживается аккаунтантом (Moments Accountant, Rényi DP accountant). Сообщаемые значения ε в литературе по LLM сильно варьируются в зависимости от модели угроз, чувствительности данных и целевой полезности; универсально "безопасного" значения ε по умолчанию не существует. Опубликованные примеры охватывают примерно диапазон ε ≈ 1–10 в некоторых сценариях обучения LLM, но это иллюстративные значения, а не рекомендуемые настройки по умолчанию. Меньшее ε, как правило, требует больше шума и может увеличивать потерю полезности.

### LoRA + DP-SGD

Полный DP-SGD для передовой модели непомерно дорог. LoRA (Hu et al. 2022) ограничивает обновления градиентов небольшим адаптером, снижая объём хранения поэкземплярных градиентов. LoRA + DP-SGD — типичная конфигурация 2025 года. DP-гарантии применяются к адаптеру; базовая модель остаётся фиксированной.

### Противоречие 2024-2025 годов

Два направления свидетельств:

- **MIA на основе канареек (Duan et al. 2024).** Вставка уникальных канареек в обучающие данные, измерение способности атакующего, использующего атаку на принадлежность, их идентифицировать. Сообщается об ограниченном успехе на языковых моделях. Предполагает, что MIA затруднена.
- **Извлечение обучающих данных (Carlini 2021, Nasr et al. 2025).** Запрос модели с префиксом; измерение того, восстанавливает ли она дословный текст из обучения. Сообщается о значительном запоминании. Предполагает, что MIA проста в соответствующем смысле.

Разрешение в марте 2025 года (arXiv:2503.06808): эти два подхода измеряют разные вещи. MIA задаёт вопрос "присутствует ли пример e в D?" на вставленных канарейках. Извлечение задаёт вопрос "что я могу восстановить из D?" Для приватности важен "наиболее извлекаемый" пример; канарейки занижают эту оценку, поскольку не оптимизированы для извлекаемости.

Новые конструкции канареек. MIA на основе функции потерь без теневых моделей. Первый нетривиальный DP-аудит LLM на реальных данных с реалистичными DP-гарантиями.

### Альтернативы DP-обучению

- **PMixED (arXiv:2403.15638).** Приватное предсказание на этапе инференса. Смесь экспертов на распределениях следующего токена; каждый эксперт видит фрагмент обучающих данных; агрегация добавляет шум для DP. Полностью избегает DP-обучения.
- **Генерация DP-синтетических данных (Google Research, 2024).** DP-SGD-дообучение LoRA, выборка синтетических данных, обучение последующего классификатора на синтетических данных.

Оба подхода обходят издержку полезности полного DP-обучения ценой другой модели угроз.

### Разворот дифференциальной приватности через обратную связь LLM

Новая атака 2025 года. Использование оценок уверенности DP-обученной модели в качестве оракула для повторной идентификации индивидов. Даже если выходные данные не раскрываются, распределения уверенности могут это делать.

Защита: не раскрывать оценки уверенности или усекать/квантовать их перед раскрытием. Это дополнительное требование помимо (ε, δ)-DP-обучения.

## Use It

`code/main.py` моделирует DP-SGD на игрушечном наборе данных для бинарной классификации. Вы можете варьировать множитель шума σ и норму обрезки C и отслеживать бюджет (ε, δ) и издержки точности. ## Key Terms

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| DP | "(ε, δ)-дифференциальная приватность" | Формальная приватность: распределение выходных данных близко при изменении соседнего набора данных |
| DP-SGD | "SGD с внедрением шума" | Обрезка градиента + добавление гауссовского шума; стандартное DP-обучение |
| LoRA + DP-SGD | "эффективное приватное дообучение" | DP-SGD на низкоранговых адаптерах; стандартная конфигурация 2025 года |
| MIA | "атака на принадлежность" | Атака, определяющая, был ли пример в обучающих данных |
| Canary | "вставленный пример-метка" | Уникальный обучающий пример, используемый для измерения утечки DP |
| PMixED | "смесь для приватного инференса" | DP на этапе инференса через смесь экспертов на распределениях следующего токена |
| DP Reversal | "атака через утечку уверенности" | Атака, использующая уверенность модели как оракул для повторной идентификации |
