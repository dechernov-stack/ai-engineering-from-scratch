# CLIP и контрастивное предобучение зрение-язык

> OpenAI's CLIP (2021) доказал идею, достаточно масштабную, чтобы питать следующие пять лет: выровнять энкодер изображений и энкодер текста в одном векторном пространстве, используя только зашумлённые пары изображение-подпись из веба и контрастивную функцию потерь. Ноль размеченных данных с учителем. 400 млн пар. Полученное пространство эмбеддингов решает zero-shot классификацию, retrieval изображение-текст и встраивается в каждую VLM 2026 года как её зрительная башня (vision tower). SigLIP 2 (2025) заменил softmax на sigmoid и превзошёл CLIP по масштабу при меньшей стоимости. Этот урок проходит математику от InfoNCE до sigmoid попарной функции потерь и строит шаг обучения на stdlib Python.

**Type:** Build

## Проблема

До-CLIP-эра зрения была с учителем. Собери размеченные датасеты (ImageNet: 1.2 млн изображений, 1000 классов), обучи CNN, выпусти. Метки дороги, метки смещены в сторону того, с чем могут согласиться разметчики, и метки не переносятся на новые задачи без дообучения.

В веб-сети изображение-подпись бесплатно доступно более одного миллиарда слабо размеченных пар. Фотография золотистого ретривера с alt-текстом "мой пёс Макс в парке" несёт сигнал надзора — текст описывает изображение. Вопрос: можно ли превратить это в полезное обучение?

Ответ CLIP: трактовать пары изображение-подпись как задачу сопоставления. Дан батч из N изображений и N подписей, научись сопоставлять каждое изображение с его собственной подписью против N-1 отвлекающих вариантов. Сигнал надзора: "эти две вещи принадлежат друг другу; эти N-1 — нет." Никаких меток классов. Никакой человеческой аннотации. Только контрастивная функция потерь.

Получившееся пространство эмбеддингов делает больше, чем то, для чего CLIP был обучен. Zero-shot на ImageNet работает, потому что "a photo of a cat" встраивается рядом с изображениями кошек, которые никогда явно не были помечены как кошки. Это та ставка, которая породила каждую VLM 2026 года.

## Концепция

### Двойной энкодер

У CLIP две башни:

- Энкодер изображений `f`: ViT или ResNet, выдаёт D-мерный вектор на изображение.
- Текстовый энкодер `g`: небольшой трансформер, выдаёт D-мерный вектор на подпись.

Обе башни нормализуют свои выходы до единичной длины. Сходство — это `cos(f(x), g(y)) = f(x)^T g(y)`, поскольку оба вектора единичной нормы.

Для батча из N пар (изображение, подпись) строится матрица сходства `S` формы `(N, N)`:

```
S[i, j] = cos(f(x_i), g(y_j)) / tau
```

где `tau` — обучаемая температура (CLIP инициализирует значением 0.07; обучается в логарифмическом пространстве).

### Функция потерь InfoNCE

CLIP использует симметричную кросс-энтропию по строкам и столбцам:

```
loss_i2t = CE(S, labels=identity)     # each image's positive is its own caption
loss_t2i = CE(S^T, labels=identity)   # each caption's positive is its own image
loss = (loss_i2t + loss_t2i) / 2
```

Это и есть InfoNCE. Softmax в CE заставляет каждое изображение соответствовать своей подписи сильнее, чем любой другой подписи в батче. "Негативы" — это все остальные элементы батча. Больше батч = больше негативов = сильнее сигнал. CLIP обучался с батчем 32k; масштаб имеет значение.

### Температура

`tau` контролирует резкость softmax. Низкий tau → резкое распределение, эффект майнинга трудных негативов. Высокий tau → мягкое, все сэмплы вносят вклад. CLIP обучает log(1/tau), с клиппингом для предотвращения коллапса. SigLIP 2 фиксирует начальный tau и вместо этого использует обучаемое смещение (bias).

### Почему sigmoid масштабируется лучше (SigLIP)

Softmax требует синхронизации всей матрицы сходства. В распределённом обучении нужно собрать все эмбеддинги (all-gather) на каждую реплику, а затем выполнить softmax. Это квадратичная зависимость от размера мира (world size) по коммуникации.

SigLIP заменяет softmax поэлементным sigmoid: для каждой пары `(i, j)` функция потерь — это бинарная классификация "являются ли эти элементы совпадающей парой?", метки положительного класса — диагональ, всё остальное — негатив. Функция потерь:

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

`y_ij = 1` если `i == j`, иначе 0. Потери каждой пары независимы. All-gather не нужен. Каждый GPU вычисляет свой локальный блок и суммирует. SigLIP 2 масштабируется до батча 32k-512k дёшево там, где CLIP потребовал бы пропорционально больше коммуникации.

### Zero-shot классификация

Дано N имён классов, для каждого класса строится текстовый шаблон:

```
"a photo of a {class}"
```

Встрой каждый шаблон текстовым энкодером. Встрой своё изображение энкодером изображений. Argmax косинусного сходства = предсказанный класс. Без обучения на целевых классах.

Шаблоны промптов имеют значение. Оригинальная статья CLIP использовала 80 шаблонов на класс (простой, художественный, фото, картина и т.д.) и усредняла эмбеддинги. +3 пункта по ImageNet. Современное использование обычно выбирает один-два шаблона.

### Линейные зонды и дообучение

Zero-shot — это базовая линия. Линейный зонд (обучение одного линейного слоя поверх замороженных признаков CLIP для ваших целевых классов) превосходит zero-shot на in-domain задачах. Полное дообучение превосходит линейный зонд на in-domain, но может навредить zero-shot переносу. Три режима с тремя компромиссами.

### SigLIP 2: NaFlex и плотные признаки

SigLIP 2 (2025) добавляет:
- NaFlex: единая модель обрабатывает переменные соотношения сторон и разрешения.
- Более качественные плотные признаки для сегментации и оценки глубины, нацеленные на использование в качестве замороженного backbone в VLM.
- Многоязычность: обучена на 100+ языках, тогда как CLIP был только англоязычным.
- Масштаб до 1 млрд параметров, тогда как CLIP достигал максимума в 400 млн.

В открытых VLM 2026 года SigLIP 2 SO400m/14 — дефолтная зрительная башня. CLIP остаётся дефолтом для чистого retrieval изображение-текст, где конкретное распределение обучения LAION-2B соответствует паттерну ваших запросов.

### ALIGN, BASIC, OpenCLIP, EVA-CLIP

ALIGN (Google, 2021): та же идея, что и у CLIP, масштаб 1.8 млрд пар, 90% зашумлённости. Доказал, что зашумлённые данные масштабируются. OpenCLIP (LAION): открытая репродукция CLIP на LAION-400M / 2B, несколько масштабов, основной открытый чекпоинт. EVA-CLIP: инициализируется из masked image modeling; сильный backbone для VLM. BASIC: гибрид CLIP+ALIGN от Google. Всё одно семейство, разные данные и тюнинг.

### Потолок zero-shot

Модели класса CLIP упираются примерно в 76% zero-shot на ImageNet (CLIP-G, OpenCLIP-G). Превысить это требует либо значительно больших данных (SigLIP 2 получает 80%+), либо архитектурных изменений (supervised-головы, больше параметров). Бенчмарк насыщается; реальная ценность — пространство эмбеддингов, которое потребляют downstream VLM.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|----------------|------------------------|
| InfoNCE | "Контрастивная функция потерь" | Кросс-энтропия по матрице сходства батча; позитив каждого элемента — его парный элемент, негативы — всё остальное |
| Sigmoid loss | "Функция потерь SigLIP" | Попарная бинарная кросс-энтропия; без softmax, без all-gather, дёшево масштабируется в распределённом обучении |
| Температура | "tau" | Скаляр, масштабирующий логиты перед softmax/sigmoid; контролирует резкость распределения |
| Zero-shot | "классификация без дообучения" | Использование текстовых промптов для построения эмбеддингов классов и классификация по косинусному сходству; без обучения на целевых классах |
| Шаблон промпта | "a photo of a ..." | Текстовый каркас вокруг имени класса; влияет на точность zero-shot на 1-5 пунктов |
| Двойной энкодер | "Two-tower" | Один энкодер изображений + один текстовый энкодер, выходы в общем D-мерном пространстве |
| Трудный негатив | "Сложный отвлекающий вариант" | Негатив, достаточно похожий на позитив, что модели приходится потрудиться, чтобы их разделить |
| Линейный зонд | "Заморожено + один слой" | Обучение только линейного классификатора поверх замороженных признаков; измеряет качество признаков |
| NaFlex | "Нативное гибкое разрешение" | Способность SigLIP 2 принимать изображения любого соотношения сторон и разрешения без изменения размера |
| Масштабирование температуры | "tau в лог-параметризации" | CLIP параметризует `log(1/tau)`, чтобы градиенты вели себя корректно; клиппинг предотвращает коллапс к почти-нулевому tau |
