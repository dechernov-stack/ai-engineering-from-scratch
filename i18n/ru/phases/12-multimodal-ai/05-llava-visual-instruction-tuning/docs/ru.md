# LLaVA и Visual Instruction Tuning

> LLaVA (апрель 2023) — самая копируемая мультимодальная архитектура на планете. Она заменила Q-Former из BLIP-2 на 2-слойный MLP, заменила gated cross-attention из Flamingo на наивную конкатенацию токенов и обучалась на 158 тыс. инструктивных диалогах, сгенерированных GPT-4 на основе текстовых подписей. Любой практик, строивший VLM в период с 2023 по 2026 год, строил тот или иной вариант LLaVA. LLaVA-1.5 добавила AnyRes. LLaVA-NeXT повысила разрешение. LLaVA-OneVision объединила изображение, несколько изображений и видео в одном рецепте. Этот урок разбирает этот рецепт, реализует проектор и объясняет, почему «победила простота».

**Type:** Build
**Languages:** Python (stdlib, проектор + конструктор шаблона инструкций)
**Prerequisites:** Phase 12 · 02 (CLIP), Phase 11 (LLM Engineering — instruction tuning)
**Time:** ~180 минут

## Learning Objectives

- Построить 2-слойный MLP-проектор, отображающий эмбеддинги патчей ViT (размерность 1024) в размерность эмбеддингов LLM (размерность 4096).
- Пройти по двухэтапному рецепту LLaVA: (1) выравнивание проектора на 558 тыс. пар подпись-изображение, (2) visual instruction tuning на 158 тыс. диалогах, сгенерированных GPT-4.
- Сконструировать промпт в формате LLaVA с плейсхолдером токена изображения, системным промптом и репликами пользователя/ассистента.
- Объяснить, почему сообщество перешло от Q-Former к MLP, несмотря на выигрыш Q-Former по бюджету токенов.

## The Problem

Q-Former из BLIP-2 (урок 12.03) сжимает изображение до 32 токенов. Чисто, эффективно, хорошо для бенчмарков. Но у него есть две проблемы.

Во-первых, Q-Former обучаем, но его функция потерь — не финальная задача. Этап 1 обучает ITC+ITM+ITG. Этап 2 обучает LM loss. Запросы (queries) учатся некоторому промежуточному представлению, которое затем должен декодировать LLM. Информация теряется в узком месте (bottleneck).

Во-вторых, Q-Former содержит 188M параметров, и при масштабе LLaVA 2023 года его приходилось совместно проектировать с целевым LLM. Меняешь LLM — переобучаешь Q-Former. Меняешь vision-энкодер — переобучаешь снова. Каждая комбинация была отдельным исследовательским проектом.

Ответ LLaVA был до смешного прост: взять 576 токенов патчей ViT, пропустить каждый через 2-слойный MLP (`1024 → 4096 → 4096`) и вставить все 576 во входную последовательность LLM. Никакого узкого места. Никакого этапа 1 предобучения на странных задачах. Просто обучить MLP напрямую на LM loss.

Откуда берутся данные? Второе озарение LLaVA: использовать GPT-4 (только текст) для генерации инструктивных данных. Подать GPT-4 подписи COCO и данные bounding-box для изображения, попросить сгенерировать диалоги, описания и вопросы со сложным рассуждением. 158 тыс. пар инструкция-ответ бесплатно. Без человеческой разметки.

Результат: VLM, которая обучалась на 8 A100 за один день, превзошла Flamingo на MMMU и выпустила открытый чекпоинт, который сообщество могло расширять. К концу 2023 года от неё отпочковалось более 50 форков.

## The Concept

### The architecture

LLaVA-1.5 на 13B:
- Vision-энкодер: CLIP ViT-L/14 @ 336 (заморожен на этапе 1, опционально разморожен на этапе 2).
- Проектор: 2-слойный MLP с активацией GELU, `1024 → 4096 → 4096`.
- LLM: Vicuna-13B (позже Llama-3.1-8B).

Прямой проход по изображению + текстовому промпту:

```
img -> ViT -> 576 patches of dim 1024
patches -> MLP -> 576 tokens of dim 4096
prompt: system + "<image>" placeholder + user question
replace <image> token with the 576 projected tokens
feed the full sequence to the LLM
decode response
```

Изображение занимает 576 токенов контекста LLM. При контексте 2048 это оставляет 1472 токена на текст. При контексте 32k это округление до погрешности.

### Stage 1: выравнивание проектора

Заморозить ViT. Заморозить LLM. Обучать только 2-слойный MLP. Датасет: 558 тыс. пар изображение-подпись (LAION-CC-SBU). Loss: языковое моделирование подписи, обусловленное спроецированными токенами изображения.

За одну эпоху при batch 128 это занимает несколько часов. Проектор учится отображать ViT-пространство в пространство LLM. Без специфической для задачи супервизии.

### Stage 2: visual instruction tuning

Разморозить проектор (по-прежнему обучаемый). Разморозить LLM (обычно полностью, иногда через LoRA). Обучать на 158 тыс. визуально-инструктивных диалогах.

Инструктивные данные — это и есть ключевой приём. Liu et al. сгенерировали их так:
1. Взять изображение COCO.
2. Извлечь текстовое описание (5 подписей от людей + список bounding-box).
3. Отправить в GPT-4 с тремя шаблонами промптов:
   - Диалог: «Сгенерируй диалог туда-обратно между пользователем и ассистентом об этом изображении».
   - Подробное описание: «Дай насыщенное, подробное описание изображения».
   - Сложное рассуждение: «Задай вопрос, требующий рассуждения об изображении, затем ответь на него».
4. Распарсить вывод GPT-4 в пары (инструкция, ответ).

Ничто из этого не касается изображения напрямую — только текстового описания. GPT-4 галлюцинирует правдоподобное содержание изображения. Есть шум, но это сработало: 158 тыс. диалогов оказалось достаточно, чтобы разблокировать диалоговые способности.

### Why the community copied this

- Нет специфичных для этапа 1 функций потерь для настройки. LM loss на всём протяжении.
- Проектор обучается за часы, а не за дни.
- LLM можно заменить (LLaVA-Llama2, LLaVA-Mistral, LLaVA-Llama3), переобучив только проектор.
- Пайплайн визуально-инструктивных данных использует GPT-4 и дёшево регенерируется для новой области.

### LLaVA-1.5 and LLaVA-NeXT

LLaVA-1.5 (октябрь 2023) добавила:
- Данные академических задач (VQA, OKVQA, RefCOCO), смешанные в instruction tuning.
- Улучшенный системный промпт.
- Контекст 2048 → 32k.

LLaVA-NeXT (январь 2024) добавила:
- AnyRes: разбиение изображений высокого разрешения на сетку 2x2 или 1x3 кропов 336x336, плюс одна глобальная миниатюра низкого разрешения. Каждый кроп становится 576 токенами; всего около 2880 визуальных токенов на изображение. Задачи OCR и работы с графиками резко улучшились.
- Лучшая смесь инструктивных данных с ShareGPT4V (высококачественные подписи от GPT-4V).
- Более сильные базовые LLM (Mistral-7B, Yi-34B).

### LLaVA-OneVision

Урок 12.08 подробно разбирает OneVision. Кратко: тот же проектор, но обучен по учебному плану (curriculum), который охватывает одно изображение, несколько изображений и видео в одной модели с общим бюджетом визуальных токенов.

### The comparison to Q-Former

| | Q-Former (BLIP-2) | MLP (LLaVA) |
|---|---|---|
| Визуальных токенов на изображение | 32 | 576 (базово) или 2880 (AnyRes) |
| Обучаемые параметры | 188M + LM | 40M + LM |
| Loss на этапе 1 | ITC+ITM+ITG | Только LM |
| Подключение нового LLM | Требует переобучения | Замена с минимальным переобучением |
| Мультиизображение | Неудобно | Естественно (конкатенация) |
| Видео | Неудобно | Естественно (конкатенация по кадрам) |
| Бюджет токенов | Малый | Большой |

MLP выигрывает по простоте и гибкости бюджета токенов. Q-Former выигрывает по бюджету токенов. К концу 2023 года бюджет токенов перестал быть связывающим ограничением (контексты LLM выросли до 32k-128k+), и простота победила.

### The prompt format

```
A chat between a curious human and an artificial intelligence assistant. The assistant gives helpful, detailed, and polite answers to the human's questions. USER: <image> Describe this image in detail. ASSISTANT: The image shows ...
```

`<image>` — это токен-плейсхолдер. Перед токенизацией он заменяется на 576 визуальных токенов (или 2880 при AnyRes). Токенизатор видит последовательность немного длиннее той, на которой он обучался, но LLM справляется с новым входом, потому что этап 1 научил его этому.

### Parameter economy

Разбивка LLaVA-1.5-7B:
- CLIP ViT-L/14 @ 336: 303M (заморожен на этапе 1, часто разморожен на этапе 2).
- Проектор (2x linear): ~22M обучаемых.
- Llama-7B: 7B.
- Всего: 7.3B параметров. Обучаемо на этапе 2: полные 7B + 22M проектора.

Стоимость обучения для этапа 2: ~20 часов на 8xA100. Это ключевая цифра — один день, одна нода, воспроизводимо. Именно поэтому LLaVA так широко распространилась.

## Use It

`code/main.py` реализует:

1. 2-слойный MLP-проектор (размерность 16 → 32 → 32 для игрушечного масштаба) на чистом Python.
2. Пайплайн построения промпта: системный промпт + `<image>`, заменённый на N спроецированных токенов + реплика пользователя + плейсхолдер генерации ассистента.
3. Визуализатор того, как выглядит 576-токенный визуальный блок в контексте LLM (процент потребляемого контекста из 2k / 32k / 128k).

## Ship It

Этот урок создаёт `outputs/skill-llava-vibes-eval.md`. Для заданного чекпоинта семейства LLaVA он запускает набор из 10 промптов на «вайб-проверку» (3 подписи, 3 VQA, 2 рассуждения, 2 отказа) и выдаёт читаемую человеком оценочную карту. Это не бенчмарк, а дымовой тест (smoke test), подтверждающий, что проектор и LLM хорошо соединены.

## Exercises

2. Постройте промпт LLaVA для случая «отказа» — изображение содержит частное лицо. Напишите ожидаемый ответ ассистента. Почему LLaVA должна отказаться от этого zero-shot и какие обучающие данные понадобились бы для закрепления такого отказа?

3. Прочитайте раздел об AnyRes в блоге LLaVA-NeXT. Вычислите число визуальных токенов для изображения 1344x672 при AnyRes. Сравните с базовыми 576 токенами при 336x336.

4. Проектор LLaVA на этапе 1 обучается с LM loss на подписях. Что происходит, если пропустить этап 1 и сразу перейти к этапу 2 (visual instruction tuning)? Приведите цитату из абляции Prismatic VLMs (arXiv:2402.07865) в качестве ответа.

5. LLaVA-Instruct-150k использует GPT-4 с подписями COCO для генерации инструкций. Для новой области (рентгеновские снимки, спутниковые изображения) опишите четырёхшаговый пайплайн данных для генерации доменных инструкций. Что может пойти не так на каждом шаге?

## Key Terms

| Термин | Как говорят люди | Что это на самом деле означает |
|------|----------------|------------------------|
| Проектор | «MLP-мост» | 2-слойный MLP с GELU, отображающий размерность ViT в размерность LLM |
| Токен изображения | «плейсхолдер <image>» | Маркер в промпте, заменяемый N спроецированными визуальными токенами перед инференсом |
| Visual instruction tuning | «этап 2 LLaVA» | Обучение на тройках (изображение, инструкция, ответ), сгенерированных GPT-4 |
| Выравнивание этапа 1 | «предобучение проектора» | Заморозить ViT и LLM, обучить проектор с LM loss на подписях |
| AnyRes | «тайлинг с несколькими кропами» | Разбиение изображения высокого разрешения на сетку тайлов с конкатенацией визуальных токенов каждого тайла |
| LLaVA-Instruct | «сгенерировано GPT-4» | 158 тыс. пар инструкция-ответ, синтезированных из подписей COCO + GPT-4 |
| Заморозка vision-энкодера | «бэкбон заблокирован» | Веса CLIP не обновляются на этапе 1, иногда и на этапе 2 тоже |
| ShareGPT4V | «лучшие подписи» | 1M насыщенных подписей, сгенерированных GPT-4V, используемых для более качественного выравнивания |
| VQA | «визуальный вопрос-ответ» | Задача ответа на вопрос в свободной форме об изображении |
| Prismatic VLMs | «статья о пространстве дизайна» | Абляция Karamcheti 2024, систематически тестирующая выбор проектора и данных |
