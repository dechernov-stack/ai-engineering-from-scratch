# Мультимодальный RAG и кросс-модальный поиск

> Vision-native document RAG — это лишь один из срезов. Промышленный мультимодальный RAG работает шире — ведя поиск по тексту, изображениям, аудио и видео для таких сценариев, как планирование поездки («найди мне тихий веганский бранч с естественным освещением»), медицинская триаж-диагностика («какой травме соответствует это фото + эти записи»), электронная коммерция («наряды, похожие на это селфи, моего размера») и выездное обслуживание («диагностировать этот звук двигателя плюс фото детали»). Три обзора 2025 года — Abootorabi et al., Mei et al., Zhao et al. — систематизировали подзадачи: кросс-модальный поиск, слияние результатов поиска (fusion), обоснование генерации (grounding), мультимодальная оценка. Этот урок разбирает эти обзоры и проектирует промышленный пайплайн.

## The Problem

Одномодальный RAG — это решённый паттерн: закодировать запрос, закодировать фрагменты, найти, подать в LLM. Мультимодальный RAG требует:

1. Нескольких «голов» поиска (каждой модальности нужны эмбеддинги в совместимом пространстве).
2. Слияния результатов поиска по модальностям.
3. Обоснования генерации, которое цитирует источники разных модальностей.
4. Метрик оценки, покрывающих кросс-модальный сигнал.

Все обзоры 2025 года приходят к одной и той же таксономии.

## The Concept

### Кросс-модальный поиск

Поиск документов модальности B по запросу модальности A. Три паттерна:

1. Общее пространство эмбеддингов. CLIP и CLAP производят эмбеддинги текст + изображение / текст + аудио в общем пространстве. Косинусное сходство между модальностями работает напрямую. Ограничено парами, на которых обучен CLIP.

2. Отдельный энкодер на модальность + переводчик. Текстовый энкодер + энкодер изображений + небольшой модуль-переводчик, отображающий одно пространство в другое. Sen2Sen авторов Gupta et al. и другие решения 2024 года. Гибко, но добавляет сложность.

3. VLM как энкодер. Использовать скрытые состояния VLM как представление для поиска. Подходит любая модальность, которую поддерживает VLM. Более высокое качество, но дороже.

Выбор: CLIP / SigLIP 2 для текст+изображение; CLAP для текст+аудио; скрытые состояния VLM для кросс-модального поиска на передовом уровне качества.

### Стратегии fusion

Вы получили 10 результатов: 5 изображений, 3 текстовых фрагмента, 2 аудиоклипа. Как их объединить?

Score fusion (самый дешёвый вариант). У каждой модальности свой retriever, каждый возвращает оценки (scores). Нормализуйте оценки внутри модальности, затем суммируйте. Просто, часто работает.

Fusion на основе внимания. Конкатенируйте все найденные элементы, пусть небольшая attention-сеть взвесит их. Требует обучения.

MoE fusion. Gating-сеть направляет данные к экспертам, специфичным для модальности. Разные типы запросов маршрутизируются по-разному — визуальный вопрос придаёт больший вес изображениям.

Вариант по умолчанию в продакшене: score fusion с лёгким смещением в сторону доминирующей модальности запроса. Переходите на MoE, если A/B-тестирование показывает явный выигрыш в вашей предметной области.

### Обоснование генерации

LLM должна указывать, какой из найденных элементов стал источником каждого утверждения. Для мультимодального случая:

- Текстовый источник: стандартная цитата `[1]`.
- Источник-изображение: `[img 3]` с короткой подписью.
- Аудио: `[audio 2 at 0:34]`.

Обучайте генератор на данных с учётом обоснования: каждое утверждение в обучающей цели помечено индексом источника. На этапе вывода модель естественным образом выдаёт цитаты.

### Обзоры 2025 года

Abootorabi et al. (arXiv:2502.08826, «Ask in Any Modality»): таксономия мультимодального RAG. Охватывает поиск, fusion, генерацию. Самое широкое покрытие.

Mei et al. (arXiv:2504.08748, «A Survey of Multimodal RAG»): фокус на бенчмарках для подзадач и видах отказов. Полезен для проектирования оценки.

Zhao et al. (arXiv:2503.18016): обзор с фокусом на визуальной модальности. Сильная сторона — работы семейства ColPali.

Прочтение всех трёх даёт представление о состоянии дел на весну 2025 года. Большинство подзадач всё ещё остаются открытыми.

### MuRAG — основополагающая статья

MuRAG (Chen et al., 2022) был первым мультимодальным RAG. Извлекал изображение + текст из мультимодальной базы знаний, генерировал ответы. Показал осуществимость концепции ещё до волны VLM. Современные системы (REACT, VisRAG, M3DocRAG) строятся на его основе.

### Пример промышленного планировщика поездок

Запрос: «найди мне тихий веганский бранч с естественным освещением».

Пайплайн:

1. Разложение запроса. «тихий» → ключевое слово для аудио/отзывов; «веганский бранч» → пункт меню; «естественное освещение» → признак изображения.
2. Поиск по модальностям:
   - Текстовый поиск по отзывам: «веганский бранч, тихая атмосфера».
   - Поиск по изображениям ресторанов: «естественное освещение, воздушно».
   - Аудиопоиск по клипам с окружающим звуком: «низкая громкость в децибелах, без музыки».
3. Слияние оценок. У каждого ресторана — составной балл.
4. Топ-k ресторанов → VLM-генератор со всеми доказательствами → ответ с цитатами.

Это выходит далеко за рамки текстового RAG. Каждая модальность добавляет сигнал, который упускает один только текст.

### Агентный мультимодальный RAG

Multi-hop: если первый поиск не возвращает ответы с высокой уверенностью, LLM переформулирует запрос и ищет снова. Паттерны агентного RAG из Phase 14 применимы и здесь. Примеры:

- Поиск исходного топ-10 → LLM говорит «слишком шумно, отфильтровать <40 дБ» → повторный поиск.
- Поиск изображений → LLM видит, что на одном из них есть меню → поиск текста меню → ответ.

Добавляет сложность, но справляется с запросами, которые не под силу однократному поиску.

### Оценка

Кросс-модальная оценка всё ещё незрела. Распространённые прокси-метрики:

- Recall@k по модальности.
- Точность по объединённому топ-k.
- Удовлетворённость конечным результатом, оцениваемая людьми.
- Специфичные для задачи метрики (завершённые бронирования, совершённые покупки).

Не существует стандартного бенчмарка, охватывающего все модальности. Большинство статей оценивают результаты на задачах, специфичных для предметной области.

## Use It

`code/main.py`:

- Три макета retriever'ов (текст, изображение, аудио), работающих на общем корпусе ресторанов.

## Key Terms

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Cross-modal retrieval | «Запрашиваешь одну модальность, извлекаешь другую» | Текстовый запрос извлекает изображения; запрос-изображение извлекает текст; требует общего пространства или переводчика |
| Score fusion | «Объединить оценки» | Взвешенная сумма оценок поиска по модальностям; самый простой вариант fusion |
| MoE fusion | «Эксперты, маршрутизируемые по модальности» | Gating-сеть выбирает, оценкам какой модальности доверять для каждого запроса |
| Grounded generation | «Цитируйте источники» | Каждое утверждение в ответе помечено индексом источника |
| MuRAG | «Первый мультимодальный RAG» | Статья 2022 года, заложившая паттерн мультимодального RAG |
| Agentic multi-hop | «Переформулировать и повторить» | LLM повторно запрашивает retriever'ы, когда уверенность первого прохода низкая |
