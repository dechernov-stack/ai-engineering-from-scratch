# BERT — Моделирование языка с масками

> GPT предсказывает следующее слово. BERT предсказывает пропущенное слово. Разница в одном предложении — и полдесятилетия всего, что связано с эмбеддингами.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 7 · 05 (Full Transformer), Phase 5 · 02 (Text Representation)
**Time:** ~45 минут

## Проблема

В 2018 году каждая NLP-задача — анализ тональности, NER, QA, entailment — обучала собственную модель с нуля на собственных размеченных данных. Не существовало предобученного чекпоинта «понимания английского», который можно было бы дообучить. ELMo (2018) показала, что можно предобучать контекстные эмбеддинги с помощью двунаправленной LSTM; это помогало, но плохо обобщалось.

BERT (Devlin et al. 2018) поставил вопрос: что если взять трансформерный энкодер, обучить его на каждом предложении из интернета и заставить предсказывать пропущенные слова по контексту с обеих сторон? Затем вы дообучаете одну голову под свою конкретную задачу. Эффективность по параметрам стала откровением.

Результат: в течение 18 месяцев BERT и его варианты (RoBERTa, ALBERT, ELECTRA) заняли первые места во всех существующих NLP-лидербордах. К 2020 году каждая поисковая система, конвейер модерации контента и система семантического поиска на земле имели внутри BERT.

В 2026 году модели только с энкодером по-прежнему остаются правильным инструментом для классификации, поиска и структурированного извлечения данных — они работают в 5–10 раз быстрее на токен, чем декодеры, а их эмбеддинги — основа каждого современного стека поиска. ModernBERT (декабрь 2024) расширил архитектуру до контекста в 8K с Flash Attention + RoPE + GeGLU.

## Концепция

![Masked language modeling: pick tokens, mask them, predict originals](../assets/bert-mlm.svg)

### Обучающий сигнал

Возьмём предложение: `the quick brown fox jumps over the lazy dog`.

Замаскируем 15% токенов случайным образом:

```
input:  the [MASK] brown fox jumps [MASK] the lazy dog
target: the  quick brown fox jumps  over  the lazy dog
```

Обучим модель предсказывать исходные токены в замаскированных позициях. Поскольку энкодер двунаправленный, предсказание `[MASK]` в позиции 1 может использовать `brown fox jumps` в позициях 2+. Это то, чего GPT делать не может.

### Правила маскирования BERT

Из 15% токенов, выбранных для предсказания:

- 80% заменяются на `[MASK]`.
- 10% заменяются случайным токеном.
- 10% остаются без изменений.

Почему не всегда `[MASK]`? Потому что `[MASK]` никогда не встречается во время инференса. Обучение модели ожидать `[MASK]` в 100% замаскированных позиций создало бы сдвиг распределения между предобучением и дообучением. 10% случайной замены + 10% без изменений удерживают модель от обмана.

### Next Sentence Prediction (NSP) — и почему от неё отказались

Оригинальный BERT также обучался на NSP: по двум предложениям A и B предсказать, следует ли B за A. RoBERTa (2019) провела абляцию и показала, что NSP вредит, а не помогает. Современные энкодеры пропускают её.

### Что изменилось в 2026: ModernBERT

Статья ModernBERT 2024 года пересобрала блок на примитивах 2026 года:

| Компонент | Оригинальный BERT (2018) | ModernBERT (2024) |
|-----------|----------------------|-------------------|
| Позиционное кодирование | Обучаемое абсолютное | RoPE |
| Функция активации | GELU | GeGLU |
| Нормализация | LayerNorm | Pre-norm RMSNorm |
| Внимание | Полное плотное | Чередующееся локальное (128) + глобальное |
| Длина контекста | 512 | 8192 |
| Токенизатор | WordPiece | BPE |

И в отличие от стека 2018 года, он нативно работает с Flash Attention. Инференс в 2–3 раза быстрее при длине последовательности 8K, чем у DeBERTa-v3, с лучшими показателями GLUE.

### Сценарии использования, где энкодер всё ещё выигрывает в 2026 году

| Задача | Почему энкодер лучше декодера |
|------|---------------------------|
| Эмбеддинги для поиска / семантического поиска | Двунаправленный контекст = лучшее качество эмбеддинга на токен |
| Классификация (тональность, интент, токсичность) | Один прямой проход; нет накладных расходов на генерацию |
| NER / разметка токенов | Выход для каждой позиции, нативно двунаправленный |
| Zero-shot entailment (NLI) | Классификационная голова поверх энкодера |
| Реранкер для RAG | Оценка cross-encoder, в 10 раз быстрее, чем реранкеры на LLM |

## Соберите это

### Шаг 1: логика маскирования

См. `code/main.py`. Функция `create_mlm_batch` принимает список идентификаторов токенов, размер словаря и вероятность маскирования. Возвращает входные идентификаторы (с применёнными масками) и метки (только в замаскированных позициях, -100 в остальных — соглашение PyTorch об игнорируемом индексе).

```python
def create_mlm_batch(tokens, vocab_size, mask_prob=0.15, rng=None):
    input_ids = list(tokens)
    labels = [-100] * len(tokens)
    for i, t in enumerate(tokens):
        if rng.random() < mask_prob:
            labels[i] = t
            r = rng.random()
            if r < 0.8:
                input_ids[i] = MASK_ID
            elif r < 0.9:
                input_ids[i] = rng.randrange(vocab_size)
            # else: keep original
    return input_ids, labels
```

### Шаг 3: сравнение типов маскирования

Покажите, как правило «три пути» сохраняет модель пригодной к использованию без `[MASK]`. Сделайте предсказание на немаскированном предложении и на маскированном. Оба должны давать разумные распределения токенов, потому что модель видела оба паттерна при обучении.

### Шаг 4: дообучение головы

Замените голову MLM на классификационную голову на игрушечном датасете тональности. Обучается только голова; энкодер заморожен. Это паттерн, которому следует каждое приложение BERT.

## Используйте это

```python
from transformers import AutoModel, AutoTokenizer

tok = AutoTokenizer.from_pretrained("answerdotai/ModernBERT-base")
model = AutoModel.from_pretrained("answerdotai/ModernBERT-base")

text = "Attention is all you need."
inputs = tok(text, return_tensors="pt")
out = model(**inputs).last_hidden_state   # (1, N, 768)
```

**Модели эмбеддингов — это дообученный BERT.** Модели `sentence-transformers`, такие как `all-MiniLM-L6-v2`, — это BERT, обученные с контрастивной функцией потерь. Энкодер тот же. Изменилась функция потерь.

**Cross-encoder реранкеры — это тоже дообученный BERT.** Классификация пар на `[CLS] query [SEP] doc [SEP]`. Двунаправленное внимание между запросом и документом — это именно то, что даёт cross-encoder'ам преимущество в качестве перед биэнкодерами.

**Когда не стоит выбирать BERT в 2026 году.** Для всего генеративного. У энкодера нет разумного способа авторегрессивно производить токены. Также: для всего, что меньше 1B параметров, где маленький декодер может сравняться по качеству при большей гибкости (Phi-3-Mini, Qwen2-1.5B).

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| MLM | «Моделирование языка с масками» | Обучающий сигнал: случайно заменить 15% токенов на `[MASK]`, предсказать исходные. |
| Двунаправленность | «Смотрит в обе стороны» | Внимание энкодера не имеет каузальной маски — каждая позиция видит каждую другую позицию. |
| `[CLS]` | «Токен пулера» | Специальный токен, добавляемый в начало каждой последовательности; его итоговый эмбеддинг используется как представление уровня предложения. |
| `[SEP]` | «Разделитель сегментов» | Разделяет парные последовательности (например, запрос/документ, предложение A/B). |
| NSP | «Предсказание следующего предложения» | Вторая задача предобучения BERT; показана бесполезной в RoBERTa, отброшена после 2019 года. |
| Дообучение (fine-tuning) | «Адаптация к задаче» | Энкодер остаётся в основном замороженным; небольшая голова обучается поверх него под конкретную задачу. |
| Cross-encoder | «Реранкер» | BERT, который принимает на вход запрос и документ одновременно, выдаёт оценку релевантности. |
| ModernBERT | «Обновление 2024 года» | Энкодер, пересобранный с RoPE, RMSNorm, GeGLU, чередующимся локальным/глобальным вниманием, контекстом 8K. |
