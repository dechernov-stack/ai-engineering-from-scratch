# Vision Transformers (ViT)

> Изображение — это сетка патчей. Предложение — это сетка токенов. Один и тот же трансформер «съедает» и то, и другое.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 7 · 05 (Full Transformer), Phase 4 · 03 (CNNs), Phase 4 · 14 (Vision Transformers intro)
**Time:** ~45 минут

## Проблема

До 2020 года компьютерное зрение означало свёртки. Каждая SOTA-модель на ImageNet, COCO и бенчмарках детекции использовала CNN-бэкбон. Трансформеры были для языка.

Dosovitskiy et al. (2020) — «An Image is Worth 16x16 Words» — показали, что свёртки можно убрать полностью. Разрежьте изображение на патчи фиксированного размера, линейно спроецируйте каждый патч в эмбеддинг, подайте последовательность в обычный трансформер-энкодер. При достаточном масштабе (предобучение на ImageNet-21k или больше) ViT сравнивается или превосходит модели на базе ResNet.

ViT положил начало более широкой тенденции 2026 года: одна архитектура, много модальностей. Whisper токенизирует аудио. ViT токенизирует изображения. Токены действий — для робототехники. Пиксельные токены — для видео. Трансформеру всё равно — подайте ему последовательность, и он научится.

К 2026 году ViT и его потомки (DeiT, Swin, DINOv2, ViT-22B, SAM 3) владеют большей частью области зрения. CNN по-прежнему побеждают на периферийных устройствах и в задачах, чувствительных к задержке. Во всём остальном где-то в стеке есть ViT.

## Концепция

![Image → patches → tokens → transformer](../assets/vit.svg)

### Шаг 1 — патчификация

Разделите изображение `H × W × C` на последовательность `N × (P·P·C)` плоских патчей. Типичная настройка: изображение `224 × 224`, патчи `16 × 16` → 196 патчей по 768 значений каждый.

```
image (224, 224, 3) → 14 × 14 grid of 16x16x3 patches → 196 vectors of length 768
```

Размер патча — это рычаг управления. Меньшие патчи = больше токенов, лучше разрешение, квадратичная стоимость внимания. Большие патчи = грубее, дешевле.

### Шаг 2 — линейный эмбеддинг

Одна обучаемая матрица проецирует каждый плоский патч в `d_model`. Эквивалентно свёртке с размером ядра `P` и шагом `P`. В PyTorch это буквально `nn.Conv2d(C, d_model, kernel_size=P, stride=P)` — реализация в 2 строки.

### Шаг 3 — добавление токена `[CLS]` и позиционных эмбеддингов

- Добавьте в начало обучаемый токен `[CLS]`. Его итоговое скрытое состояние — это представление изображения, используемое для классификации.
- Добавьте обучаемые позиционные эмбеддинги (оригинальный ViT) или синусоидальные 2D (более поздние варианты).
- В 2024+ RoPE распространили на 2D для позиции, иногда без явных эмбеддингов.

### Шаг 4 — стандартный энкодер трансформера

Сложите стопкой L блоков `LayerNorm → Self-Attention → + → LayerNorm → MLP → +`. Идентично BERT. Никаких специфичных для зрения слоёв. Это педагогическая суть статьи.

### Шаг 5 — голова

Для классификации: возьмите скрытое состояние `[CLS]` → линейный слой → softmax. Для DINOv2 или SAM отбросьте `[CLS]`, используйте эмбеддинги патчей напрямую.

### Значимые варианты

| Модель | Год | Изменение |
|-------|------|--------|
| ViT | 2020 | Оригинал. Фиксированный размер патча, полное глобальное внимание. |
| DeiT | 2021 | Дистилляция; обучаем только на ImageNet-1k. |
| Swin | 2021 | Иерархический, со смещёнными окнами. Фиксированная субквадратичная стоимость. |
| DINOv2 | 2023 | Самообучение (без меток). Лучшие универсальные признаки для зрения. |
| ViT-22B | 2023 | 22 млрд параметров; действуют законы масштабирования. |
| SigLIP | 2023 | ViT + языковая пара, контрастивная sigmoid-функция потерь. |
| SAM 3 | 2025 | Сегментация чего угодно; ViT-Large + декодер масок с промптами. |

### Почему это заняло время

ViT требует *очень много* данных, чтобы сравняться с CNN, потому что у него нет ни одного из индуктивных смещений CNN (инвариантность к сдвигу, локальность). Без >100М размеченных изображений или сильного самообучающегося предобучения CNN по-прежнему побеждают при равных вычислениях. DeiT исправил это в 2021 году трюками с дистилляцией; DINOv2 исправил это окончательно в 2023 году с помощью самообучения.

## Соберите это

См. `code/main.py`. Патчификация и линейный эмбеддинг на чистом stdlib + проверки на здравый смысл. Без обучения — ViT в любом реалистичном масштабе требует PyTorch и часов работы GPU.

### Шаг 1: фейковое изображение

Изображение RGB 24 × 24 как список строк из кортежей `(R, G, B)`. Используем патчи 6×6 → 16 патчей, вектор эмбеддинга размерности 108 для каждого.

### Шаг 2: патчификация

```python
def patchify(image, P):
    H = len(image)
    W = len(image[0])
    patches = []
    for i in range(0, H, P):
        for j in range(0, W, P):
            patch = []
            for di in range(P):
                for dj in range(P):
                    patch.extend(image[i + di][j + dj])
            patches.append(patch)
    return patches
```

Растровый порядок: построчно по сетке. Каждый ViT использует именно такой порядок.

### Шаг 3: линейный эмбеддинг

Умножьте каждый плоский патч на случайную матрицу `(patch_flat_size, d_model)`. Проверьте, что форма выхода равна `(N_patches + 1, d_model)` после добавления `[CLS]`.

### Шаг 4: подсчёт параметров для реалистичного ViT

Выведите количество параметров для ViT-Base: 12 слоёв, 12 голов, d=768, patch=16. Сравните с ResNet-50 (~25M). ViT-Base выходит на ~86M. ViT-Large — ~307M. ViT-Huge — ~632M.

## Используйте это

```python
from transformers import ViTImageProcessor, ViTModel
import torch
from PIL import Image

processor = ViTImageProcessor.from_pretrained("google/vit-base-patch16-224-in21k")
model = ViTModel.from_pretrained("google/vit-base-patch16-224-in21k")

img = Image.open("cat.jpg")
inputs = processor(img, return_tensors="pt")
out = model(**inputs).last_hidden_state   # (1, 197, 768): [CLS] + 196 patches
cls_emb = out[:, 0]                       # image representation
```

**Эмбеддинги DINOv2 — стандарт 2026 года для признаков изображений.** Заморозьте бэкбон, обучите крошечную голову. Работает для классификации, поиска, детекции, генерации подписей. Чекпоинты DINOv2 от Meta превосходят CLIP на всех не-текстовых задачах зрения.

**Выбор размера патча.** Небольшие модели используют 16×16 (ViT-B/16). Плотные предсказания (сегментация) используют 8×8 или 14×14 (SAM, DINOv2). Очень большие модели используют 14×14.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Патч (Patch) | «Токен для визуального трансформера» | Плоский вектор значений пикселей для области изображения `P × P × C`. |
| Патчификация (Patchify) | «Режем + разворачиваем» | Разрезать изображение на непересекающиеся патчи, развернуть каждый в вектор. |
| Токен `[CLS]` | «Сводка изображения» | Добавляемый в начало обучаемый токен; его итоговый эмбеддинг — это представление изображения. |
| Индуктивное смещение (Inductive bias) | «Что предполагает модель» | У ViT меньше априорных предположений, чем у CNN; требуется больше данных, чтобы компенсировать разрыв. |
| DINOv2 | «ViT с самообучением» | Обучен без меток с использованием аугментации изображений + моментум-учителя. Лучшие универсальные признаки изображений в 2026 году. |
| SigLIP | «Преемник CLIP» | ViT + текстовый энкодер, обученные с контрастивной sigmoid-функцией потерь; лучше CLIP при равных вычислениях. |
| Swin | «Оконный ViT» | Иерархический ViT с локальным вниманием + смещёнными окнами; субквадратичный. |
| Токены-регистры (Register tokens) | «Трюк 2023 года» | Несколько дополнительных обучаемых токенов, поглощающих «стоки внимания» (attention sinks); улучшает признаки DINOv2. |
