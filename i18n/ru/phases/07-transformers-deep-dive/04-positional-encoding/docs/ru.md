# Позиционное кодирование — синусоидальное, RoPE, ALiBi

> Attention инвариантно к перестановкам. «Кот сидел на коврике» и «коврике на сидел кот» дают одинаковый результат без позиционного сигнала. Три алгоритма это исправляют — и у каждого своя ставка на то, что такое «позиция».

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 7 · 02 (Self-Attention), Phase 7 · 03 (Multi-Head Attention)
**Time:** ~45 минут

## Проблема

Scaled dot-product attention слеп к порядку. Матрица внимания `softmax(Q K^T / √d) V` вычисляется из попарных сходств. Перемешайте строки `X` — и строки выхода перемешаются точно так же. Ничто внутри attention не заботится о позиции.

Это не баг в модели типа «мешок слов». Но для языка, кода, аудио, видео — всего, где порядок несёт смысл — это фатально.

Решение — так или иначе внедрить позицию в эмбеддинги. Три эпохи ответов:

1. **Абсолютное синусоидальное кодирование** (Vaswani, 2017). Добавить `sin/cos` позиции к эмбеддингу. Просто, не требует обучения, плохо экстраполируется за пределы длины обучения.
2. **RoPE — Rotary Position Embeddings** (Su, 2021). Повернуть векторы Q и K на угол, пропорциональный позиции. Кодирует *относительную* позицию прямо в скалярном произведении. Доминирует в 2026 году.
3. **ALiBi — Attention with Linear Biases** (Press, 2022). Полностью отказаться от эмбеддингов; добавить к оценкам внимания линейный штраф для каждой головы в зависимости от расстояния. Отличная экстраполяция по длине.

По состоянию на 2026 год практически все передовые открытые модели используют RoPE: Llama 2/3/4, Qwen 2/3, Mistral, Mixtral, DeepSeek-V3, Kimi. Несколько моделей с длинным контекстом используют ALiBi или его современные варианты. Абсолютное синусоидальное кодирование — уже история.

### Абсолютное синусоидальное кодирование

Предварительно вычисляется фиксированная матрица `PE` формы `(max_len, d_model)`:

```
PE[pos, 2i]   = sin(pos / 10000^(2i / d_model))
PE[pos, 2i+1] = cos(pos / 10000^(2i / d_model))
```

Затем `X' = X + PE[:N]` перед attention. Каждое измерение — синусоида своей частоты. Модель учится считывать позицию по паттерну фазы. Не работает за пределами `max_len`: ничто не подсказывает модели, что происходит на позиции 2048, если она видела только позиции 0–2047.

### RoPE

Поворачиваются векторы Q и K (а не эмбеддинги). Для пары измерений `(2i, 2i+1)`:

```
[q'_2i    ]   [ cos(pos·θ_i)  -sin(pos·θ_i) ] [q_2i   ]
[q'_2i+1  ] = [ sin(pos·θ_i)   cos(pos·θ_i) ] [q_2i+1 ]

θ_i = base^(-2i / d_head),  base = 10000 by default
```

Такое же вращение применяется к ключам с позицией `pos_k`. Скалярное произведение `q'_m · k'_n` становится функцией только от `(m - n)`. То есть: **оценка внимания зависит только от относительного расстояния**, хотя вращение было привязано к абсолютным позициям. Красивый трюк.

Расширение RoPE: `base` можно масштабировать (NTK-aware, YaRN, LongRoPE), чтобы экстраполировать на более длинные контексты без переобучения. Именно так Llama 3 расширила контекст с 8K до 128K.

### ALiBi

Отказ от трюка с эмбеддингами. Оценки внимания смещаются напрямую:

```
attn_score[i, j] = (q_i · k_j) / √d  -  m_h · |i - j|
```

Где `m_h` — наклон, специфичный для головы (например, `1 / 2^(8·h/H)`). Близкие токены получают бонус; дальние — штраф. Никаких затрат на этапе обучения. В статье показано, что экстраполяция по длине превосходит синусоидальное кодирование и соответствует RoPE на исходной длине обучения.

### Что выбрать в 2026 году

| Вариант | Экстраполяция | Стоимость обучения | Используется в |
|---------|---------------|---------------|---------|
| Абсолютное синусоидальное | плохая | бесплатно | оригинальный transformer, ранний BERT |
| Обучаемое абсолютное | отсутствует | небольшая | GPT-2, GPT-3 |
| RoPE | хорошая при масштабировании | бесплатно | Llama 2/3/4, Qwen 2/3, Mistral, DeepSeek-V3, Kimi |
| RoPE + YaRN | отличная | этап дообучения | Qwen2-1M, Llama 3.1 128K |
| ALiBi | отличная | бесплатно | BLOOM, MPT, Baichuan |

RoPE победил, потому что встраивается в attention без изменения архитектуры, кодирует относительную позицию, а гиперпараметр `base` даёт удобный рычаг для дообучения на длинном контексте.

## Постройте это

### Шаг 1: синусоидальное кодирование

См. `code/main.py`. Вычисление в 4 строки:

```python
def sinusoidal(N, d):
    pe = [[0.0] * d for _ in range(N)]
    for pos in range(N):
        for i in range(d // 2):
            theta = pos / (10000 ** (2 * i / d))
            pe[pos][2 * i]     = math.sin(theta)
            pe[pos][2 * i + 1] = math.cos(theta)
    return pe
```

Добавьте это к матрице эмбеддингов перед первым слоем attention.

### Шаг 2: RoPE, применённое к Q, K

RoPE работает на месте с Q и K. Для каждой пары измерений:

```python
def apply_rope(x, pos, base=10000):
    d = len(x)
    out = list(x)
    for i in range(d // 2):
        theta = pos / (base ** (2 * i / d))
        c, s = math.cos(theta), math.sin(theta)
        a, b = x[2 * i], x[2 * i + 1]
        out[2 * i]     = a * c - b * s
        out[2 * i + 1] = a * s + b * c
    return out
```

Важно: применить ту же функцию к Q на позиции `m` и к K на позиции `n`. Их скалярное произведение получит множитель `cos((m-n)·θ_i)` на каждой паре координат. Attention бесплатно учится относительной позиции.

### Шаг 3: наклоны и смещение ALiBi

```python
def alibi_bias(n_heads, seq_len):
    # slope_h = 2 ** (-8 * h / n_heads) for h = 1..n_heads
    slopes = [2 ** (-8 * (h + 1) / n_heads) for h in range(n_heads)]
    bias = []
    for m in slopes:
        row = [[-m * abs(i - j) for j in range(seq_len)] for i in range(seq_len)]
        bias.append(row)
    return bias  # add to attention scores before softmax
```

Добавьте `bias[h]` к матрице оценок внимания `(seq_len, seq_len)` головы `h`, затем примените softmax.

### Шаг 4: проверка свойства относительного расстояния RoPE

Возьмите два случайных вектора `a, b`. Поверните на `(pos_a, pos_b)`. Затем на `(pos_a + k, pos_b + k)`. Оба скалярных произведения должны совпасть с точностью до ошибки округления. Именно это свойство — весь смысл RoPE: он инвариантен к абсолютному смещению, важен лишь относительный разрыв.

## Используйте это

PyTorch 2.5+ поставляется с утилитами RoPE в `torch.nn.functional`. Большая часть production-кода использует `flash_attn` или `xformers`, где RoPE применяется внутри ядра attention.

```python
from transformers import AutoModel
model = AutoModel.from_pretrained("meta-llama/Llama-3.2-3B")
# model.config.rope_scaling → {"type": "yarn", "factor": 32.0, "original_max_position_embeddings": 8192}
```

**Трюки для длинного контекста в 2026 году:**

- **NTK-aware интерполяция.** Пересчитать `base` в `base * (scale_factor)^(d/(d-2))` при расширении с 4K до 16K+.
- **YaRN.** Более умная интерполяция, сохраняющая энтропию внимания на длинных контекстах. Используется в Llama 3.1 128K.
- **LongRoPE.** Метод Microsoft 2024 года, использующий эволюционный поиск для подбора масштабных коэффициентов по каждому измерению. Используется в Phi-3-Long.
- **Интерполяция позиций + дообучение.** Просто сжать позиции на коэффициент расширения и дообучить на 1–5 млрд токенов. На удивление эффективно.

## Упражнения

1. **Лёгкое.** Постройте тепловую карту синусоидальной матрицы `PE` для `max_len=512, d=128`. Убедитесь в паттерне «полосы расширяются по мере роста индекса измерения».
2. **Среднее.** Реализуйте NTK-aware масштабирование RoPE. Обучите крошечную LM на последовательностях длиной 256, затем протестируйте на длине 1024 с масштабированием и без. Измерьте перплексию.
3. **Сложное.** Реализуйте ALiBi и RoPE в одном и том же модуле attention. Обучите 4-слойный transformer на задаче копирования с последовательностями длиной 512. Экстраполируйте до 2048 на этапе тестирования. Сравните деградацию.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Positional encoding | «Сообщает attention о порядке» | Любой сигнал, добавленный к эмбеддингам или attention, кодирующий позицию. |
| Sinusoidal | «Оригинальный вариант» | `sin/cos` на геометрических частотах, добавляемый к эмбеддингам; не экстраполируется. |
| RoPE | «Вращательные эмбеддинги» | Поворот Q, K на угол, зависящий от позиции; скалярное произведение кодирует относительное расстояние. |
| ALiBi | «Трюк с линейным смещением» | Добавление `-m·\|i-j\|` к оценкам внимания; не нужны эмбеддинги, отличная экстраполяция. |
| base | «Рычаг RoPE» | Масштабатор частоты в RoPE; увеличьте, чтобы расширить контекст при инференсе. |
| NTK-aware | «Трюк масштабирования RoPE» | Пересчёт `base`, чтобы высокочастотные измерения не сжимались при расширении контекста. |
| YaRN | «Навороченный вариант» | Интерполяция и экстраполяция по измерениям, сохраняющая энтропию внимания. |
| Extrapolation | «Работает за пределами длины обучения» | Способна ли схема позиционирования давать корректный результат сверх `max_len`, виденных в обучении? |
