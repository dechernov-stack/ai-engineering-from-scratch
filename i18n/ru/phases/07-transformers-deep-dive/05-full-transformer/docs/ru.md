# Полный трансформер — энкодер + декодер

> Внимание — главная звезда. Всё остальное — остаточные связи, нормализация, feed-forward, cross-attention — это каркас, позволяющий складывать его в глубину.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 7 · 02 (Self-Attention), Phase 7 · 03 (Multi-Head Attention), Phase 7 · 04 (Positional Encoding)
**Time:** ~75 минут

## Проблема

Один слой attention — это экстрактор признаков, а не модель. Одного матричного умножения на слой недостаточно ёмкости для языка. Нужна глубина — а глубина ломается без правильной обвязки.

Статья Vaswani 2017 года упаковала шесть архитектурных решений, превративших один слой attention в блок, пригодный для стекирования. Каждый трансформер с тех пор — только-энкодер (BERT), только-декодер (GPT), энкодер-декодер (T5) — наследует один и тот же скелет. В 2026 году блоки усовершенствованы (RMSNorm, SwiGLU, pre-norm, RoPE), но скелет остался тем же.

Этот урок — скелет. Следующие уроки специализируют его — 06 для энкодеров, 07 для декодеров, 08 для энкодер-декодеров.

## Концепция

![Encoder and decoder block internals, wired](../assets/full-transformer.svg)

### Шесть компонентов

1. **Эмбеддинг + сигнал позиции.** Токены → векторы. Позиция внедряется через RoPE (современный подход) или синусоидальное кодирование (классический).
2. **Self-attention.** Каждая позиция обращает внимание на каждую другую. В декодерах — маскированное.
3. **Feed-forward сеть (FFN).** Позиционно-независимый двухслойный MLP: `W_2 · activation(W_1 · x)`. Коэффициент расширения по умолчанию — 4×.
4. **Остаточная связь (residual connection).** `x + sublayer(x)`. Без этого градиенты затухают после ~6 слоёв.
5. **Нормализация слоя.** `LayerNorm` или `RMSNorm` (современный вариант). Стабилизирует остаточный поток (residual stream).
6. **Cross-attention (только декодер).** Запросы (queries) приходят от декодера, ключи и значения — от выхода энкодера.

Проследим, как вектор проходит через один блок: attention смешивает информацию между позициями, остаточная связь переносит её дальше, FFN преобразует её, а нормализация удерживает поток стабильным.

### Блок энкодера (используется в BERT, энкодере T5)

```
x → LN → MHA(self) → + → LN → FFN → + → out
                     ^              ^
                     |              |
                     └── residual ──┘
```

Энкодер двунаправленный. Маскирования нет. Все позиции видят все позиции.

### Блок декодера (используется в GPT, декодере T5)

```
x → LN → MHA(masked self) → + → LN → MHA(cross to encoder) → + → LN → FFN → + → out
```

В декодере три подслоя на блок. Средний — cross-attention — единственное место, где информация течёт от энкодера к декодеру. В чисто декодерной архитектуре (GPT) cross-attention опускается, и остаются только маскированный self-attention + FFN.

### Pre-norm против post-norm

Оригинальная статья: `x + sublayer(LN(x))` против `LN(x + sublayer(x))`. Post-norm вышел из моды примерно в 2019 году — его труднее обучать на большой глубине без тщательного прогрева (warmup). Pre-norm (`LN` *перед* подслоем) — стандарт 2026 года: Llama, Qwen, GPT-3+, Mistral — все используют его.

### Модернизированный блок 2026 года

Vaswani 2017 поставлял LayerNorm + ReLU. Современные стеки заменили оба компонента. Вот как выглядят production-блоки сейчас:

| Компонент | 2017 | 2026 |
|-----------|------|------|
| Нормализация | LayerNorm | RMSNorm |
| Активация FFN | ReLU | SwiGLU |
| Расширение FFN | 4× | 2.6× (SwiGLU использует три матрицы, общее число параметров совпадает) |
| Позиция | Синусоидальная абсолютная | RoPE |
| Attention | Полный MHA | GQA (или MLA) |
| Члены смещения (bias) | Да | Нет |

RMSNorm отбрасывает центрирование по среднему, присущее LayerNorm (на одно вычитание меньше), что экономит вычисления и эмпирически как минимум не уступает по стабильности. SwiGLU (`Swish(W1 x) ⊙ W3 x`) стабильно превосходит FFN на ReLU/GELU примерно на 0.5 пункта перплексии в статьях Llama, PaLM и Qwen.

### Количество параметров

Для одного блока с `d_model = d` и расширением FFN `r`:

- MHA: `4 · d²` (проекции Q, K, V, O)
- FFN (SwiGLU): `3 · d · (r · d)` ≈ `3rd²`
- Нормализации: незначительно

При `d = 4096, r = 2.6, layers = 32` (примерно Llama 3 8B) итого: `32 · (4·4096² + 3·2.6·4096²) ≈ 32 · (16 + 32) M = ~1.5B parameters per layer × 32 ≈ 7B` (плюс эмбеддинги и голова). Совпадает с опубликованными значениями.

## Соберите это

### Шаг 1: строительные блоки

Используя крошечный класс `Matrix` из урока 03 (скопированный в этот файл для автономности):

- `layer_norm(x, eps=1e-5)` — вычесть среднее, поделить на стандартное отклонение.
- `rms_norm(x, eps=1e-6)` — поделить на RMS. Без вычитания среднего.
- `gelu(x)` и `silu(x) * W3 x` (SwiGLU).
- `ffn_swiglu(x, W1, W2, W3)`.
- `encoder_block(x, params)` и `decoder_block(x, enc_out, params)`.

Полную схему соединений см. в `code/main.py`.

### Шаг 2: соберите 2-слойный энкодер и 2-слойный декодер

Соберите их в стек. Передайте выход энкодера в каждый cross-attention декодера. Добавьте финальный LN перед проекцией выхода.

```python
def encode(tokens, params):
    x = embed(tokens, params.emb) + sinusoidal(len(tokens), params.d)
    for block in params.encoder_blocks:
        x = encoder_block(x, block)
    return x

def decode(target_tokens, encoder_out, params):
    x = embed(target_tokens, params.emb) + sinusoidal(len(target_tokens), params.d)
    for block in params.decoder_blocks:
        x = decoder_block(x, encoder_out, block)
    return x
```

### Шаг 3: запустите forward на игрушечном примере

Пропустите 6-токенный исходный текст и 5-токенный целевой через модель. Проверьте, что форма выхода равна `(5, vocab)`. Без обучения — этот урок посвящён архитектуре, а не функции потерь.

### Шаг 4: замените на RMSNorm + SwiGLU

Замените LayerNorm и ReLU-FFN на RMSNorm и SwiGLU. Убедитесь, что формы остались прежними. Это модернизация 2026 года одной заменой функции.

## Используйте это

Эталонные реализации в PyTorch/TF: `nn.TransformerEncoderLayer`, `nn.TransformerDecoderLayer`. Но большая часть production-кода 2026 года реализует собственный блок, потому что:

- Flash Attention вызывается внутри attention, а не через `nn.MultiheadAttention`.
- GQA / MLA нет в стандартной эталонной реализации.
- RoPE, RMSNorm, SwiGLU не являются настройками по умолчанию в PyTorch.

В HF `transformers` есть чистые эталонные блоки, которые стоит прочитать: `modeling_llama.py` — канонический декодер-блок 2026 года. Это ~500 строк, и один раз разобрать его стоит.

**Энкодер против декодера против энкодер-декодера — что выбрать:**

| Задача | Выбор | Пример |
|------|------|---------|
| Классификация, эмбеддинги, QA по тексту | Только энкодер | BERT, DeBERTa, ModernBERT |
| Генерация текста, чат, код, рассуждения | Только декодер | GPT, Llama, Claude, Qwen |
| Структурированный вход → структурированный выход (перевод, суммаризация) | Энкодер-декодер | T5, BART, Whisper |

Только-декодер выиграл в языковых задачах, потому что масштабируется чище всего и справляется и с пониманием, и с генерацией. Энкодер-декодер по-прежнему лучше всего подходит, когда вход имеет чёткую идентичность «исходной последовательности» (перевод, распознавание речи, структурированные задачи).

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Block (блок) | «Один слой трансформера» | Стек из нормализации + attention + нормализации + FFN, обёрнутый в остаточные связи. |
| Residual (остаточная связь) | «Skip connection» | Выход `x + f(x)`; обеспечивает прохождение градиента через глубокие стеки. |
| Pre-norm | «Нормализовать до, а не после» | Современный вариант: `x + sublayer(LN(x))`. Позволяет обучать более глубокие модели без гимнастики с прогревом. |
| RMSNorm | «LayerNorm без среднего» | Деление на RMS; на одну операцию меньше, та же эмпирическая стабильность. |
| SwiGLU | «FFN, на который все перешли» | `Swish(W1 x) ⊙ W3 x → W2`. Превосходит ReLU/GELU по перплексии языковой модели. |
| Cross-attention | «Как декодер видит энкодер» | MHA, где Q из декодера, K/V из выходов энкодера. |
| FFN expansion (расширение FFN) | «Насколько широк средний MLP» | Отношение скрытого размера к d_model, обычно 4 (LayerNorm) или 2.6 (SwiGLU). |
| Bias-free (без смещений) | «Убрать члены +b» | Современные стеки опускают смещения в линейных слоях; небольшое улучшение перплексии, меньше модель. |
