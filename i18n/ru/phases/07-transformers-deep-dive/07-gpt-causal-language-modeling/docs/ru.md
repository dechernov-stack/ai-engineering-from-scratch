# GPT — Каузальное языковое моделирование

> BERT видит обе стороны. GPT видит только прошлое. Треугольная маска — это самая значимая отдельная строка кода в современном ИИ.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 7 · 02 (Self-Attention), Phase 7 · 05 (Full Transformer), Phase 7 · 06 (BERT)
**Time:** ~75 минут

## Проблема

Языковая модель отвечает на один вопрос: учитывая первые `t-1` токенов, каково распределение вероятностей для токена `t`? Обучите модель на этом сигнале — предсказании следующего токена — и получите модель, способную генерировать произвольный текст по одному токену за раз.

Чтобы обучить её целиком на всей последовательности параллельно, нужно, чтобы предсказание в каждой позиции зависело только от более ранних позиций. Иначе модель тривиально жульничает, подглядывая в ответ.

Каузальная маска решает эту задачу. Это одна верхнетреугольная матрица значений `-inf`, добавляемая к оценкам внимания перед softmax. После softmax эти позиции становятся равны 0. Каждая позиция может обращать внимание только на саму себя и более ранние позиции. А поскольку маска применяется один раз ко всей последовательности, за один проход вперёд вы получаете N параллельных предсказаний следующего токена.

GPT-1 (2018), GPT-2 (2019), GPT-3 (2020), GPT-4 (2023), GPT-5 (2025), Claude, Llama, Qwen, Mistral, DeepSeek, Kimi — все они являются каузальными трансформерами только с декодером и одним и тем же базовым циклом. Различия между ними — в качестве данных, масштабе и архитектурных улучшениях, а также в постобучении (SFT, RLHF, DPO и их преемниках).

## Концепция

![Causal mask creates a triangular attention matrix](../assets/causal-attention.svg)

### Маска

Для последовательности длины `N` строится матрица размера `N × N`:

```
M[i, j] = 0       if j <= i
M[i, j] = -inf    if j > i
```

Добавьте `M` к исходным оценкам внимания перед softmax. `exp(-inf) = 0`, так что замаскированные позиции вносят нулевой вес. Каждая строка матрицы внимания — это распределение вероятностей только по предыдущим позициям.

Стоимость реализации: один вызов `torch.tril()`. Время вычисления: наносекунды. Влияние на область: всё.

### Откуда берётся треугольник

Маску обычно представляют как заплатку, приклеенную к механизму внимания. Если провести вывод в обратном направлении, она перестаёт быть загадочной: внимание — это третье уточнение префиксного среднего, а треугольник — это границы цикла этого среднего, записанные в виде матрицы.

**Этап 1 — префиксное среднее.** Самое простое каузальное обобщение последовательности: позиция `i` становится средним позиций `0…i`. В виде цикла это `out[i] = X[:i+1].mean(0)`. То же самое вычисление — одно умножение матриц. Возьмите нижнетреугольную матрицу единиц, разделите каждую строку на её количество элементов, умножьте:

```python
import numpy as np

A = np.tril(np.ones((n, n)))
A = A / A.sum(axis=1, keepdims=True)
out = A @ X
```

Строка `i` матрицы `A` — это `[1/(i+1), …, 1/(i+1), 0, …, 0]`. Нули над диагональю — это и есть каузальность. Ничего из будущего не было замаскировано; будущее никогда не входило в сумму.

**Этап 2 — обучаемые веса.** Равномерное усреднение считает каждый прошлый токен одинаково значимым. Замените единицы обучаемой матрицей оценок `S`. Теперь строки больше не суммируются в единицу по построению, поэтому нормализуйте каждую строку с помощью softmax вместо деления на количество. Softmax никогда не выдаёт точный ноль, что нарушает каузальность — если только будущие оценки не подаются на вход как `-inf`, потому что `exp(-inf) = 0`:

```python
def softmax(x, axis):
    e = np.exp(x - np.max(x, axis=axis, keepdims=True))
    return e / e.sum(axis=axis, keepdims=True)

S = S + np.triu(np.full((n, n), -np.inf), k=1)
A = softmax(S, axis=1)
out = A @ X
```

Тот же треугольник, та же построчно-стохастическая матрица, то же одно матричное умножение. Маска `-inf` — это не новый механизм. Это нулевые элементы этапа 1, переведённые в область входных значений softmax.

**Этап 3 — веса, зависящие от содержания.** На этапе 2 `S` фиксированы после обучения: позиция 7 всегда взвешивает позицию 3 одинаково, независимо от того, что говорят токены. Пусть оценки зависят от самих токенов: `S = Q @ K.T / sqrt(d_k)`. Больше ничего не меняется. Маска, softmax, умножение матриц — идентичны.

Три этапа, один инвариант: нижнетреугольная построчно-стохастическая матрица, умноженная на последовательность. Равномерное усреднение, обучаемые статические веса, веса, зависящие от содержания. Маска никогда не добавлялась к вниманию. Она сохранилась от среднего.

### Параллельное обучение, последовательный вывод

Обучение: один прямой проход всей последовательности `(N, d_model)`, вычисление N потерь кросс-энтропии (по одной на позицию), суммирование, обратное распространение. Параллельно по последовательности. Именно поэтому обучение GPT масштабируется — вы обрабатываете 1M токенов в батче за один проход GPU.

Вывод: вы генерируете токен за токеном. Подайте `[t1, t2, t3]`, получите `t4`. Подайте `[t1, t2, t3, t4]`, получите `t5`. Подайте `[t1, t2, t3, t4, t5]`, получите `t6`. KV-кэш (Урок 12) сохраняет скрытые состояния `t1…tn`, чтобы вы не пересчитывали их на каждом шаге. Но последовательная глубина при выводе = длина выходной последовательности. Это и есть "авторегрессивный налог", и именно поэтому декодирование — узкое место по задержке в любой LLM.

### Функция потерь — сдвиг на единицу

Дана последовательность токенов `[t1, t2, t3, t4]`:

- Вход: `[t1, t2, t3]`
- Цели: `[t2, t3, t4]`

Для каждой позиции `i` вычислите `-log P(target_i | inputs[:i+1])`. Суммируйте. Это кросс-энтропия для всей последовательности.

Каждая трансформерная LM, о которой вы слышали, обучается на этой функции потерь. Предобучение, тонкая настройка, SFT — одна и та же потеря, разные данные.

### Стратегии декодирования

После обучения выбор сэмплирования имеет большее значение, чем принято думать.

| Метод | Что делает | Когда использовать |
|--------|--------------|-------------|
| Greedy | Argmax на каждом шаге | Детерминированные задачи, автодополнение кода |
| Temperature | Делит логиты на T, сэмплирует | Творческие задачи, более высокое T = больше разнообразия |
| Top-k | Сэмплирует только из top-k токенов | Убирает "хвосты" с низкой вероятностью |
| Top-p (nucleus) | Сэмплирует из наименьшего набора с суммарной вероятностью ≥ p | Стандарт с 2020 года; адаптируется к форме распределения |
| Min-p | Оставляет токены с `p > min_p * max_p` | С 2024 года; лучше отбрасывает длинные "хвосты", чем top-p |
| Speculative decoding | Модель-черновик предлагает N токенов, большая модель проверяет | Снижение задержки в 2–3 раза при том же качестве |

В 2026 году min-p + temperature 0.7 — разумный выбор по умолчанию для моделей с открытыми весами. Speculative decoding — обязательный элемент любого промышленного стека вывода.

### Что сделало "рецепт GPT" рабочим

1. **Только декодер.** Никаких накладных расходов на энкодер. Один проход внимания + FFN на слой.
2. **Масштабирование.** 124M → 1.5B → 175B → триллионы. Законы масштабирования Chinchilla (Урок 13) подсказывают, как расходовать вычисления.
3. **Обучение в контексте (in-context learning).** Проявилось в районе 6–13 млрд параметров. Модель может следовать few-shot примерам без дообучения.
4. **RLHF.** Постобучение на человеческих предпочтениях превратило сырой предобученный текст в чат-ассистентов.
5. **Pre-norm + RoPE + SwiGLU.** Стабильное обучение при масштабировании.

Базовая архитектура почти не изменилась со времён GPT-2. Всё интересное происходило в данных, масштабе и постобучении.

## Постройте это

### Шаг 1: каузальная маска

См. `code/main.py`. Одна строка кода:

```python
def causal_mask(n):
    return [[0.0 if j <= i else float("-inf") for j in range(n)] for i in range(n)]
```

Добавьте её к оценкам внимания перед softmax. Это весь механизм целиком.

### Шаг 2: 2-слойная модель в стиле GPT

Соберите стеком два блока декодера (маскированное self-attention + FFN, без cross-attention). Добавьте эмбеддинг токенов, позиционное кодирование и unembedding (связанный с матрицей эмбеддингов токенов — стандартный приём со времён GPT-2).

### Шаг 3: предсказание следующего токена, от начала до конца

На игрушечном словаре из 20 токенов получите логиты в каждой позиции. Вычислите кросс-энтропийную потерю относительно цели со сдвигом на единицу. Без градиента — это проверка прямого прохода на корректность.

### Шаг 4: сэмплирование

Реализуйте greedy, temperature, top-k, top-p, min-p. Запустите каждый на фиксированном промпте и сравните результаты. Функция сэмплирования — это 10 строк кода.

## Используйте это

PyTorch, идиома 2026 года:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")
tok = AutoTokenizer.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")

prompt = "Attention is all you need because"
inputs = tok(prompt, return_tensors="pt")
out = model.generate(
    **inputs,
    max_new_tokens=64,
    temperature=0.7,
    top_p=0.9,
    do_sample=True,
)
print(tok.decode(out[0]))
```

Под капотом `generate()` выполняет прямой проход, извлекает логиты последней позиции, сэмплирует следующий токен, добавляет его и повторяет. Каждый промышленный стек вывода LLM (vLLM, TensorRT-LLM, llama.cpp, Ollama, MLX) реализует тот же цикл с серьёзной оптимизацией — батчевый prefill, непрерывный батчинг, пагинация KV-кэша, speculative decoding.

**GPT против BERT, одной строкой каждый:** GPT предсказывает `P(x_t | x_{<t})`. BERT предсказывает `P(x_masked | x_unmasked)`. Функция потерь определяет, способна ли модель генерировать текст.

## Ключевые термины

| Термин | Как говорят | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Каузальная маска | "Треугольник" | Верхнетреугольная матрица `-inf`, добавляемая к оценкам внимания так, чтобы позиция `i` видела только позиции `≤ i`. |
| Предсказание следующего токена | "Потеря (loss)" | Кросс-энтропия распределения модели относительно истинного следующего токена в каждой позиции. |
| Авторегрессивность | "Генерировать по одному" | Подать выход обратно на вход; параллелизм возможен только при обучении, но не при генерации. |
| Логиты | "Оценки до softmax" | Необработанный выход LM-головы до softmax; сэмплирование происходит именно на них. |
| Temperature | "Ручка креативности" | Делим логиты на T; T→0 = greedy, T→∞ = равномерное распределение. |
| Top-p | "Nucleus sampling" | Усечение распределения до наименьшего набора с суммой ≥p; сэмплирование из оставшегося. |
| Min-p | "Лучше, чем top-p" | Оставляем токены, где `p ≥ min_p × max_p`; порог адаптируется к резкости распределения. |
| Speculative decoding | "Черновик + проверка" | Дешёвая модель предлагает N токенов; большая модель проверяет их параллельно. |
| Teacher forcing | "Приём обучения" | Во время обучения подаётся истинный предыдущий токен, а не предсказание модели. Стандарт для любой seq2seq LM. |
