# Варианты внимания — скользящее окно, разреженность, дифференциальное внимание

> Полное внимание — это круг. Каждый токен видит каждый токен, и за это приходится платить памятью. Четыре варианта меняют форму круга и отыгрывают половину стоимости.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 7 · 02 (Self-Attention), Phase 7 · 03 (Multi-Head), Phase 7 · 12 (KV Cache / Flash Attention)
**Time:** ~60 минут

## Проблема

Полное внимание стоит `O(N²)` памяти и `O(N²)` вычислений от длины последовательности. Для Llama 3 70B с контекстом 128K это 16 миллиардов записей внимания на слой, умноженные на 80 слоёв. Flash Attention (Урок 12) скрывает `O(N²)` памяти активаций, но не меняет арифметическую стоимость — каждый токен всё равно обращает внимание на каждый другой токен.

Три класса вариантов меняют саму топологию матрицы внимания:

1. **Внимание со скользящим окном (SWA).** Каждый токен обращает внимание на фиксированное окно соседей, а не на весь префикс. Память и вычисления падают до `O(N · W)`, где `W` — окно. Gemma 2/3, первые слои Mistral 7B, Phi-3-Long.
2. **Разреженное / блочное внимание.** Оцениваются только выбранные пары `(i, j)`; остальные принудительно обнуляются. Longformer, BigBird, sparse transformer от OpenAI.
3. **Дифференциальное внимание.** Вычисляются две карты внимания с отдельными проекциями Q/K, одна вычитается из другой. Убивает «attention sink» («сток внимания»), который перетягивает вес на первые несколько токенов. DIFF Transformer от Microsoft (2024).

Эти подходы сосуществуют. Передовая модель 2026 года часто комбинирует их: большинство слоёв — SWA-1024, каждый пятый — глобальное полное внимание, и несколько слоёв — дифференциальные головы, которые «подчищают» извлечение информации. Соотношение SWA к глобальному вниманию 5:1 у Gemma 3 — текущий стандарт по учебнику.

## Концепция

### Внимание со скользящим окном (SWA)

Каждый запрос в позиции `i` обращает внимание только на позиции в `[i - W, i]` (каузальный SWA) или `[i - W/2, i + W/2]` (двунаправленный). Токены вне окна получают `-inf` в матрице оценок.

```
full causal:           sliding window (W=4):
positions 0-7          positions 0-7, W=4
    0 1 2 3 4 5 6 7        0 1 2 3 4 5 6 7
0 | x                0 |  x
1 | x x              1 |  x x
2 | x x x            2 |  x x x
3 | x x x x          3 |  x x x x
4 | x x x x x        4 |    x x x x
5 | x x x x x x      5 |      x x x x
6 | x x x x x x x    6 |        x x x x
7 | x x x x x x x x  7 |          x x x x
```

Для `N = 8192` и `W = 1024` матрица оценок имеет 1024 × 8192 ненулевых строк в ожидании — сокращение в 8 раз.

**KV-кэш уменьшается вместе с SWA.** На слой нужно хранить только последние `W` токенов K и V. Для конфигурации в духе Gemma-3 (окно 1024, контекст 128K) KV-кэш уменьшается в 128 раз.

**Цена за качество.** Трансформеры только с SWA плохо справляются с долгосрочным извлечением информации. Решение: чередовать слои SWA со слоями полного внимания. Gemma 3 использует соотношение SWA:global 5:1. Mistral 7B использовал стек с каузальным SWA, где информация «течёт вперёд» через перекрывающиеся окна — каждый слой расширяет эффективное рецептивное поле на `W`, и после `L` слоёв модель может обращать внимание на `L × W` токенов назад.

### Разреженное / блочное внимание

Паттерн разреженности `N × N` задаётся заранее. Три канонические формы:

- **Локальный + страйдовый (sparse transformer от OpenAI).** Внимание на последние `W` токенов плюс каждый `stride`-й токен до этого. Захватывает и локальный, и дальний контекст при `O(N · sqrt(N))` вычислений.
- **Longformer / BigBird.** Локальное окно + небольшой набор глобальных токенов (например, `[CLS]`), которые обращают внимание на всех и на которые обращают внимание все + случайные разреженные связи. Эмпирически — удвоение контекста при том же качестве.
- **Native Sparse Attention (DeepSeek, 2025).** Модель учится, какие блоки `(Q, K)` важны; нулевые блоки пропускаются на уровне ядра. Совместимо с FlashAttention.

Разреженное внимание — это прежде всего история про инженерию ядер. Математика проста (маскировать матрицу оценок); выигрыш достигается за счёт того, что нулевые записи никогда не загружаются в SRAM. FlashAttention-3 и API FlexAttention 2026 года делают пользовательские разреженные паттерны полноценной частью PyTorch.

### Дифференциальное внимание (DIFF Transformer, 2024)

У обычного внимания есть проблема «attention sink»: softmax требует, чтобы сумма каждой строки была равна 1, поэтому токены, которые не хотят обращать внимание ни на что конкретное, сбрасывают вес на первый токен (или первые несколько). Это крадёт ёмкость, которая должна была достаться реальному содержимому.

Дифференциальное внимание решает это, вычисляя **две** карты внимания и вычитая их:

```
A1 = softmax(Q1 K1^T / √d)
A2 = softmax(Q2 K2^T / √d)
DiffAttn = (A1 - λ · A2) V
```

где `λ` — обучаемый скаляр (обычно 0,5–0,8). A1 захватывает веса реального содержимого; A2 захватывает «сток». Вычитание отменяет сток и перераспределяет вес на релевантные токены.

Заявленные результаты (Microsoft, 2024): перплексия ниже на 5–10%, эффективный контекст в 1,5–2 раза длиннее при той же длине обучения, более чёткое извлечение по методу «игла в стоге сена».

### Сравнение вариантов

| Вариант | Вычисления | KV-кэш | Качество относительно полного | Использование в продакшене |
|---------|---------|----------|-----------------|----------------|
| Полное внимание | O(N²) | O(N) на слой | базовый уровень | слой по умолчанию в любой модели |
| SWA (окно 1024) | O(N·W) | O(W) на слой | -0,1 ppl, хорошо с глобальными слоями | Gemma 2/3, Phi-3-Long |
| Локальное + страйдовое разреженное | O(N·√N) | смешанный | похоже на SWA | sparse transformer от OpenAI, Longformer |
| BigBird (локальное + глобальное + случайное) | ~O(N) | смешанный | соответствует полному при 2× контексте | ранние long-context BERT |
| Native Sparse (DeepSeek-V3.2) | O(N · доля активных) | O(N) | в пределах 0,05 ppl | DeepSeek-V3.2, 2025 |
| Дифференциальное | O(2·N²) | O(2N) | -5…-10% ppl | DIFF Transformer, модели начала 2026 |

## Реализация

См. `code/main.py`. Мы реализуем компаратор каузальных масок, который показывает полное, SWA, локальное+страйдовое и дифференциальное внимание бок о бок на игрушечной последовательности.

### Шаг 1: полная каузальная маска (базовый уровень)

```python
def causal_mask(n):
    return [[0.0 if j <= i else float("-inf") for j in range(n)] for i in range(n)]
```

Базовый уровень из Урока 07. Нижнетреугольная матрица; нулевой вес выше диагонали.

### Шаг 2: каузальная маска скользящего окна

```python
def swa_mask(n, window):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
    return M
```

Один параметр — `window`. При `window >= n` получаем полное каузальное внимание. При `window = 1` каждый токен обращает внимание только на себя.

### Шаг 3: локальная + страйдовая разреженная маска

```python
def strided_mask(n, window, stride):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
        for j in range(0, i + 1, stride):
            M[i][j] = 0.0
    return M
```

Плотное локальное окно плюс каждый `stride`-й токен назад до начала последовательности. Рецептивное поле растёт логарифмическими шагами с добавлением слоёв.

### Шаг 4: дифференциальное внимание

```python
def diff_attention(Q1, K1, Q2, K2, V, lam):
    A1 = softmax_causal(Q1 @ K1.T / sqrt_d)
    A2 = softmax_causal(Q2 @ K2.T / sqrt_d)
    return (A1 - lam * A2) @ V
```

Два прохода внимания, вычитание с обучаемым коэффициентом смешивания. В коде мы сравниваем тепловую карту attention sink для обычного и дифференциального внимания и наблюдаем, как сток исчезает.

### Шаг 5: размеры KV-кэша

Выведите размер кэша на слой при `N = 131072` для каждого варианта. SWA и разреженные варианты уменьшают его в 10–100 раз. Дифференциальное — удваивает. Платите за память осознанно.

## Применение

Паттерны продакшена 2026 года:

```python
from transformers import AutoModelForCausalLM
# Gemma 3 mixes SWA (window=1024) and global layers at 5:1.
model = AutoModelForCausalLM.from_pretrained("google/gemma-3-27b-it")
# print(model.config.sliding_window, model.config.layer_types)
```

FlexAttention в PyTorch 2.5+ принимает функцию маски:

```python
from torch.nn.attention.flex_attention import flex_attention, create_block_mask

def swa_pattern(b, h, q_idx, kv_idx):
    return (q_idx - kv_idx < 1024) & (q_idx >= kv_idx)

mask = create_block_mask(swa_pattern, B=batch, H=heads, Q_LEN=n, KV_LEN=n)
out = flex_attention(q, k, v, block_mask=mask)
```

Это компилируется в пользовательское ядро Triton. Скорость в пределах 10% от FlashAttention-3 для распространённых паттернов, а функция маски — обычный Python-callable.

**Что выбрать:**

- **Чистое полное внимание** — для любого слоя при контексте до ~16K, или когда качество извлечения важнее всего.
- **Смесь SWA + global** — длинный контекст (>32K), ограничения по памяти при обучении и инференсе. Стандарт 2026 года выше 32K.
- **Разреженное блочное внимание** — пользовательское ядро, пользовательский паттерн. Применяется для специализированных задач (извлечение, аудио).
- **Дифференциальное внимание** — любая задача, где вред от загрязнения attention sink критичен (длинноконтекстный RAG, «игла в стоге сена»).

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Внимание со скользящим окном (SWA) | «Локальное внимание» | Каждый запрос обращает внимание на последние `W` токенов; KV-кэш уменьшается до `O(W)`. |
| Эффективное рецептивное поле | «Как далеко назад видит модель» | В стеке SWA из `L` слоёв с окном `W` — до `L × W` токенов. |
| Longformer / BigBird | «Локальное + глобальное + случайное» | Разреженные паттерны с несколькими всегда-активными глобальными токенами; ранний подход к длинному контексту. |
| Native Sparse Attention | «Трюк с ядром от DeepSeek» | Обучение разреженности на уровне блоков; пропуск нулевых блоков на уровне ядра при сохранении качества. |
| Дифференциальное внимание | «Две карты, одна вычитается» | DIFF Transformer: вычитание обучаемого коэффициента `λ`, умноженного на вторую карту внимания, из первой, чтобы устранить attention sink. |
| Attention sink | «Вес утекает на токен 0» | Нормализация softmax заставляет строки суммироваться до 1; неинформативные запросы сбрасывают вес на позицию 0. |
| FlexAttention | «Маска как Python» | API PyTorch 2.5+, компилирующий произвольные функции маски в ядра формата FlashAttention. |
| Смесь типов слоёв | «5:1 SWA к global» | Чередование разреженных и полных слоёв внимания в стеке для сохранения качества при меньшей памяти. |
