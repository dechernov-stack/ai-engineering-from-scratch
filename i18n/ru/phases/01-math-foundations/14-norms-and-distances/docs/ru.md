# Нормы и расстояния

> Ваша функция расстояния определяет, что означает "похожий". Выберите неправильно — и всё, что идёт дальше, сломается.

**Type:** Build
**Language:** Python
**Prerequisites:** Phase 1, Lessons 01 (Linear Algebra Intuition), 02 (Vectors, Matrices & Operations)
**Time:** ~90 minutes

## Learning Objectives

- Реализовать функции расстояний L1, L2, косинусного, Махаланобиса, Жаккара и редактирования с нуля
- Выбрать подходящую метрику расстояния для данной задачи ML и объяснить, почему альтернативы не работают
- Связать нормы L1 и L2 с регуляризацией LASSO и Ridge, а также их геометрическими областями ограничений
- Продемонстрировать, как один и тот же набор данных производит разных ближайших соседей при разных метриках

## The Problem

У вас есть два вектора. Может быть, это word embeddings. Может быть, это профили пользователей. Может быть, это массивы пикселей. Вам нужно узнать: насколько они близки?

Ответ зависит полностью от выбранной функции расстояния. Две точки данных могут быть ближайшими соседями под одной метрикой и далеко друг от друга под другой. Ваш классификатор KNN, ваш движок рекомендаций, ваша база данных векторов, ваш алгоритм кластеризации, ваша функция потерь — все они зависят от этого выбора. Ошибитесь и ваша модель будет оптимизировать не то.

Нет универсального лучшего расстояния. L2 работает для пространственных данных. Косинусное сходство доминирует в NLP. Жаккар работает с множествами. Редактирование работает со строками. Махаланобис учитывает корреляции. Вассерштейн движет вероятностную массу. Каждый кодирует разное предположение о том, что означает "похожий".

Этот урок строит все основные функции расстояния с нуля, показывает, когда каждая из них — правильный инструмент, и демонстрирует, как один и тот же набор данных производит совершенно разных ближайших соседей в зависимости от используемой метрики.

## The Concept

### Нормы: измерение величины вектора

Норма измеряет "размер" вектора. Каждая функция расстояния между двумя векторами может быть записана как норма их разности: d(a, b) = ||a - b||. Таким образом, понимание норм — это понимание расстояний.

### Норма L1 (манхэттенское расстояние)

Норма L1 суммирует абсолютные значения всех компонент.

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

Это называется манхэттенским расстоянием, потому что оно измеряет, как далеко вы идёте на городской сетке, где вы можете двигаться только вдоль осей. Нет диагоналей.

```
Point A = (1, 1)
Point B = (4, 5)

L1 distance = |4-1| + |5-1| = 3 + 4 = 7

On a grid, you walk 3 blocks east and 4 blocks north.
```

Когда использовать L1:
- Высокоразмерные разреженные данные (текстовые признаки, one-hot кодирование)
- Когда вам нужна робастность к выбросам (одна огромная разница не доминирует)
- Задачи отбора признаков (L1 регуляризация способствует разреженности)

Связь с L1 регуляризацией (Lasso): добавление ||w||_1 к вашей функции потерь штрафует сумму абсолютных значений весов. Это толкает небольшие веса к точному нулю, выполняя автоматический отбор признаков. L1 штраф создаёт ромбовидные области ограничений в пространстве весов, и углы ромбов лежат на осях, где некоторые веса равны нулю.

Связь с функциями потерь: Mean Absolute Error (MAE) — это среднее L1 расстояние между предсказаниями и целевыми значениями. Он штрафует все ошибки линейно, делая его более устойчивым к выбросам по сравнению с MSE.

### Норма L2 (евклидово расстояние)

Норма L2 — это прямолинейное расстояние. Квадратный корень из суммы квадратов компонент.

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

Это расстояние, которое вы выучили на уроках геометрии. Пифагор в n измерениях.

```
Point A = (1, 1)
Point B = (4, 5)

L2 distance = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

The straight line, cutting diagonally through the grid.
```

Когда использовать L2:
- Низко- и среднемерные непрерывные данные
- Когда масштабы признаков сравнимы
- Физические расстояния (пространственные данные, показания датчиков)
- Сходство изображений на уровне пикселей

Связь с L2 регуляризацией (Ridge): добавление ||w||_2^2 к вашей функции потерь штрафует большие веса. В отличие от L1, это не толкает веса к нулю. Это сжимает все веса к нулю пропорционально. L2 штраф создаёт круглые области ограничений, поэтому нет углов на осях. Веса становятся маленькими, но редко точно нулевыми.

Связь с функциями потерь: Mean Squared Error (MSE) — это среднее значение L2 расстояний в квадрате. Возведение в квадрат штрафует большие ошибки сильнее, чем маленькие.

```
MAE (L1 loss):  |y - y_hat|         Linear penalty. Robust to outliers.
MSE (L2 loss):  (y - y_hat)^2       Quadratic penalty. Sensitive to outliers.
```

### Нормы Lp: обобщённое семейство

L1 и L2 — это специальные случаи нормы Lp:

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

Различные значения p производят разные формы "единичных шаров" (множество всех точек на расстоянии 1 от начала координат):

```
p=1:    Diamond shape      (corners on axes)
p=2:    Circle/sphere      (the usual round ball)
p=3:    Superellipse       (rounded square)
p=inf:  Square/hypercube   (flat sides along axes)
```

### Норма L-infinity (расстояние Чебышева)

Когда p приближается к бесконечности, норма Lp сходится к максимальному абсолютному компоненту.

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

Расстояние между двумя точками определяется единственным измерением, где они различаются больше всего. Все остальные измерения игнорируются.

```
Point A = (1, 1)
Point B = (4, 5)

L-inf distance = max(|4-1|, |5-1|) = max(3, 4) = 4
```

Когда использовать L-infinity:
- Когда наихудшее отклонение в любом одном измерении имеет значение
- Игровые доски (король в шахматах движется в L-infinity: один шаг в любом направлении стоит 1)
- Технические допуски (каждое измерение должно быть в пределах спецификации)

### Косинусное сходство и косинусное расстояние

Косинусное сходство измеряет угол между двумя векторами, игнорируя их величины.

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

Оно варьируется от -1 (противоположные направления) до +1 (одно направление). Перпендикулярные векторы имеют косинусное сходство 0.

Косинусное расстояние преобразует его в расстояние: cosine_distance = 1 - cosine_similarity. Это варьируется от 0 (идентичное направление) до 2 (противоположное направление).

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

Почему косинус доминирует в NLP и embeddings: в тексте длина документа не должна влиять на сходство. Документ о кошках, который в два раза длиннее другого документа о кошках, всё ещё должен быть "похожим". Косинусное сходство игнорирует величину (длину) и только заботится о направлении. Два документа с одинаковым распределением слов, но разной длины указывают в одном направлении и получают косинусное сходство 1.0.

Когда использовать косинусное сходство:
- Сходство текстов (TF-IDF векторы, word embeddings, sentence embeddings)
- Любая область, где величина — это шум, а направление — это сигнал
- Системы рекомендаций (векторы предпочтений пользователя)
- Поиск embeddings (базы данных векторов почти всегда используют косинус или скалярное произведение)

### Скалярное произведение vs косинусное сходство

Скалярное произведение двух векторов это:

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

Косинусное сходство — это скалярное произведение, нормализованное обеими величинами. Когда оба вектора уже нормализованы по L2 (величина = 1), скалярное произведение и косинусное сходство идентичны.

```
If ||a|| = 1 and ||b|| = 1:
    a . b = cos(angle between a and b)
```

Когда они отличаются: скалярное произведение включает информацию о величине. Вектор с большей величиной получает более высокий балл скалярного произведения. Это имеет значение в некоторых системах поиска, где вы хотите, чтобы "популярные" элементы ранжировались выше. Величина действует как неявный сигнал качества или важности.

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

Both agree on direction, but dot product also reflects magnitude.
```

На практике:
- Используйте косинусное сходство, когда вам нужно чистое направленное сходство
- Используйте скалярное произведение, когда величины несут значимую информацию
- Многие базы данных векторов (Pinecone, Weaviate, Qdrant) позволяют вам выбирать между ними
- Если ваши embeddings нормализованы по L2, выбор не имеет значения

### Расстояние Махаланобиса

Евклидово расстояние рассматривает все измерения одинаково. Но если ваши признаки коррелированы или имеют разные масштабы, L2 даёт вводящие в заблуждение результаты.

Расстояние Махаланобиса учитывает структуру ковариации данных.

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

где S — это ковариационная матрица данных.

Интуитивно: расстояние Махаланобиса сначала декоррелирует и нормализует данные (отбеливание), затем вычисляет L2 расстояние в этом трансформированном пространстве. Если S — это единичная матрица (некоррелированные, единичные дисперсионные признаки), расстояние Махаланобиса сводится к евклидову расстоянию.

```
Example: height and weight are correlated.
Someone 6'2" and 180 lbs is not unusual.
Someone 5'0" and 180 lbs is unusual.

Euclidean distance might say they are equally far from the mean.
Mahalanobis distance correctly identifies the second as an outlier
because it accounts for the height-weight correlation.
```

Когда использовать расстояние Махаланобиса:
- Обнаружение выбросов (точки с большим расстоянием Махаланобиса от среднего — это выбросы)
- Классификация, когда признаки имеют разные масштабы и корреляции
- Когда у вас есть достаточно данных для оценки надёжной ковариационной матрицы
- Контроль качества в производстве (многомерный мониторинг процессов)

### Сходство Жаккара (для множеств)

Сходство Жаккара измеряет перекрытие между двумя множествами.

```
J(A, B) = |A intersect B| / |A union B|
```

Оно варьируется от 0 (нет перекрытия) до 1 (идентичные множества). Расстояние Жаккара = 1 - сходство Жаккара.

```
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

Intersection = {cat, fish}         size = 2
Union = {cat, dog, fish, bird, snake}  size = 5

Jaccard similarity = 2/5 = 0.4
Jaccard distance = 0.6
```

Когда использовать Жаккар:
- Сравнение множеств тегов, категорий или признаков
- Сходство документов на основе присутствия слов (не частоты)
- Обнаружение почти дубликатов (приближение Жаккара через MinHash)
- Сравнение бинарных векторов признаков (данные о наличии/отсутствии)
- Оценка моделей сегментации (Intersection over Union = Жаккар)

### Расстояние редактирования (расстояние Левенштейна)

Расстояние редактирования подсчитывает минимальное количество операций с одним символом, необходимых для преобразования одной строки в другую. Операции: вставка, удаление или замена.

```
"kitten" -> "sitting"

kitten -> sitten  (substitute k -> s)
sitten -> sittin  (substitute e -> i)
sittin -> sitting (insert g)

Edit distance = 3
```

Вычисляется с помощью динамического программирования. Заполните матрицу, где запись (i, j) — это расстояние редактирования между первыми i символами строки A и первыми j символами строки B.

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

Когда использовать расстояние редактирования:
- Проверка орфографии и коррекция
- Выравнивание последовательностей ДНК (с взвешенными операциями)
- Нечёткое сопоставление строк
- Дедупликация грязных текстовых данных

### KL дивергенция (не расстояние, но используется как таковая)

KL дивергенция измеряет, насколько одно вероятностное распределение отличается от другого. Рассмотрено в Уроке 09, но оно принадлежит этому обсуждению, потому что люди используют его как "расстояние", несмотря на то, что это не так.

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

Критическое свойство: KL дивергенция НЕ симметрична.

```
D_KL(P || Q) != D_KL(Q || P)
```

Это означает, что она не соответствует основному требованию метрики расстояния. Она также не удовлетворяет неравенству треугольника. Это дивергенция, не расстояние.

Прямая KL (D_KL(P || Q)) — это "mode-seeking": Q пытается охватить все моды P.
Обратная KL (D_KL(Q || P)) — это "mode-seeking": Q сосредотачивается на одной моде P.

Когда вы видите KL дивергенцию:
- VAE (KL термин в ELBO толкает латентное распределение к приорному)
- Дистилляция знаний (ученик пытается совпадать с распределением учителя)
- RLHF (KL штраф держит fine-tuned модель близко к базовой модели)
- Методы градиента политики (ограничение обновлений политики)

### Расстояние Вассерштейна (расстояние землекопа)

Расстояние Вассерштейна измеряет минимальную "работу", необходимую для преобразования одного вероятностного распределения в другое. Думайте об этом как: если одно распределение — это куча грязи, а другое — это яма, сколько грязи вам нужно переместить и на какое расстояние?

```
W(P, Q) = inf over all transport plans gamma of E[d(x, y)]
```

Для одномерных распределений это упрощается до интеграла абсолютной разности функций кумулятивного распределения:

```
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

Почему Вассерштейн имеет значение:
- Это истинная метрика (симметричная, удовлетворяет неравенству треугольника)
- Он предоставляет градиенты даже когда распределения не перекрываются (KL дивергенция идёт в бесконечность)
- Это свойство сделало его центральным для Wasserstein GAN (WGAN), который решил проблему нестабильности обучения оригинальных GAN

```
Distributions with no overlap:

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL divergence: infinity (log of zero)
Wasserstein: 4 (move all mass 4 bins)

Wasserstein gives a meaningful gradient. KL does not.
```

Когда использовать Вассерштейн:
- Обучение GAN (WGAN, WGAN-GP)
- Сравнение распределений, которые могут не перекрываться
- Проблемы оптимального транспорта
- Поиск изображений (сравнение цветовых гистограмм)

### Почему разные задачи нуждаются в разных расстояниях

| Задача | Лучшее расстояние | Почему |
|------|--------------|-----|
| Сходство текстов | Косинус | Величина — это шум, направление — это смысл |
| Сравнение пикселей изображения | L2 | Пространственные отношения имеют значение, признаки сравнимого масштаба |
| Разреженные высокоразмерные признаки | L1 | Робастно, не усиливает редкие большие различия |
| Перекрытие множеств (теги, категории) | Жаккар | Данные естественно множественные, не векторные |
| Сопоставление строк | Редактирование | Операции отображаются на интуицию человеческого редактирования |
| Обнаружение выбросов | Махаланобис | Учитывает корреляции признаков и масштабы |
| Сравнение распределений | KL дивергенция | Измеряет потерянную информацию при использовании Q вместо P |
| Обучение GAN | Вассерштейн | Предоставляет градиенты даже когда распределения не перекрываются |
| Embeddings (база данных векторов) | Косинус или скалярное произведение | Embeddings натренированы кодировать смысл в направлении |
| Рекомендации | Скалярное произведение | Величина может кодировать популярность или уверенность |
| Последовательности ДНК | Взвешенное редактирование | Стоимость замены варьируется в зависимости от пары нуклеотидов |
| QC производства | L-infinity | Наихудшее отклонение в любом измерении имеет значение |

### Связь с функциями потерь

Функции потерь — это функции расстояния, применённые к предсказаниям против целей.

```
Loss function       Distance it uses       Behavior
MSE                 L2 squared             Penalizes large errors heavily
MAE                 L1                     Penalizes all errors equally
Huber loss          L1 for large errors,   Best of both: robust to outliers,
                    L2 for small errors    smooth gradient near zero
Cross-entropy       KL divergence          Measures distribution mismatch
Hinge loss          max(0, margin - d)     Only penalizes below margin
Triplet loss        L2 (typically)         Pulls positives close, pushes
                                           negatives away
Contrastive loss    L2                     Similar pairs close, dissimilar
                                           pairs beyond margin
```

### Связь с регуляризацией

Регуляризация добавляет штраф нормы на веса к функции потерь.

```
L1 regularization (Lasso):   loss + lambda * ||w||_1
  -> Sparse weights. Some weights become exactly zero.
  -> Automatic feature selection.
  -> Solution has corners (non-differentiable at zero).

L2 regularization (Ridge):   loss + lambda * ||w||_2^2
  -> Small weights. All weights shrink toward zero.
  -> No feature selection (nothing goes to exactly zero).
  -> Smooth solution everywhere.

Elastic Net:                  loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> Combines sparsity of L1 with stability of L2.
  -> Groups of correlated features are kept or dropped together.
```

Почему L1 производит разреженность, но L2 — нет: представьте область ограничений в 2D пространстве весов. L1 — это ромб, L2 — это круг. Контуры функции потерь (эллипсы) с наибольшей вероятностью касаются ромба в углу, где один вес равен нулю. Они касаются круга в гладкой точке, где оба веса ненулевые.

### Поиск ближайшего соседа

Каждая функция расстояния подразумевает задачу поиска ближайшего соседа: по запросу, найти ближайшие точки в наборе данных.

Точный поиск ближайшего соседа — это O(n * d) на запрос в наборе данных n точек с d измерениями. Для больших наборов данных это слишком медленно.

Алгоритмы приблизительного поиска ближайшего соседа (ANN) обменивают небольшое количество точности на массивные прирост скорости:

```
Algorithm         Approach                      Used by
KD-trees          Axis-aligned space partition   scikit-learn (low-dim)
Ball trees        Nested hyperspheres            scikit-learn (medium-dim)
LSH               Random hash projections        Near-duplicate detection
HNSW              Hierarchical navigable         FAISS, Qdrant, Weaviate
                  small-world graph
IVF               Inverted file index with       FAISS (billion-scale)
                  cluster-based search
Product quant.    Compress vectors, search       FAISS (memory-constrained)
                  in compressed space
```

HNSW (Hierarchical Navigable Small World) — это доминирующий алгоритм в современных базах данных векторов. Он строит многослойный граф, где каждый узел подключается к своим приблизительным ближайшим соседям. Поиск начинается на верхнем слое (разреженном, длинные прыжки) и спускается к нижнему слою (плотному, короткие прыжки).

## Use It

Наиболее практичное использование: поиск похожих элементов в базе данных векторов.

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
print(f"Similarities: {similarities[top_k]}")
```

Когда вы вызываете `model.encode(text)` и затем ищете базу данных векторов, это то, что происходит под капотом. Модель embedding отображает текст в векторы. База данных векторов вычисляет косинусное сходство (или скалярное произведение) между вашим вектором запроса и каждым сохранённым вектором, используя алгоритмы ANN, чтобы избежать проверки всех из них.

## Key Terms

| Термин | Что говорят люди | Что это на самом деле означает |
|------|----------------|----------------------|
| Норма | "Размер вектора" | Функция, которая отображает вектор в неотрицательный скаляр, удовлетворяя неравенству треугольника, абсолютной однородности и равенству нулю только для нулевого вектора |
| Норма L1 | "Манхэттенское расстояние" | Сумма абсолютных значений компонент. Производит разреженность в оптимизации. Робастна к выбросам |
| Норма L2 | "Евклидово расстояние" | Квадратный корень из суммы квадратов компонент. Прямолинейное расстояние в евклидовом пространстве |
| Норма Lp | "Обобщённая норма" | p-й корень из суммы p-х степеней абсолютных компонент. L1 и L2 — это специальные случаи |
| Норма L-infinity | "Max норма" или "расстояние Чебышева" | Максимальное абсолютное значение компоненты. Предел Lp при p, стремящемся к бесконечности |
| Косинусное сходство | "Угол между векторами" | Скалярное произведение, нормализованное обеими величинами. Варьируется от -1 до +1. Игнорирует длину вектора |
| Косинусное расстояние | "1 минус косинусное сходство" | Преобразует косинусное сходство в расстояние. Варьируется от 0 до 2 |
| Скалярное произведение | "Ненормализованный косинус" | Сумма компонент-мудрых произведений. Равно косинусному сходству, умноженному на обе величины |
| Расстояние Махаланобиса | "Расстояние, учитывающее корреляцию" | L2 расстояние в пространстве, которое было отбелено (декоррелировано и нормализовано) с использованием ковариационной матрицы данных |
| Сходство Жаккара | "Перекрытие множеств" | Размер пересечения, делённый на размер объединения. Для множеств, не векторов |
| Расстояние редактирования | "Расстояние Левенштейна" | Минимум вставок, удалений и замен для преобразования одной строки в другую |
| KL дивергенция | "Расстояние между распределениями" | Не истинное расстояние (не симметричное). Измеряет дополнительные биты от использования Q для кодирования P |
| Расстояние Вассерштейна | "Расстояние землекопа" | Минимальная работа для транспортировки массы из одного распределения в другое. Истинная метрика |
| Приблизительный поиск ближайшего соседа | "Поиск ANN" | Алгоритмы (HNSW, LSH, IVF), которые находят приблизительно ближайшие точки намного быстрее, чем точный поиск |
| HNSW | "Алгоритм базы данных векторов" | Hierarchical Navigable Small World граф. Многослойный граф для быстрого приблизительного поиска ближайшего соседа |
| L1 регуляризация | "Lasso" | Добавление L1 нормы весов к потерям. Толкает веса к нулю (разреженность) |
| L2 регуляризация | "Ridge" или "weight decay" | Добавление квадрата L2 нормы весов к потерям. Сжимает веса к нулю без разреженности |
| Elastic Net | "L1 + L2" | Комбинирует L1 и L2 регуляризацию. Лучше обрабатывает коррелированные группы признаков, чем либо отдельно |
