# Временная разность — Q-обучение и SARSA

> Monte Carlo ждёт окончания эпизода. TD обновляется после каждого шага, бутстрапируя оценку следующего значения. Q-обучение — off-policy и оптимистично; SARSA — on-policy и осторожно. Оба метода — это одна строка кода. Оба лежат в основе каждого метода глубокого RL в этой фазе.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 9 · 01 (MDPs), Phase 9 · 02 (Dynamic Programming), Phase 9 · 03 (Monte Carlo)
**Time:** ~75 минут

## Проблема

Monte Carlo работает, но у него есть два дорогих требования. Ему нужны завершающиеся эпизоды, и обновление происходит только после получения итоговой отдачи. Если ваш эпизод длится 1000 шагов, MC ждёт 1000 шагов, прежде чем что-то обновить. Это метод с высокой дисперсией, низким смещением и медленной работой на практике.

У динамического программирования противоположный профиль — бутстрапированные обновления с нулевой дисперсией, — но требуется известная модель.

Обучение с временной разностью (TD) находит компромисс. Из одного перехода `(s, a, r, s')` формируется одношаговая цель `r + γ V(s')`, и `V(s)` сдвигается к ней. Без модели. Без полных эпизодов. Есть смещение от использования приближённого `V` в правой части, но дисперсия значительно ниже, чем у MC, а обновления происходят онлайн начиная с первого шага.

Это и есть точка опоры, вокруг которой вращается весь современный RL — DQN, A2C, PPO, SAC. Остальная часть Фазы 9 — это слои аппроксимации функций и приёмы, построенные поверх одношагового TD-обновления, которое вы напишете в этом уроке.

## Концепция

![Q-learning vs SARSA: off-policy max vs on-policy Q(s', a')](../assets/td.svg)

**TD(0)-обновление для V:**

`V(s) ← V(s) + α [r + γ V(s') - V(s)]`

Величина в скобках — это TD-ошибка `δ = r + γ V(s') - V(s)`. Это онлайн-аналог `G_t - V(s_t)` в MC. Сходимость требует, чтобы `α` удовлетворяло условию Роббинса-Монро (`Σ α = ∞`, `Σ α² < ∞`) и чтобы все состояния посещались бесконечно часто.

**Q-обучение.** Off-policy TD-метод для управления:

`Q(s, a) ← Q(s, a) + α [r + γ max_{a'} Q(s', a') - Q(s, a)]`

`max` предполагает, что *жадная* политика будет использоваться начиная с `s'`, независимо от того, какое действие агент на самом деле совершает. Это разделение позволяет Q-обучению изучать `Q*`, пока агент исследует среду через ε-жадную стратегию. Mnih et al. (2015) превратили это в глубокое Q-обучение на Atari (Урок 05).

**SARSA.** On-policy TD-метод:

`Q(s, a) ← Q(s, a) + α [r + γ Q(s', a') - Q(s, a)]`

Название происходит от кортежа `(s, a, r, s', a')`. SARSA использует действие `a'`, которое агент *на самом деле* совершает следующим, а не жадное `argmax`. Сходится к `Q^π` для той ε-жадной `π`, которая используется, что в пределе `ε → 0` становится `Q*`.

**Разница на задаче "ходьба по краю обрыва".** В классической задаче cliff-walking (падение с обрыва = награда -100) Q-обучение изучает оптимальный путь вдоль края обрыва, но иногда получает штраф во время исследования. SARSA изучает более безопасный путь на шаг дальше от обрыва, потому что учитывает шум исследования в своих Q-значениях. При достаточном обучении оба метода достигают оптимума при `ε → 0`. На практике это важно: когда исследование действительно происходит в эксплуатации, поведение SARSA более консервативно.

**Expected SARSA.** Замените `Q(s', a')` его ожидаемым значением при `π`:

`Q(s, a) ← Q(s, a) + α [r + γ Σ_{a'} π(a'|s') Q(s', a') - Q(s, a)]`

Более низкая дисперсия, чем у SARSA (нет выборки `a'`), та же on-policy цель. Часто используется по умолчанию в современных учебниках.

**n-шаговый TD и TD(λ).** Интерполяция между TD(0) и MC путём ожидания `n` шагов перед бутстрапированием. `n=1` — это TD, `n=∞` — это MC. TD(λ) усредняет по всем `n` с геометрическими весами `(1-λ)λ^{n-1}`. Большинство методов глубокого RL используют `n` в диапазоне от 3 до 20.

## Реализация

### Шаг 1: SARSA с ε-жадной политикой

```python
def sarsa(env, episodes, alpha=0.1, gamma=0.99, epsilon=0.1):
    Q = defaultdict(lambda: {a: 0.0 for a in ACTIONS})

    def choose(s):
        if random() < epsilon:
            return choice(ACTIONS)
        return max(Q[s], key=Q[s].get)

    for _ in range(episodes):
        s = env.reset()
        a = choose(s)
        while True:
            s_next, r, done = env.step(s, a)
            a_next = choose(s_next) if not done else None
            target = r + (gamma * Q[s_next][a_next] if not done else 0.0)
            Q[s][a] += alpha * (target - Q[s][a])
            if done:
                break
            s, a = s_next, a_next
    return Q
```

Восемь строк. *Единственное* отличие от Q-обучения — строка с целевым значением.

### Шаг 2: Q-обучение

```python
def q_learning(env, episodes, alpha=0.1, gamma=0.99, epsilon=0.1):
    Q = defaultdict(lambda: {a: 0.0 for a in ACTIONS})
    for _ in range(episodes):
        s = env.reset()
        while True:
            a = choose(s, Q, epsilon)
            s_next, r, done = env.step(s, a)
            target = r + (gamma * max(Q[s_next].values()) if not done else 0.0)
            Q[s][a] += alpha * (target - Q[s][a])
            if done:
                break
            s = s_next
    return Q
```

`max` разделяет цель и поведение. Этот единственный символ и есть разница между on-policy и off-policy.

### Шаг 3: кривые обучения

Отслеживайте среднюю отдачу за каждые 100 эпизодов. Q-обучение сходится быстрее на простом детерминированном GridWorld; SARSA более консервативен на cliff-walking. На 4×4 GridWorld из `code/main.py` оба метода близки к оптимуму после ~2000 эпизодов с `α=0.1, ε=0.1`.

### Шаг 4: сравнение с истиной DP

Запустите итерацию по ценности (Урок 02), чтобы получить `Q*`. Проверьте `max_{s,a} |Q_learned(s,a) - Q*(s,a)|`. Здоровый табличный TD-агент оказывается в пределах `~0.5` на 4×4 GridWorld после 10 000 эпизодов.

## Подводные камни

- **Начальные значения Q имеют значение.** Оптимистичная инициализация (`Q = 0` для задачи с отрицательной наградой) способствует исследованию. Пессимистичная инициализация может навсегда заблокировать жадную политику.
- **Расписание α.** Постоянное `α` подходит для нестационарных задач. Убывающее `α_n = 1/n` теоретически обеспечивает сходимость, но на практике слишком медленное — зафиксируйте `α` в `[0.05, 0.3]` и наблюдайте за кривой обучения.
- **Расписание ε.** Начните с высокого значения (`ε=1.0`), снижайте до `ε=0.05`. "GLIE" (жадность в пределе с бесконечным исследованием) — это условие сходимости.
- **Максимизационное смещение в Q-обучении.** Оператор `max` смещён вверх, когда `Q` зашумлён. Приводит к переоценке — Double Q-learning Хасселта (используется в DDQN, Урок 05) исправляет это с помощью двух Q-таблиц.
- **Незавершающиеся эпизоды.** TD может обучаться без терминальных состояний, но нужно либо ограничивать число шагов, либо правильно обрабатывать бутстрапирование на этом пределе. Стандартный подход: считать предел нетерминальным и продолжать бутстрапирование.
- **Хеширование состояний.** Если состояния представлены кортежами/тензорами, используйте хешируемый ключ (кортеж, а не список; кортеж из округлённых чисел с плавающей точкой, а не сырых значений).

## Применение

Ландшафт TD в 2026 году:

| Задача | Метод | Причина |
|------|-------|--------|
| Небольшие табличные среды | Q-обучение | Напрямую изучает оптимальную политику. |
| On-policy, критичные к безопасности задачи | SARSA / Expected SARSA | Консервативность во время исследования. |
| Пространство состояний высокой размерности | DQN (Фаза 9 · 05) | Q-функция на нейросети с replay-буфером и целевой сетью. |
| Непрерывные действия | SAC / TD3 (Фаза 9 · 07) | TD-обновление на Q-сети; сеть политики выдаёт действия. |
| LLM RL (на основе модели награды) | PPO / GRPO (Фаза 9 · 08, 12) | Actor-critic с TD-подобным преимуществом через GAE. |
| Офлайн RL | CQL / IQL (Фаза 9 · 08) | Q-обучение с консервативной регуляризацией. |

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| TD-ошибка | "Сигнал обновления" | `δ = r + γ V(s') - V(s)`, бутстрапированная невязка. |
| TD(0) | "Одношаговый TD" | Обновление после каждого перехода с использованием только оценки следующего состояния. |
| Q-обучение | "Off-policy RL 101" | TD-обновление с `max` по действиям в следующем состоянии; изучает `Q*` независимо от поведенческой политики. |
| SARSA | "On-policy Q-обучение" | TD-обновление с использованием реального следующего действия; изучает `Q^π` для текущей ε-жадной π. |
| Expected SARSA | "Низкодисперсионная SARSA" | Замена выборочного `a'` его ожиданием при π. |
| GLIE | "Правильное расписание исследования" | Жадность в пределе с бесконечным исследованием; необходимо для сходимости Q-обучения. |
| Бутстрапирование | "Использование текущей оценки в цели" | То, что отличает TD от MC. Источник смещения, но колоссальное снижение дисперсии. |
| Смещение максимизации | "Q-обучение переоценивает" | `max` по зашумлённым оценкам смещён вверх; исправляется Double Q-learning. |
