# Агентские экономики, токенные стимулы, репутация

> Долгоживущим автономным агентам (кривая работоспособности METR от 1 до 8 часов) нужна экономическая субъектность. Формирующийся **5-слойный стек** выглядит так: **DePIN** (физические вычисления) → **Идентичность** (W3C DIDs + репутационный капитал) → **Когниция** (RAG + MCP) → **Расчёты** (абстракция аккаунтов) → **Управление** (агентские DAO). Среди рабочих сетей стимулирования агентов — **Bittensor** (сабнеты TAO вознаграждают модели под конкретные задачи), **Fetch.ai / ASI Alliance** (LLM ASI-1 Mini + токен FET) и **Gonka** (PoW на основе трансформеров, перераспределяющий вычисления на продуктивные ИИ-задачи). Академическая работа: децентрализованная LaMAS с AAMAS 2025 использует **атрибуцию заслуг по значению Шепли** для справедливого вознаграждения вносящих вклад агентов; работа Google Research "Mechanism design for large language models" предлагает **токенные аукционы** с оплатой по второй цене при монотонной агрегации. В этом уроке мы строим минимальный рынок агентов, применяем атрибуцию заслуг по значению Шепли к мультиагентному пайплайну и запускаем аукцион токенов по второй цене, чтобы теоретико-игровой аппарат обрёл конкретное воплощение.

**Type:** Learn
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 16 (Negotiation and Bargaining), Phase 16 · 09 (Parallel Swarm Networks)

## Проблема

Мультиагентные системы усложняются, когда агенты создают ценность совместно, но должны вознаграждаться индивидуально. Классические механизмы — равное деление, «победитель получает всё» для последнего внёсшего вклад — несправедливы или уязвимы к манипуляциям. Коалиционное вознаграждение через значения Шепли справедливо по построению, но дорого вычислительно. Литература 2025–2026 годов продвигает полезные приближения: сэмплирование Шепли, аукционы с монотонной агрегацией и ончейн-репутацию, накапливающуюся из подтверждённых вкладов.

Помимо атрибуции заслуг, область обратилась к реальным экономическим агентам: Bittensor TAO вознаграждает вычисления для майнинга, используемые для дообучения моделей под конкретные сабнеты, Fetch.ai/ASI вознаграждает использование LLM ASI-1 Mini токенами FET, Gonka перераспределяет proof-of-work трансформеров на продуктивные ИИ-задачи. Агенты, совершающие транзакции автономно, существуют уже сегодня; вопрос в том, как согласовать стимулы.

В этом уроке агентские экономики рассматриваются как специфическое семейство проблем — атрибуция заслуг, дизайн механизмов и репутация — и каждая строится с минимальной математикой, чтобы идеи закрепились.

## Концепция

### 5-слойный стек агентской экономики

1. **DePIN (физические вычисления).** Децентрализованная инфраструктура, сдающая в аренду GPU, хранилище, пропускную способность. Сабнеты Bittensor, Render Network, Akash. Не специфично для агентов; агенты просто это используют.
2. **Идентичность.** W3C Decentralized Identifiers (DIDs) дают каждому агенту устойчивый ID, независимый от какой-либо платформы. Репутация накапливается на DID. Agent Network Protocol (ANP) использует DID как слой обнаружения.
3. **Когниция.** Цикл рассуждений агента: LLM + RAG + MCP. Это то, что строится в других фазах.
4. **Расчёты.** Абстракция аккаунтов (ERC-4337) позволяет агентам оплачивать газ со своих собственных балансов без необходимости держать ETH. Агенты могут платить за услуги, друг другу или за вычисления.
5. **Управление.** Агентские DAO: структуры управления, где люди *и* агенты голосуют по изменениям протокола, причём право голоса привязано к репутации.

Не каждая рабочая система использует все пять слоёв. Bittensor использует 1, 2, частично 3, частично 4, и ни одного элемента из 5. Агенты OpenAI не используют ничего, кроме 3. Стек — это справочная карта, а не требование.

### Bittensor, Fetch.ai, Gonka — что работает

**Bittensor (TAO).** Сабнеты — это специализированные задачи (языковое моделирование, генерация изображений, прогнозирование). Майнеры предоставляют выходы моделей. Валидаторы их ранжируют; оценка с весом по стейку распределяет вознаграждения TAO. У каждого сабнета своя оценка. Экономический урок: платить за качество выхода под конкретную задачу, а не за использованные вычисления.

**Fetch.ai / ASI Alliance.** LLM ASI-1 Mini работает в сети Fetch.ai; пользователи платят токенами FET за инференс. Нарратив «агенты как равноправные участники» здесь выражен сильнее: агент на Fetch может вызвать другого для выполнения задачи и заплатить в FET.

**Gonka.** Proof-of-work на трансформерах: «работой» являются прямые проходы трансформера. Майнеры зарабатывают, выполняя задачи инференса с известными правильными ответами (из обучающих данных). Ресурсно-продуктивный PoW вместо хэш-based PoW.

Все три сети являются production-grade по состоянию на апрель 2026 года. Распределение выплат различается. Bittensor вознаграждает качество относительно валидаторов сабнета; Fetch вознаграждает полезность, измеряемую платящими пользователями; Gonka вознаграждает верифицируемую работу инференса.

### Атрибуция заслуг по значению Шепли

Три агента совместно работают над задачей. Результат оценивается в 0.8. Кто что внёс?

Значение Шепли: уникальное распределение заслуг, удовлетворяющее четырём аксиомам (эффективность, симметрия, линейность, нулевой вклад). Для агента `i`:

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

где `S_i_O` — множество агентов, предшествующих `i` в порядке `O`. На практике: перебираются все перестановки, фиксируется предельный вклад каждого агента в каждой перестановке, затем усредняется.

Для N=3 агентов существует 6 перестановок. Для N=10 — уже 3.6 млн, поэтому на практике вместо полного перебора сэмплируют порядки.

### Аукцион по второй цене для агрегации

Google Research ("Mechanism design for large language models") предлагает токенные аукционы по второй цене для агрегации выходов LLM. Постановка: N агентов, каждый предлагает завершение; у каждого есть приватная ценность быть выбранным. Аукционер выбирает предложение с наивысшей ценностью, но платит за *вторую по величине* ценность. При монотонной агрегации (ценность зависит от того, какое предложение выбрано, а не от того, сколько ставок было сделано) это правдивый механизм — агенты делают ставки, соответствующие их истинной ценности.

Почему это важно для LLM-систем: можно передавать задачи на завершение нескольким агентам с разным ценообразованием; аукцион выбирает лучшее + справедливо платит, и у агентов нет стимула искажать информацию.

### Репутационный капитал

Репутационная оценка, привязанная к DID, накапливается из подтверждённых вкладов. Простое правило обновления:

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

С коэффициентом затухания `alpha`, близким к 1. Репутация:

- Дёшева для чтения при принятии решений о маршрутизации («отправлять сложные задачи агентам с высокой репутацией»).
- Дорога для подделки (накапливается со временем, привязана к DID).
- Может быть урезана: вклады, не прошедшие верификацию, вычитаются.

### Децентрализованная LaMAS с AAMAS 2025

Предложение LaMAS (AAMAS 2025) объединяет: DID-идентичность, атрибуцию заслуг по значению Шепли и простой аукционный механизм. Ключевое утверждение: децентрализация шага атрибуции заслуг делает систему проверяемой и устойчивой к манипуляции из одной точки.

### Где экономика ломается

- **Манипуляция оракулом цены.** Если функцию заслуг можно обыграть, агенты будут её обыгрывать. Каждому механизму нужен адверсариальный тест.
- **Sybil-атаки.** Один оператор создаёт N фейковых агентов, чтобы раздуть собственный вклад. DIDs замедляют, но не останавливают это; смягчением является стоимость подделки репутации.
- **Стоимость верификации.** Атрибуция заслуг справедлива ровно настолько, насколько справедлив верификатор. Если верификация дешёва (маленькая LLM), её можно обыграть; если дорога (комиссия людей), система не масштабируется.
- **Регуляторный навес.** Агентские экономики пересекаются с финансовым регулированием. Bittensor, Fetch и Gonka по состоянию на 2026 год все работают в юридически серых зонах в некоторых юрисдикциях.

### Когда агентские экономики имеют смысл

- **Открытые сети с разнородными операторами.** Ни одна команда не контролирует всех агентов.
- **Верифицируемые выходы.** Без верификации атрибуция заслуг — это гадание.
- **Долгоживущие рабочие процессы.** Одноразовые задачи не выигрывают от накопления репутации.
- **Токенизированные платежи юридически реализуемы** в вашей юрисдикции.

В закрытых корпоративных системах экономика уступает место более простому распределению (менеджеры назначают работу, метрики внутренние). Экономическая литература применима в основном к открытым сетям.

## Постройте это

`code/main.py` реализует:

- `shapley(value_fn, agents)` — точное вычисление значения Шепли полным перебором для малых N.
- `second_price_auction(bids)` — правдивый механизм; победитель платит вторую по величине цену.
- `Reputation` — репутация, привязанная к DID, с экспоненциальным затуханием и урезанием.
- Демо 1: три агента совместно работают над задачей, точное значение Шепли распределяет заслуги.
- Демо 2: пять агентов делают ставки на слот задачи; аукцион по второй цене выбирает победителя + оплату.
- Демо 3: 100 раундов назначения задач агентам с разнородной репутацией; маршрутизация по весу репутации обходит случайную.

Запуск:

```
python3 code/main.py
```

Ожидаемый вывод: значения Шепли для каждого агента; результат аукциона, показывающий равновесие правдивых ставок; маршрутизация по весу репутации, показывающая прирост качества на 10-20% по сравнению со случайной после разогрева.

## Внедрение

Запуск агентской экономики в 2026 году:

- **Начинайте с репутации, а не с токенов.** Репутацию дёшево реализовать, и она ценна сама по себе; токены добавляют юридическую и экономическую сложность.
- **Верифицируйте до вознаграждения.** Никогда не распределяйте заслуги без независимого шага верификации. Самооценка качества порождает sybil-игры.
- **Сэмплируйте Шепли, не вычисляйте точно.** Сэмплируйте 100-1000 порядков; полный перебор не масштабируется.
- **Ограничивайте коэффициент затухания и устанавливайте нижний порог репутации.** Неограниченное затухание стирает легитимных вкладчиков; слишком медленное затухание вознаграждает устаревших агентов с высокой репутацией.
- **Проверяйте механизмы адверсариально.** Запускайте red-team сценарии до открытия сети. У каждого механизма есть своя теория игр; вы хотите найти дыры, а не атакующих.

## Ключевые термины

| Термин | Что говорят | Что это на самом деле значит |
|------|----------------|------------------------|
| DePIN | «Децентрализованная физическая инфраструктура» | Вычисления/хранилище/пропускная способность, стимулируемые токенами. Bittensor, Akash, Render. |
| DID | «Децентрализованный идентификатор» | Спецификация W3C для переносимых ID. Репутация агента привязывается к DID, а не к платформе. |
| ERC-4337 | «Абстракция аккаунта» | Контрактные аккаунты, способные спонсировать газ, что обеспечивает платежи агентов. |
| Значение Шепли | «Справедливая атрибуция заслуг» | Уникальное распределение, удовлетворяющее эффективности, симметрии, линейности, нулевому вкладу. |
| Аукцион по второй цене | «Аукцион Викри» | Правдивый механизм: победитель платит вторую по величине ставку. Совместим с монотонной агрегацией. |
| Репутационный капитал | «Накопленная оценка качества» | Оценка, привязанная к DID, формируемая из подтверждённых вкладов; затухает со временем. |
| Агентская DAO | «Агенты + люди управляют» | DAO с агентами-избирателями как полноправными участниками, право голоса привязано к репутации. |
| TAO / FET / GPU-кредиты | «Деноминации токенов» | TAO Bittensor, FET Fetch.ai, различные токены DePIN. |
